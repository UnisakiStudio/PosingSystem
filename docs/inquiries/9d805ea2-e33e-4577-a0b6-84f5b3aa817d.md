# 姿勢アニメーション名入力の負荷修正

- 問い合わせ: `9d805ea2-e33e-4577-a0b6-84f5b3aa817d`
- 確認日: 2026-09-30
- 報告環境: 可愛いポーズツール 3.0.10 / ゆにさきポーズシステム 3.0.13 / Unity 2022.3.22f1 / MA 1.18.7
- 対象: Inspectorの「姿勢アニメーションを表示」内にある名前欄

## 原因

`AnimationDefineDrawer.OnGUI`で表示名を通常のTextFieldとして毎キー入力で保存し、ほかの設定と同じ変更検出ブロック内で`previewImage`をnullへ設定していた。次のInspector描画で`PosingSystemConverter.TakeScreenshot`が呼ばれ、名前だけの変更でもアバターの撮影、画像の圧縮、アセット保存が再実行される。

## 修正

- 名前をSerializedProperty対応の`EditorGUI.DelayedTextField`で編集し、Enterまたはフォーカス移動時に確定する。
- 名前欄をサムネイル無効化の変更検出から外し、入力中・確定後とも既存画像を保持する。
- 名前以外の設定変更では従来の画像無効化を維持する。
- 共通PosingSystemの変更で対応し、製品固有の変更は行わない。
- CHANGELOGのUnreleasedへ追記。

API仕様: https://docs.unity3d.com/2022.3/Documentation/ScriptReference/EditorGUI.DelayedTextField.html

## 検証

Unity 2022.3.22f1のEditModeで、実際のAnimationDefineDrawerを一時EditorWindowに表示し、マウス・キーイベントを送信する回帰テストを実行。

修正前: 4件中3件失敗。最初の1文字で名前が変更され、名前編集だけでpreviewImageがnullになる症状を再現。
修正後: 4件成功、失敗0件、スキップ0件。最終ジョブID: `28f32da2e3a94f96b7c80b7d03d3293c`。

1. 逐次入力中は設定が変わらず、Enter確定後も画像を保持。Undo/Redoが正常。
2. 別行の名前欄へ移動すると元の行だけを確定。両方のサムネイルを保持。
3. Escで未確定入力を取消。
4. 回転設定を変更すると対象行のサムネイルを無効化。
