# Unisaki Posing System

ఇవి Unisaki Studio భంగిమ సాధనాలు ఉపయోగించే ఉమ్మడి వ్యవస్థ మూలకోడ్, వనరులు.

Unityలో భంగిమ సాధనాన్ని ఎంచుకున్నప్పుడు Inspector పైభాగంలో ఇన్‌స్టాల్ చేసిన సంచికను చూడవచ్చు. వినియోగ సూచనలు ప్యాకేజీలోని READMEలో ఉన్నాయి.

## ఈ రిపాజిటరీ, వినియోగ నిబంధనలు

ఈ రిపాజిటరీలోని మూలకోడ్, వనరులు ఓపెన్ సోర్స్ కావు. ఉపయోగించడానికి BOOTHలో ఉత్పత్తిని కొనుగోలు చేసి వినియోగ నిబంధనలను అంగీకరించాలి.
