# Unisaki Posing System

Вихідний код і ресурси спільної системи, яку використовують інструменти поз Unisaki Studio.

## Посібник та історія змін

- [README: установлення, оновлення та налаштування](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/uk/README.md)
- [Історія змін](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/uk/CHANGELOG.md)
- [Сторінка товару на BOOTH](https://yunisaki.booth.pm/items/5479202)

Установлена версія відображається вгорі Inspector, коли ви вибираєте інструмент поз у Unity. Інструкції зібрано в README всередині пакета.

## Репозиторій та умови використання

Вихідний код і ресурси цього репозиторію не є відкритим ПЗ. Для використання потрібно придбати товар на BOOTH і прийняти умови використання.
