# Unisaki Posing System

Kod źródłowy i zasoby wspólnego systemu używanego przez narzędzia póz Unisaki Studio.

## Instrukcja i historia zmian

- [README: instalacja, aktualizacja i konfiguracja](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/pl/README.md)
