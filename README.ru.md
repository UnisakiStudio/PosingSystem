# Unisaki Posing System

Исходный код и ресурсы общей системы, используемой инструментами поз Unisaki Studio.

## Руководство и история изменений

- [README: установка, обновление и настройка](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/ru/README.md)
- [История изменений](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/ru/CHANGELOG.md)
- [Страница товара на BOOTH](https://yunisaki.booth.pm/items/5479202)

Установленная версия указана вверху Inspector при выборе инструмента поз в Unity. Инструкции собраны в README внутри пакета.

## Репозиторий и условия использования

Исходный код и ресурсы этого репозитория не являются открытым ПО. Для использования необходимо приобрести товар на BOOTH и принять условия использования.
