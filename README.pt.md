# Unisaki Posing System

Código-fonte e recursos do sistema comum utilizado pelas ferramentas de poses do Unisaki Studio.

## Manual e histórico de alterações

- [README: instalação, atualização e configuração](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/pt/README.md)

A versão instalada aparece no topo do Inspector ao selecionar a ferramenta de poses no Unity. As instruções estão reunidas no README do pacote.

## Este repositório e os termos de utilização

O código-fonte e os recursos deste repositório não são de código aberto. A utilização exige a compra do produto na BOOTH e a aceitação dos termos.
