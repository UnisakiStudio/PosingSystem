# Unisaki Posing System

Source code and resources for the shared system used by Unisaki Studio's posing tools.

## Documentation and changelog

- [README: installation, updates and configuration](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/en/README.md)
- [Changelog](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/en/CHANGELOG.md)
- [BOOTH product page](https://yunisaki.booth.pm/items/5479202)

To check the installed version, select the posing tool in Unity and look at the top of its Inspector. Instructions are in the package README.
