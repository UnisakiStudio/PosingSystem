# Unisaki Posing System

Broncode en bronnen van het gedeelde systeem voor de posetools van Unisaki Studio.

## Handleiding en wijzigingsgeschiedenis

- [README: installatie, bijwerken en instellingen](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/nl/README.md)
- [Wijzigingsgeschiedenis](Packages/jp.unisakistudio.posingsystem/Documentation~/Localization/nl/CHANGELOG.md)
- [Productpagina op BOOTH](https://yunisaki.booth.pm/items/5479202)

De geïnstalleerde versie staat boven in de Inspector wanneer je de posetool in Unity selecteert. De README in het pakket bevat de gebruiksaanwijzing.

## Deze repository en de gebruiksvoorwaarden

De broncode en bronnen van deze repository zijn niet open source. Voor gebruik moet je het product op BOOTH kopen en de voorwaarden accepteren.
