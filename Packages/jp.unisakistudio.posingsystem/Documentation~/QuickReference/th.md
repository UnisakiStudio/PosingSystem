# ไทย — Unisaki Posing System / คู่มือ

> เอกสารอ้างอิงด่วน 30 ภาษา ครอบคลุมคำอธิบายฟังก์ชันและตารางชื่อท่ามาตรฐาน เป็นเอกสารสั้นสำหรับอ้างอิง ใช้สารบัญภาษาเพื่ออ่านเอกสารเต็ม

## ฟังก์ชัน

### กลับซ้ายขวา

เพิ่มสวิตช์กลับซ้ายขวาในเมนู เพื่อกลับท่าเมื่อคุณต้องการ

### ปิดท่ามือ

เพิ่มสวิตช์ล็อกท่ามือในเมนู ขณะล็อก รูปนิ้วจะคงเดิมแม้กำคอนโทรลเลอร์

### หายใจ

เปิดหรือปิดการหายใจจากเมนู VRChat คนอื่นจะเห็นการเปลี่ยนแปลงด้วย

### พลิกตัว

พลิกตัวตามการเอียงศีรษะ รองรับเฉพาะท่านอนบางท่า

### ความสูงเท้า

ปรับความสูงเท้าโดยคงตำแหน่งศีรษะไว้ เพื่อแก้เท้าลอยหรือจมพื้น

### ความสูงพื้น

เลื่อนทั้งร่างกายรวมถึงศีรษะขึ้นหรือลงได้สูงสุด 3 เมตร ค่าความสูงพื้นที่ 50% คือระดับเดิม

### โหมดถ่ายภาพ

เพิ่มโหมดถ่ายภาพ เพื่อเคลื่อนไปข้างหน้าได้สูงสุด 3 เมตรและหมุน ปรับตำแหน่งที่มองเห็นตัวเอง

### กระโดดเพื่อสลับท่านอน

เมื่อเลือกทั้งท่านอนหงายและท่านอนคว่ำ ให้กระโดดอยู่กับที่เพื่อสลับท่า

### ลดท่าผิดรูปจากการหมุนศีรษะ

ลดท่าที่ผิดรูปเมื่อปลดล็อกศีรษะแล้วหันศีรษะต่างจากท่าต้นฉบับ

### ซิงค์โหมดถ่ายภาพ

ให้คนอื่นเห็นตำแหน่งและทิศทางในโหมดถ่ายภาพด้วย หากถ่ายเฉพาะบนหน้าจอของตนเองจะใช้ 0 bit

### แสดงศีรษะในโหมดถ่ายภาพ

แสดงศีรษะบนหน้าจอของตนเองแม้ถ่ายระยะใกล้ เมื่อออกจากโหมดถ่ายภาพจะกลับไปแสดงตามปกติ

### ปิดการโยกตัวเริ่มต้นของ VRChat

ปิดการโยกตัวขณะยืนเฉย ๆ ตามค่าเริ่มต้นของ VRChat โดยยังใช้แอนิเมชันหายใจของเครื่องมือนี้ได้

### เพิ่มแอนิเมชันหายใจ

ขยับหน้าอกและส่วนอื่นตามการหายใจ ตั้งความแรงแยกแต่ละท่าได้โดยไม่ใช้ bit ซิงค์เพิ่ม

### สร้างไอคอนท่า

ใช้ภาพตัวอย่างช่วยแยกท่า แต่การบิลด์อวาตาร์จะใช้เวลานานขึ้นเล็กน้อย

### ลดขนาดไอคอน

ลดขนาดข้อมูลอวาตาร์ โดยรายละเอียดของไอคอนจะลดลงเล็กน้อย

### ใช้การแก้ไขเฉพาะอวาตาร์

แก้ความต่างของทิศทางและการบิดข้อต่อของอวาตาร์แต่ละตัวโดยอัตโนมัติ

### ป้องกันเข่างอกลับด้าน

ช่วยป้องกันเข่างอไปด้านหลังเมื่อเหยียดขา

### ใช้ท่ายืน ย่อตัว และนอนคว่ำเดิมของอวาตาร์

ตรวจจับการเคลื่อนไหวจากเลเยอร์ Base ของอวาตาร์ขณะสร้าง โดยไม่เพิ่มในรายการนำเข้า หากตั้งค่าเองไว้จะใช้ค่านั้นก่อน

### รวมการล็อกการติดตามกับเครื่องมืออื่น

เปิดหากการล็อกการติดตามทำงานไม่ถูกต้องเมื่อใช้ร่วมกับเครื่องมืออื่น

## ฟังก์ชันอำนวยความสะดวก

### ตรวจสอบการตั้งค่า

เลือกออบเจ็กต์ที่มีปัญหาในส่วนตรวจสอบการตั้งค่าของ Inspector แก้ปัญหาที่แสดง แล้วลองอีกครั้ง

### อัปเดตพรีบิลด์

สร้างการตั้งค่าล่วงหน้าเพื่อลดเวลาบิลด์อวาตาร์

### ใช้พรีเซ็ตนี้

เลือกชุดท่าเริ่มต้น ซึ่งจะแทนที่การตั้งค่าท่าปัจจุบัน

### ปรับแอนิเมชัน

ดูตัวอย่างและปรับท่าอย่างละเอียด

### ถ่ายไอคอนใหม่

ใช้หลังเปลี่ยนชุดหรือรูปลักษณ์ หากเปลี่ยนการตั้งค่าให้พรีบิลด์ใหม่

### ล้างการเลือกเอง

ล้างการตั้งค่าและการปรับด้วยตนเองสำหรับประเภทการเคลื่อนไหวนี้ หากเปิดนำเข้าอัตโนมัติ การบิลด์ครั้งถัดไปจะตรวจจับอีกครั้ง ย้อนกลับได้
