Unisaki Posing System 3.2.0 — English guide

Unisaki Posing System is the shared core for Kawaii Posing, Cool Posing, and related tools. Install the purchased product and this core together using VCC or ALCOM. Use Unity 2022.3, VRChat Avatars SDK 3.10.4+, Modular Avatar 1.15.1+, and NDMF 1.14.0+.

Language

Choose Language / 言語 at the top of the tool Inspector. One choice controls the Inspector and generated VRChat menu. Re-upload the avatar after changing its language. Your last choice is remembered for other projects belonging to the same OS user on this computer. Without a saved choice, the tool follows the OS language and falls back to English. An existing avatar's explicit choice is preserved. Language preferences do not sync to other PCs.

Set up an avatar

Select a scene avatar with a VRC Avatar Descriptor in the Hierarchy, then choose Unisaki Studio > Add Kawaii Posing or Add Cool Posing. Apply a matching avatar preset when offered. The tool Inspector has Features, Poses, and Avatar Setup tabs. Choose the poses and optional controls you want, adjust the fit, then upload normally. Use Update prebuild after changing settings if you use cached prebuild data.

Detailed manuals

Open Manual on the purchased product's Inspector for its full English offline guide. The product's Documentation~/UserGuide.en.html contains installation, avatar fitting, VRChat controls, pose editing, parameter memory, updating, and troubleshooting. Standard pose names are translated for display; custom names, avatar names, asset filenames, saved object names, and parameter identifiers preserve their original spelling. Thirty languages can be selected. The bundled Inspector, setup dialogs, standard pose names and generated menus have complete display catalogs for every selection. This offline guide is in English.

30-language quick references cover the feature explanations and standard pose-name tables. These are concise references; this full manual is in English.

Licensing and support

Use the installer downloaded from the store where you purchased the product. Product licenses keep their existing per-user registry/file storage and remain separate from EditorPrefs. Read the original agreements included with the package. The existing English shared-system agreement is a reference translation; each product's agreement is also supplied separately.
