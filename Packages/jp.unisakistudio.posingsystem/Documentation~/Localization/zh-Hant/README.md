# Unisaki Posing System

這是Kawaii Posing Tool、Cool Posing Tool等產品使用的共用姿勢系統。通過Modular Avatar和NDMF，在上傳虛擬化身時產生所需的選單和動畫。

本README面向開發中的v3.2.0。正式發佈日期尚未確定。已安裝的版本可在姿勢工具的Inspector頂部查看。另請參閱[新增功能與更新紀錄](CHANGELOG.md)。

## 顯示語言與離線文件

在Inspector最上方的“Language / 言語”中選擇顯示語言。同一項選擇會同時套用於Inspector和產生的VRChat選單。要更改遊戲內的顯示語言，請重新上傳虛擬化身。

未選擇語言時，使用電腦的語言；不支援該語言時使用英語。支援Windows、macOS和Linux。最後選擇的語言儲存在EditorPrefs中，同一臺電腦上同一個OS使用者的其他專案也會使用此設定。所有姿勢工具和虛擬化身都使用同一種語言。在任意工具的Inspector中變更語言，都會更新共用設定；不採用個別虛擬化身的語言選擇。語言設定不會同步到其他電腦。授權的儲存方式不變。 僅在尚未儲存語言時的首次安裝確認中顯示語言按鈕。之後請在Inspector中變更語言。

可通過隨附的[語言清單](../index.html)選擇README、更新紀錄和使用說明。Inspector中的“使用說明”和“更新紀錄”也會遵循所選語言。原始使用條款和參考譯文仍按原有方式另行提供。

## 桌面模式下的姿勢切換

在桌面模式下切換站立、半蹲和坐姿時，縮短了所選姿勢生效前的延遲。一般建置和預先建置均會啟用此改進，無需專用命令或額外設定。VR模式及特殊狀態下保留原有處理方式。使用舊版預先建置時，請先更新預先建置再上傳。

## 安裝與版本更新

請按照各商品購買檔案中的安裝說明，通過VCC或ALCOM新增姿勢工具。本系統會作為姿勢工具的相依套件一同安裝。

v3.2.0所需環境如下。

- 使用Unity 2022.3的VRChat虛擬化身專案
- VRChat Avatars SDK 3.10.4或更高版本
- Modular Avatar 1.15.1或更高版本，須為1.x系列
- NDMF（Non-Destructive Modular Framework）1.14.0或更高版本，須為1.x系列

使用Kawaii Posing Tool時，請在ALCOM / VCC中將其更新為3.2.0，並確認Unisaki Posing System也已更新為3.2.0。如果使用過預先建置，請按一下“更新預先建置”，儲存場景後再上傳虛擬化身。

Cool Posing Tool 1.2.0使用共用系統3.2.0。請將商品和共用系統一同更新至對應版本。

### 曾使用8bit版本的使用者

新增的物件統一使用一般Prefab。在“功能”中關閉不需要的項目，可以降低參數用量。僅使用姿勢選擇時，基本用量為8 bit。

為保留已放置的虛擬化身和預設的參照，各商品的舊8bit版Prefab仍儲存在“Editor/Legacy”中。繼續使用現有8bit版本時，無需刪除或替換Prefab。Unity新建選單中選擇8bit版本的操作已取消。

## 設定介面說明

在Hierarchy中選取虛擬化身內的“可愛いポーズ”“カッコいいポーズ”等物件，即可進行設定。

| 頁籤 | 設定內容 |
| --- | --- |
| 功能 | 新增到遊戲內選單的項目、便利功能、圖示圖片、ExpressionParameters用量 |
| 姿勢 | 選擇、新增和調整姿勢順序，在Scene中預覽，各姿勢的詳情與動畫調整 |
| 虛擬化身設定 | 根據體型進行修正、膝部修正、匯入原始姿勢或自訂動作、預設 |

有詳細設定的項目可按一下“開啟設定”，在其下方展開設定區域。呼吸設定也位於“功能”中。

可通過頂部的“說明 / 更新紀錄”開啟使用說明、諮詢頁面和更新紀錄。更新紀錄可在商品和Unisaki Posing System之間切換查看。

## 功能與ExpressionParameters用量

在“功能”的“選單功能”中選取的項目會顯示在遊戲內選單中。例如，選取“左右鏡像”後，就能在遊戲內切換鏡像。僅在Inspector中選取此項，並不意味著始終對所有姿勢進行鏡像。

| 功能 | 額外使用的bit數 |
| --- | ---: |
| 左右鏡像 | 1 bit |
| 停用手勢 | 1 bit |
| 啟用呼吸動畫 | 0 bit |
| 呼吸（遊戲內開關） | 1 bit |
| 腳部高度 | 8 bit |
| 地面高度 | 8 bit |
| 拍照模式（僅自己的畫面） | 0 bit |
| 同步拍照模式 | 16 bit |
| 拍照模式中保持頭部可見 | 0 bit |
| 關閉VRChat預設站立搖擺 | 0 bit |
| 減輕頭部旋轉造成的姿勢變形 | 1 bit（與翻身共用） |
| 翻身 | 10 bit（其中1 bit與姿勢變形抑制共用） |

翻身功能的用量分別為：開關1 bit、頭部傾斜8 bit、頸部固定1 bit。如果已經啟用姿勢變形抑制，新增翻身功能時新增用量為9 bit。共用部分不會重複計算，更改勾選項時顯示用量也會更新。

顯示的合計值僅涵蓋安裝在該虛擬化身中的姿勢工具，不是包含服裝和其他功能元件在內的整個虛擬化身的總量。並用多個姿勢工具時，共用設定也不會重複計數。當姿勢數量超出基本編號範圍時，姿勢選擇還需要額外的bit。

### 腳部高度與地面高度

- “腳部高度”：保持頭部位置，調整腳部一側的高度。用於讓腳與地面或床面貼合。
- “地面高度”：上下移動包含頭部在內的整個身體。50%為原始高度，0%為向下3m，100%為向上3m。初始值為50%。

兩者均位於遊戲內的“設定”中，“地面高度”排在“腳部高度”之後。將“地面高度”從中央移開時會上下移動，恢復至50%附近時會返回原始高度並結束修正。沒有單獨的懸浮開關。視點修正在開始懸浮及操作地面高度時進行。

腳部高度的處理方式已改為：對於一般動畫，不再為了高度調整而重複產生全身動作。這樣可減少所產生動畫的資料量，但並不表示整個虛擬化身的體積一律縮小至原來的1/3。

### 拍照模式

1. 啟用“功能 > 選單功能 > 拍照模式”。
2. 在VRChat中開啟“拍照模式”，通過“選擇姿勢”選擇姿勢。
3. 使用“距離”向前移動，最遠可達3m，使用“朝向”進行旋轉。距離大於0時，虛擬化身會朝向自己。
4. 按需啟用“固定雙腳”。啟動時不會強制固定雙腳，因此可在固定前調整位置。如果在選單中新增了“停用手勢”，也可以在同一介面切換手型。
5. 通過“結束拍照”恢復距離和朝向，並解除雙腳固定。

拍照模式的移動和旋轉僅在自己的畫面中使用時，用量為0 bit。希望其他人也能看到位置和朝向時，請啟用“便利功能 > 同步拍照模式”。距離和朝向合計使用16 bit。

如果自己的虛擬化身靠近時頭部消失，請啟用“便利功能 > 拍照模式中保持頭部可見”。此設定只影響拍照期間自己的畫面，結束拍照後會恢復一般顯示。

### 跳躍切換躺姿

同時選擇仰臥和俯臥姿勢後，可通過原地跳躍進行切換。如果只選擇其中一種，則保持該姿勢。不希望通過跳躍切換時，請在Unity的“功能 → 便利功能”中關閉“跳躍切換躺姿”。不會額外消耗同步參數，新增用量為0 bit。虛擬化身使用多個姿勢工具時，在任意一個工具中關閉此功能，都會套用於整個虛擬化身。

### 翻身

在支援的躺姿中，向左右傾斜頭部，身體也會平滑翻身。並非所有躺姿都會自動支援此功能。

1. 啟用“功能 > 選單功能 > 翻身”。
2. 在“姿勢”中開啟所需躺姿的“詳情”，啟用“啟用翻身”。
3. 在“翻身側向姿勢”中指定側躺動畫。系統會根據原始姿勢和側躺姿勢產生左右翻身。按需調整“接地修正強度”。
4. 在VRChat中選擇支援的姿勢並開啟“翻身”。使用時請解除頸部固定。

啟用翻身的姿勢會根據頭部傾斜確定動畫的播放位置，因此無法再使用一般MotionTime設定。如果使用已經製作好的翻身動畫，請將其指定到一般動畫欄，並清空“翻身側向姿勢”。動畫的播放位置應設定為0時向左、0.5時仰臥、1時向右。

### 呼吸與預設搖擺

在“功能 > 便利功能 > 啟用呼吸動畫”中，可讓胸部等部位隨呼吸移動。通過“開啟設定”，可以為各姿勢分類選擇“無、弱、中、強、急、自訂”。“急”表示較快的呼吸。“自訂”可指定自己準備的呼吸動畫。

僅使用呼吸動作時，用量為0 bit。若要在VRChat中暫停或恢復呼吸，也請啟用“選單功能 > 呼吸”。開關同步使用1 bit。改變強度不會增加bit數。

頸部、肩部、手臂等也會隨胸部一起移動，以減少頭部和雙手的位置變化。這不是完全固定位置，請根據體型和姿勢選擇合適的強度。

“便利功能 > 關閉VRChat預設站立搖擺”可抑制VRChat預設新增的待機身體搖擺。初始為關閉，且會保留姿勢工具自身的呼吸及其他自訂動作。即使不使用呼吸動作，也可以啟用此項，且不會增加bit數。由預設待機動作以外的因素造成的搖擺，無法通過此設定停止。

並用多個姿勢工具時，在任意一個工具中停止預設搖擺，都會套用於整個虛擬化身。若要恢復，請在所有工具中關閉此設定，然後重新上傳。

### 減輕頭部旋轉造成的姿勢變形

當頭部朝向與原始姿勢不同時，解除頸部固定後可能導致姿勢變形，此時可使用此功能。它位於“功能 > 便利功能”中，不會新增專用的遊戲內選單。頸部固定時使用原始姿勢的朝向。仰臥姿勢會保持原本的向上朝向，因此不屬於修正物件。

### 選單圖示

- “產生姿勢圖示”：產生虛擬化身擺出各姿勢的圖片，並顯示在選單中。更容易辨認姿勢，但產生圖片會增加建置時間。
- “減少圖示容量”：降低圖片解析度，以縮小虛擬化身體積。

面向Android建置時不會產生姿勢圖示。更換服裝等之後，請使用“重新拍攝圖示”。姿勢清單中的圖片可通過“更新姿勢縮圖”更新。這些操作較為耗時，請先閱讀確認對話框再執行。

## 新增、排序與預覽姿勢

在“姿勢”的左側選擇姿勢分類。最上方的放大鏡頁籤可跨分類搜尋姿勢名。開啟“詳情”，即可集中設定動畫、圖示和MotionTime等。

可將多個動畫拖放到新增區域，或先在Project中選取，再按一下“匯入Project中選擇的片段”批次加入。同一片段的重複項會被排除。

要調整順序，請在“詳情”的“順序”中選擇目標位置。也可使用上下移動按鈕；移動後會保留詳情的展開或折疊狀態。

按一下各姿勢的“預覽”，無需開啟調整視窗即可在Scene中查看姿勢。結束預覽後恢復原始顯示。此簡易預覽不會執行MA或NDMF的建置處理，因此可能與建置時整合的服裝或FloorAdjuster等的最終結果不同。最終服裝效果和接地情況也請在建置虛擬化身後確認。

## 動畫調整與手腳自動調整（IK）

在“姿勢”中開啟“動畫調整”，即可一邊預覽，一邊細調身體與手腳。調整後，請通過視窗中的儲存操作儲存調整動畫。

對於支援手腳自動調整的商品和姿勢，系統會根據虛擬化身的體型調整手腳位置。可在動畫調整介面通過“啟用手腳自動調整”切換整體設定，通過“對此姿勢啟用IK”單獨切換各姿勢。未提供自動調整的姿勢會顯示相應說明。

如果希望在自動調整的基礎上手動完成，請按一下“將IK烘焙至調整中”。此操作會將當時的IK結果寫入新的調整動畫，並關閉該虛擬化身中對應姿勢的IK。原始動畫會保留。只有整體和目標姿勢的自動調整均已啟用，且存在可套用的IK設定時，此按鈕才可用。

可在“虛擬化身設定”的“防止膝蓋反折”中切換膝部修正。在詳情的“最小膝蓋彎曲角度（度）”中設定彎曲角度。“啟用虛擬化身專屬修正”僅在存在對應修正資料時可用。與手腳自動調整重疊的修正可能無法並用。

## 原始姿勢、自訂動作與預設

這些項目在“虛擬化身設定”中設定。

- “使用虛擬化身原有的站立、蹲下和俯臥姿勢”：自動匯入虛擬化身原本設定的姿勢。
- “使用自訂動作”：開啟匯入設定，為站立、蹲下（Crouching）、俯臥（Prone）等各類型分別指定動作。原則上每種類型設定一個動作。
- “與其他工具整合追蹤鎖定”：與其他功能元件並用時，若固定功能無法正常工作，可啟用此項。

自行指定動作的匯入設定，與自動匯入原始姿勢的設定是兩個獨立功能。

預設位於頁籤最下方。可依名稱搜尋，並通過“套用此預設”切換姿勢設定。預設主要用於初次安裝時的設定，會替換當前設定；如果已有調整內容，請儲存後再切換。

顯示預設清單時，僅載入名稱和適用虛擬化身等資訊；套用所選預設時才載入調整動畫。即使首次建立清單，也不會預先載入所有虛擬化身的動畫。

清單分為“適用於虛擬化身”“使用者預設”“Unisaki Studio官方預設”。“隱藏內建預設”是同一專案共用的顯示設定。新增、編輯或刪除預設後，清單會更新。如果顯示未變化，請按一下“重新載入”。

## 預先建置與警告

啟用“使用虛擬化身原有的站立、蹲下和俯臥姿勢”後，每次產生時都會從虛擬化身的Base檢測動作。檢測結果不會寫回手動匯入設定，因此僅使用自動匯入時，清單會保持未指定狀態。Base中的動作變化和自動匯入的開關會在下次產生時生效。

上傳時的自動匯入會套用於建置用副本，不會改寫場景中的原始物件、匯入設定或匯入來源的Controller和動作。如果已有預先建置且輸入未變化，會重複使用其結果。

某一類型存在手動指定時，優先使用手動設定，並套用旋轉、調整動畫和播放位置指定。關閉“使用”或移除已指定動作的設定，會停止該類型的自動匯入。通過“清除手動指定”移除該類型的設定和調整後，如果自動匯入已啟用，下次產生時會重新檢測。此操作可通過Undo撤銷。同一類型存在多個舊設定時，優先使用Inspector中選取的有效設定。

舊版自動匯入新增到清單中的設定，無法與手動註冊或已經調整過的設定區分，因此不會自動刪除。請僅對需要恢復自動匯入的類型使用“清除手動指定”。同一虛擬化身安裝多個產品時，其他產品中的手動設定也會套用於共用的原始姿勢。

預先建置通過重複使用已產生的資料，縮短虛擬化身的建置時間。可通過“更新預先建置”建立或更新。一般虛擬化身建置也會產生所需資料，因此不必每次都手動執行預先建置。

更改設定後，會進入需要更新的狀態，並通過Inspector頂部的“檢查設定”和Hierarchy標記提示。更改姿勢或IK設定後，更新預先建置可減少後續建置時間。

“警告顯示設定”位於“檢查設定”區域內，可按警告類型隱藏提示，也可隱藏Hierarchy標記。隱藏提示並不意味著設定問題已解決或產生資料已更新。錯誤和必要的產生處理仍然保留。

## 使用注意事項

- 適用於3點追蹤和桌面模式，不支援全身追蹤期間的姿勢固定。
- 根據體型和修改內容，手腳接地及服裝效果可能需要額外調整。
- 與特殊Base層或其他姿勢切換元件組合時，可能無法按預期工作。
- 拍照模式的移動、旋轉和地面高度，會修正工具姿勢以及未選擇工具姿勢時的預設和自訂動作。VRChat中替換後的預設動作及視點表現，請在實際用戶端中確認。
