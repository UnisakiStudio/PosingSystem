# 更新紀錄

## [3.2.0] - 尚未發佈

### 新增

- Inspector、編輯操作、安裝對話框、標準姿勢名和產生的VRChat選單現支援30種顯示語言。
- 統一了Inspector和遊戲內選單的語言選擇。初始使用電腦語言，同一OS使用者的其他專案也會使用最後的選擇。
- 支援以所選語言開啟README、更新紀錄和離線使用說明。
- 依照現有術語，補齊了128個標準姿勢的顯示名和各功能說明。

### 相容性

- 保留虛擬化身的現有設定、自訂名稱、資源參照、參數識別碼和授權儲存方式。

## [3.1.4] - 2026-11-11

- 修復了為虛擬化身指定的專用蹲下、俯臥動畫未生效，反而使用VRChat預設姿勢的問題。自動匯入和手動指定均已修復。
- 修復了編輯或預覽姿勢時，透過MA Bone Proxy安裝的頭髮、眼鏡等仍留在原位的問題。現在會跟隨預覽姿勢，同時保持原虛擬化身的設定和擺放不變。
- 修復了拍攝「仰向け寝_お疲れ」等姿勢縮圖時，利用視點位置進行姿勢校正失敗的問題。拍攝時會使用已套用建置時姿勢校正和地板調整的動畫。

請在ALCOM / VCC中將Unisaki Posing System更新為3.1.4。Kawaii Posing Tool 3.1.2和Cool Posing Tool 1.1.0可繼續使用。如果先前使用過預先建置，請在更新後按一下「更新預先建置」並儲存場景，然後重新建置、上傳虛擬化身。

## [3.1.3] - 2026-11-09

- 在複製的虛擬化身上執行「更新姿勢縮圖」或預先建置時，不再刪除原虛擬化身的姿勢縮圖。
- 修復了在首次儲存場景前或Prefab編輯介面中執行預先建置後，僅重拍縮圖就顯示「設定已變更」的問題。
- 修復了上次預先建置產生的姿勢資料殘留時，下一次預先建置可能中途停止的問題。
- 減輕了尚無姿勢縮圖時開啟清單的處理負擔。也調整了預先建置或建置開始時，在取得套件資訊完成前阻止Unity操作的處理。
- PC和Android建置時，也會移除虛擬化身中已停用姿勢工具的編輯設定。
- 使用「詢問此錯誤」時，即使Console開頭排列著無法判斷原因的錯誤，也能將後面的診斷編號等加入草稿。若翻身片段設定發生錯誤，草稿也會包含需要檢查的項目。

請在ALCOM / VCC中將Unisaki Posing System更新為3.1.3。Kawaii Posing Tool 3.1.2和Cool Posing Tool 1.1.0可繼續使用。這些產品仍指定較早的共用系統版本，因此更新時可能顯示衝突確認。如果先前使用過預先建置，請在更新後按一下「更新預先建置」，儲存場景，再重新建置、上傳虛擬化身。

## [3.1.2] - 2026-11-09

- 修復了啟用“減輕頭部旋轉造成的姿勢變形”時，從俯臥站起後面部仍保持朝上的問題。
- 即使關閉“腳部高度”，也可通過EX選單的“設定 → 仰臥時自動鎖定頭部”切換頭部固定。在3.1.0、3.1.1中該項目消失的虛擬化身，更新後建置即可恢復。
- 即使在Unity中取消勾選虛擬化身本體，也可執行“更新預先建置”。
- 修復了Assets中殘留舊版共用姿勢Controller時，更新後可能無法產生姿勢的問題。使用者自行編輯的Controller設定也會保留。
- 當工具或其父物件停用，導致無法使用共用姿勢Animator時，會顯示目標名稱。可通過“檢查設定 → 選擇物件”定位。
- 預先建置顯示“設定有更新”時，可通過“詳情 → 查看預先建置後的設定變更”檢查與上次不同的設定。
- 腳本錯誤導致建置停止（PS050）時，最多顯示Unity檢測到的5條原始錯誤。通過“詢問此錯誤”，可查看、編輯並發送包含Unity和相關工具版本及錯誤編號的草稿。

如果使用過預先建置，更新後請按一下“更新預先建置”並儲存場景，然後重新建置、上傳虛擬化身。

## [3.1.1] - 2026-11-08

- 即使關閉“左右鏡像”，已啟用的“地面高度”和“翻身”也會顯示在VRChat EX選單的“設定”中。
- 即使舊版中對姿勢進行了排序、刪除或改名，也能將正確的翻身分別繼承到“伸腿坐”“放鬆”“支起單膝”。完全Unpack後，只要能識別原始姿勢，也能繼承。自訂姿勢、使用者自行關閉的翻身和替換的側躺動作會保留。
- 修復了在VRChat選擇虛擬化身時會瞬間俯臥的問題，也修復了僅選擇俯臥姿勢時，跳躍會瞬間變為仰臥的問題。跳躍切換可通過“功能 → 便利功能 → 跳躍切換躺姿”關閉，預設啟用。
- 更新後，如果共用姿勢Animator Controller的參照丟失，在可恢復時會顯示警告並根據設定重建。多個虛擬化身共用的Controller參照也會保留。
- 專案存在編譯錯誤時，會在建置開始時說明原因並停止。腳本錯誤導致無法檢查參照期間，暫緩自動清理已產生的Controller。
- 即使專案中存在與商品同名的Prefab，新增工具時也會優先使用正式Prefab。共用Controller僅換行符不同時，也可繼續預先建置。
- 姿勢工具新增的FX層（如地面高度）的Write Defaults現會遵循虛擬化身一側的設定。

如果使用過預先建置，更新後請在場景中的工具上按一下“更新預先建置”並儲存場景，然後重新建置、上傳虛擬化身。

## [3.1.0] - 2026-11-07

- 支援根據體型調整適用姿勢手腳的自動調整（IK）、虛擬化身專屬修正及防止膝蓋反折。
- 拍照模式可調整虛擬化身的位置和朝向，也可選擇同步位置、朝向，以及拍照時顯示自己的頭部。
- “地面高度”可上下移動整個身體，最大距離為3m，可與“腳部高度”分別使用。
- 新增呼吸動作、關閉預設待機搖擺，以及減輕頭部朝向導致姿勢變形的設定。
- 可在Inspector查看啟用的功能和參數用量，並支援姿勢搜尋、批次加入、排序及Scene簡易預覽。
- 加快桌面模式中站立、半蹲和坐姿的切換。
- 改善更改設定後的預先建置警告、Inspector滾動負擔，以及清理產生資源時的長時間停頓。
- 修復了自動匯入啟用時，未更改設定的預先建置仍出現更新警告，且上傳時重新產生的問題。匯入結果會套用於產生用虛擬化身，不改動原始物件的匯入設定。
- 新增根據頭部傾斜翻身，以及為各姿勢指定對應動作的設定。
- 改善舊預設翻身設定的繼承、自訂動作匯入及產生資源管理。

## [3.1.0-beta.2] - 公開測試版（2026-11-05）

- 在IK的“位置長度基準”中，新增固定長度，以及Head到Viewpoint的高度差（Y）和前後差（Z）。
- 除Inspector外，也在Hierarchy物件名左側顯示警告。除未執行預先建置和設定變化外，也支援動作匯入或預設操作當前顯示的警告。
- 修復了開啟場景等時自動清理產生資源，會載入其他場景產生的Controller並導致Unity長時間停頓的問題。
- 修復了修改姿勢清單或功能時預先建置歷史丟失的問題。現會顯示“預先建置後設定已變更”，而非“未執行”，Hierarchy也會顯示需要更新的警告。
- 共用Inspector和Hierarchy顯示使用的預先建置比較結果，在設定和參照資源未變化時減少滾動負擔。建置時仍會像以前一樣每次進行比較。

## [3.1.0-beta.1] - 公開測試版（2026-11-04）

- 將桌面模式的一般姿勢切換改為1次求值方式。一般建置和預先建置均啟用，VR及特殊條件下保留原有流程。
- 將alpha.3及更早版本的預先建置識別為需要更新。
- 拍照期間改變地面高度時保持視點，並在結束拍照後恢復至最新地面高度。

- 將自動匯入改為僅在產生時檢測，預先建置和建置不會再新增或更改手動匯入設定。
- 自動匯入開關、Base變化和清除手動設定會觸發重新產生。保留多個產品共用的手動指定和調整，並將舊匯入動作恢復為預設姿勢。
- 按場景GUID和各虛擬化身，將預先建置產生的Controller管理為一個檔案。更新前會拆分複製物件、不同場景或Prefab共用的參照。
- 建置時使用NDMF的臨時資源管理，不增加編輯用產生檔案。
- 開啟和儲存場景時檢查產生資源。存在未儲存編輯、Undo/Redo或外部參照時會保留，僅將歸屬明確且未使用的檔案移至資源回收筒。
- 套用匯入動作的旋轉、調整動畫和播放位置指定。將旋轉、RootT/RootQ及Humanoid調整處理與一般姿勢統一。
- 對巢狀BlendTree的調整會複製為匯入目標專用，保留原始動作和行走用混合設定。
- “僅站立”的播放位置指定會按原始影格率展開為靜態姿勢，不停止行走一側的播放。

## [3.1.0-alpha.2] - 封閉測試版（2026-10-26）

### 修復與更改

- 對未選擇工具姿勢時的預設和自訂動作，也套用拍照模式與地面高度修正。
- 將地面高度擴充為上下3m。50%為原始高度及初始值，0%為向下3m，100%為向上3m。
- 修復了“僅站立”覆蓋會修改匯入來源BlendTree的問題。
- 沒有IK規則的姿勢使用手動修正，並減少不必要的產生警告。
- 修復了同名姿勢調整草稿混淆，以及未檢測到同一資源內動作更改的問題。
- 修復了無效初始姿勢的編號導致其他姿勢被初始選取的問題。
- 匯入不支援的AnimatorOverrideController時，顯示說明而非拋出異常。
- 套用舊預設時，保留明確關閉的翻身設定。
- 改善了淺色Editor主題下功能圖示的可辨識性。

VRChat用戶端中的視點和預設動作替換後的驗證仍在進行。

## [3.1.0-alpha.1] - 發佈前

### 新增

- 新增各功能開關和ExpressionParameters用量顯示。
- 新增可將虛擬化身向前移動和旋轉的拍照模式。
- 新增拍照模式同步選擇。僅本機顯示為0 bit，同步時為16 bit。
- 新增拍照模式中保持自身虛擬化身頭部可見的設定。
- 新增“地面高度”，可將包含頭部的整個身體上下移動3m。50%為原始高度及初始值，0%為向下3m，100%為向上3m。
- 新增根據頭部傾斜翻身及各姿勢的對應動畫設定。
- 新增呼吸動作及弱、中、強、急、自訂設定。
- 新增分別選擇呼吸動作和遊戲內開關選單的設定。僅動作使用0 bit，開關同步使用1 bit。
- 新增關閉VRChat預設待機動作搖擺的設定。
- 新增減輕頭部朝向不同造成姿勢變形的設定。
- 新增根據體型調整適用姿勢手腳的自動調整（IK），並提供虛擬化身整體及各姿勢的開關。
- 新增“將IK烘焙至調整中”，將IK結果儲存為調整動畫。
- 新增虛擬化身專屬姿勢修正、防止膝蓋反折及最小彎曲角度設定。
- 新增從姿勢清單在Scene中查看姿勢的簡易預覽。
- 新增姿勢分類頁籤、跨分類搜尋、多個動畫批次加入及指定移動後的順序。
- 新增在Inspector中顯示商品與共用系統更新紀錄的功能。

### 更改

- 加快預設載入，縮短新增工具和顯示預設清單時的等待時間。
- 新增、編輯和刪除預設後，清單現會自動更新。
- 將Inspector整理為“功能”“姿勢”“虛擬化身設定”3個頁籤。
- 為設定項目新增說明和圖示，並統一詳細設定的展開與折疊顯示。
- 將呼吸詳情移至功能設定內，將預設移至虛擬化身設定末尾。
- 將自訂動作的單獨指定與虛擬化身原始姿勢的自動匯入整理為獨立設定。
- 減少腳部高度調整所產生全身動畫的重複。
- 將姿勢圖片更新改為帶確認對話框的按鈕。
- 將警告顯示設定集中到“檢查設定”中。
- 取消8bit專用Prefab的新建入口，統一為一般Prefab中的功能選擇。保留現有參照。
- 將VRChat Avatars SDK的最低版本改為3.10.4。

### 修復

- 將未選擇工具姿勢時的預設和自訂動作也納入拍照模式及地面高度的修正範圍。
- 修復了“僅站立”覆蓋時改動匯入來源BlendTree的問題。
- 沒有有效IK規則的姿勢使用手動調整，減少不必要的IK產生警告。
- 修復了同名姿勢調整內容混合，以及同一資源內替換動作未觸發重新產生的問題。
- 即使已停用初始姿勢的編號被其他姿勢重複使用，也不會再被初始選取。
- 匯入原始姿勢時檢測到不支援的AnimatorOverrideController，會顯示說明而非拋出異常。
- 套用舊預設時，保留明確關閉的翻身設定。
- 改善Inspector圖示背景，確保淺色Editor主題下也能辨認功能圖示。

- 修復了向虛擬化身新增工具時，“翻身”“地面高度”“拍照模式”圖示不顯示的問題。
- 修復了套用舊版本預設時，適用姿勢的翻身設定丟失的問題。
- 修復了編輯姿勢名時開啟其他詳情，輸入會轉移到另一姿勢的問題。
- 修復了姿勢排序時詳情關閉的問題，並修正設定更改的Undo、Redo處理。
- 修復了預覽與原始虛擬化身重疊，以及放置位置被重複相加的問題。
- 修復了預覽缺少元件的虛擬化身時報錯的問題。
- 修復了虛擬化身骨骼朝向和縮放差異導致的IK手腳方向及位置偏移。
- 修復了更改設定後，警告和預先建置狀態未立即更新的問題。
- 修復了更改IK設定後仍重複使用舊預先建置結果的問題。
- 修復了某些設定下附加功能產生失敗的建置錯誤。
