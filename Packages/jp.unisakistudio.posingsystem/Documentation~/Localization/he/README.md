# Unisaki Posing System

מערכת התנוחות המשותפת המשמשת את Kawaii Posing, את Cool Posing וכלים נוספים. המערכת משתמשת ב-Modular Avatar וב-NDMF ליצירת התפריטים והאנימציות הדרושים בעת העלאת האווטאר.

README זה מיועד לגרסה v3.2.0 הנמצאת בפיתוח. טרם נקבע תאריך שחרור רשמי. הגרסה המותקנת מופיעה בראש ה-Inspector של כלי התנוחות. ראו גם [תכונות חדשות ויומן שינויים](CHANGELOG.md).

## שפת התצוגה ותיעוד לא מקוון

בחרו שפת תצוגה באמצעות Language / 言語 בראש ה-Inspector. בחירה אחת חלה גם על ה-Inspector וגם על תפריט VRChat שנוצר. כדי לשנות את השפה בתוך המשחק, יש להעלות את האווטאר מחדש.

ללא בחירה שמורה, נעשה שימוש בשפת המחשב ובאנגלית כאשר השפה אינה נתמכת. התכונה פועלת ב-Windows, ב-macOS וב-Linux. הבחירה האחרונה נשמרת ב-EditorPrefs ומשמשת גם פרויקטים אחרים של אותו משתמש במערכת ההפעלה במחשב זה. בחירה מפורשת שכבר נשמרה באווטאר נשמרת. ההעדפה אינה מסתנכרנת למחשבים אחרים. אחסון הרישיונות אינו משתנה.

אפשר לבחור README, יומן שינויים ומדריך מתוך [רשימת השפות](../index.html) הכלולה. גם המדריך ויומן השינויים שב-Inspector נפתחים בשפה שנבחרה. ההסכמים המקוריים ותרגומי העזר נשארים מסמכים נפרדים.

## החלפת יציבה במצב שולחן עבודה

קוצרה ההשהיה עד להחלת התנוחה שנבחרה בעת מעבר בין עמידה, כריעה וישיבה במצב שולחן עבודה. השיפור חל בבנייה רגילה ובחישוב מקדים, ללא פקודה או הגדרה נוספת. במצב VR ובמצבים מיוחדים נשמר העיבוד הקיים. יש לעדכן נתוני חישוב מקדים ישנים לפני ההעלאה.

## התקנה ועדכון

פעלו לפי קובצי הרכישה והוראות ההתקנה של המוצר והוסיפו את כלי התנוחות באמצעות VCC או ALCOM. מערכת זו מותקנת כתלות של כלי התנוחות.

דרישות גרסה v3.2.0:

- פרויקט אווטאר של VRChat ב-Unity 2022.3
- VRChat Avatars SDK בגרסה 3.10.4 ומעלה
- Modular Avatar מסדרת 1.x, בגרסה 1.15.1 ומעלה
- NDMF (Non-Destructive Modular Framework) מסדרת 1.x, בגרסה 1.14.0 ומעלה

משתמשי Kawaii Posing צריכים לעדכן את המוצר ל-3.2.0 ב-ALCOM / VCC ולוודא שגם Unisaki Posing System עודכן ל-3.2.0. אם השתמשתם בחישוב מקדים, לחצו על עדכון חישוב מקדים ושמרו את הסצנה לפני העלאת האווטאר.

Cool Posing 1.2.0 משתמש במערכת המשותפת 3.2.0. עדכנו יחד את המוצר והמערכת המשותפת לגרסאות תואמות.

### למשתמשי מהדורת 8bit

הוספת התקנות חדשות אוחדה לשימוש ב-Prefab הרגיל. אפשר לכבות פריטים מיותרים בתכונות כדי לצמצם את השימוש בפרמטרים. בחירת תנוחה בלבד משתמשת בבסיס של 8 bit.

קובצי ה-Prefab הישנים של מהדורת 8bit נשארים בתיקיית Editor/Legacy של כל מוצר כדי לשמור הפניות מאווטארים ומתצורות מוכנות קיימות. אין צורך למחוק או להחליף Prefab כדי להמשיך להשתמש במהדורה קיימת. האפשרות לבחור את מהדורת 8bit מהתפריט להוספה חדשה ב-Unity הוסרה.

## מבנה מסך ההגדרות

ב-Hierarchy בחרו את אובייקט הכלי בתוך האווטאר, למשל 可愛いポーズ או カッコいいポーズ, כדי לשנות את הגדרותיו.

| כרטיסייה | מה מגדירים |
| --- | --- |
| תכונות | פריטים לתפריט המשחק, תכונות שימושיות, סמלים ושימוש ב-ExpressionParameters |
| תנוחות | בחירה, הוספה וסידור של תנוחות, תצוגה מקדימה ב-Scene, פרטים והתאמת אנימציה |
| הגדרת אווטאר | תיקונים למבנה הגוף, תיקון ברכיים, ייבוא תנוחות מקוריות ותנועות אישיות ותצורות מוכנות |

בפריט שיש לו הגדרות מפורטות, לחצו על פתיחת הגדרות כדי לפרוס אותן מתחתיו. גם הגדרות הנשימה נמצאות בתכונות.

באמצעות עזרה / שינויים בראש המסך אפשר לפתוח את המדריך, התמיכה ויומן השינויים. ביומן אפשר לעבור בין המוצר לבין Unisaki Posing System.

## תכונות ושימוש ב-ExpressionParameters

הפריטים שנבחרו בתכונות > תכונות תפריט מופיעים בתפריט המשחק. לדוגמה, הפעלת שיקוף מוסיפה אפשרות להחליף שיקוף ב-VRChat. סימון האפשרות ב-Inspector אינו משאיר את כל התנוחות משוקפות תמיד.

| תכונה | תוספת שימוש ב-bit |
| --- | ---: |
| שיקוף | 1 bit |
| ללא מחוות | 1 bit |
| אנימציית נשימה | 0 bit |
| נשימה: הפעלה וכיבוי במשחק | 1 bit |
| גובה כפות רגליים | 8 bit |
| גובה רצפה | 8 bit |
| מצב צילום: תצוגה מקומית בלבד | 0 bit |
| סנכרון מצב צילום | 16 bit |
| השארת הראש גלוי במצב צילום | 0 bit |
| השבתת תנודות עמידה רגילות של VRChat | 0 bit |
| צמצום עיוות תנוחה מסיבוב הראש | 1 bit משותף להתהפכות |
| התהפכות | 10 bit, כולל 1 bit משותף לצמצום עיוות התנוחה |

התהפכות משתמשת ב-1 bit להפעלה וכיבוי, ב-8 bit להטיית הראש וב-1 bit לנעילת הראש. אם צמצום עיוות התנוחה כבר מופעל, הוספת התהפכות מוסיפה רק 9 bit. החלק המשותף נספר פעם אחת, והתצוגה מתעדכנת עם שינוי הסימונים.

הסכום המוצג מתייחס לכלי התנוחות המותקנים באווטאר, ולא לסכום הכולל של האווטאר עם בגדים וגימיקים נוספים. הגדרות משותפות אינן נספרות פעמיים גם בשימוש בכמה כלי תנוחות. אם מספר התנוחות חורג מטווח המספור הבסיסי, בחירת התנוחה עשויה לדרוש סיביות נוספות.

### גובה כפות רגליים וגובה רצפה

- גובה כפות רגליים משנה את גובה הצד של הרגליים תוך שמירת מיקום הראש. השתמשו בו כדי ליישר את הרגליים עם הרצפה או המיטה.
- גובה רצפה מזיז את הגוף כולו, כולל הראש, למעלה ולמטה. 50% הוא הגובה המקורי, 0% הוא 3m מתחתיו ו-100% הוא 3m מעליו. ברירת המחדל היא 50%.

שתי האפשרויות נמצאות בהגדרות במשחק; גובה רצפה מופיע אחרי גובה כפות רגליים. הזזת גובה רצפה מהמרכז מזיזה את הגוף אנכית, והחזרה לקרבת 50% מחזירה לגובה המקורי ומסיימת את התיקון. אין מתג ציפה נפרד. תיקון נקודת המבט נעשה בתחילת הציפה ובמהלך שינוי גובה הרצפה.

באנימציות רגילות, התאמת גובה כפות הרגליים אינה משכפלת עוד תנועות גוף מלאות כדי לשנות גובה. כך מצטמצמים נתוני האנימציה שנוצרים, אך גודל האווטאר כולו אינו מצטמצם תמיד לשליש.

### מצב צילום

1. הפעילו תכונות > תכונות תפריט > מצב צילום.
2. ב-VRChat פתחו מצב צילום ובחרו תנוחה באמצעות בחירת תנוחה.
3. מרחק מזיז את האווטאר עד 3m קדימה, וכיוון מסובב אותו. כשהמרחק גדול מ-0 האווטאר פונה אליכם.
4. הפעילו נעילת רגליים לפי הצורך. היא אינה נכפית בתחילת המצב, ולכן אפשר לכוון מיקום לפני הנעילה. אם הוספתם ללא מחוות לתפריט, אפשר גם לשנות את צורת היד באותו מסך.
5. סיום צילום מאפס את המרחק והכיוון ומשחרר את נעילת הרגליים.

התנועה והסיבוב במצב צילום משתמשים ב-0 bit כשהם מוצגים רק אצלכם. כדי שאחרים יראו את המיקום והכיוון, הפעילו תכונות שימושיות > סנכרון מצב צילום. המרחק והכיוון יחד משתמשים ב-16 bit.

אם ראש האווטאר שלכם נעלם בקרבתכם, הפעילו תכונות שימושיות > השארת הראש גלוי במצב צילום. האפשרות חלה רק על התצוגה שלכם במהלך הצילום, ובסיומו חוזרת התצוגה הרגילה.

### החלפת תנוחת שכיבה בקפיצה

כאשר נבחרו גם שכיבה על הגב וגם שכיבה על הבטן, קפיצה במקום מחליפה ביניהן. אם נבחרה רק אחת, היא נשמרת. כדי לבטל החלפה בקפיצה, כבו ב-Unity את החלפת תנוחת שכיבה בקפיצה תחת תכונות > תכונות שימושיות. תוספת השימוש בפרמטרים מסונכרנים היא 0 bit. באווטאר עם כמה כלי תנוחות, כיבוי בכלי אחד חל על האווטאר כולו.

### התהפכות

בתנוחות שכיבה נתמכות, הטיית הראש לצדדים גורמת להתהפכות חלקה של הגוף. התמיכה אינה מתווספת אוטומטית לכל תנוחת שכיבה.

1. הפעילו תכונות > תכונות תפריט > התהפכות.
2. בתנוחות פתחו את פרטי תנוחת השכיבה והפעילו הפעלת התהפכות.
3. הקצו אנימציית שכיבה על הצד לתנוחת צד להתהפכות. התנוחה המקורית ותנוחת הצד משמשות ליצירת התהפכות לשני הכיוונים. התאימו את עוצמת תיקון מגע ברצפה לפי הצורך.
4. ב-VRChat בחרו תנוחה נתמכת והפעילו התהפכות. השתמשו בה כשנעילת הראש משוחררת.

בתנוחה שמשתמשת בהתהפכות, הטיית הראש קובעת את מיקום הניגון באנימציה ולכן הגדרות MotionTime הרגילות אינן זמינות. כדי להשתמש באנימציית התהפכות מלאה שהכנתם, הקצו אותה בשדה האנימציה הרגיל והשאירו את תנוחת צד להתהפכות ריקה. באנימציה זו מיקום ניגון 0 הוא צד שמאל, 0.5 הוא שכיבה על הגב ו-1 הוא צד ימין.

### נשימה ותנודות עמידה רגילות

תכונות > תכונות שימושיות > אנימציית נשימה מוסיפה תנועה לחזה ולאזורים נוספים בהתאם לנשימה. בפתיחת הגדרות אפשר לבחור לכל סוג יציבה: ללא, חלש, בינוני, חזק, מהיר או מותאם אישית. מהיר משתמש בקצב נשימה מהיר יותר; במותאם אישית אפשר להקצות אנימציית נשימה משלכם.

תנועת הנשימה לבדה משתמשת ב-0 bit. כדי לעצור ולחדש נשימה ב-VRChat, הפעילו גם תכונות תפריט > נשימה. סנכרון ההפעלה והכיבוי משתמש ב-1 bit. שינוי העוצמה אינו מגדיל את מספר הסיביות.

הצוואר, הכתפיים והזרועות נעים עם החזה כדי לצמצם תזוזה של הראש והידיים. המיקום אינו קבוע לחלוטין, ולכן יש לבחור עוצמה המתאימה למבנה הגוף ולתנוחה.

תכונות שימושיות > השבתת תנודות עמידה רגילות של VRChat מצמצמת את תנודות הגוף שמוסיף VRChat בזמן עמידה במנוחה. ברירת המחדל היא כבוי, ואנימציית הנשימה של הכלי ותנועות אישיות אחרות נשמרות. אפשר להפעיל את האפשרות גם ללא נשימה והיא אינה מוסיפה סיביות. היא אינה עוצרת תנודות שמקורן אינו אנימציית העמידה הרגילה.

כשמשתמשים בכמה כלי תנוחות, הפעלת השבתת תנודות העמידה בכלי אחד חלה על האווטאר כולו. כדי להחזירן, כבו את ההגדרה בכל הכלים והעלו מחדש.

### צמצום עיוות תנוחה מסיבוב הראש

השתמשו באפשרות כאשר שחרור נעילת הראש מעוות את התנוחה בגלל הבדל בכיוון הצוואר לעומת המקור. היא נמצאת בתכונות > תכונות שימושיות ואינה מוסיפה תפריט ייעודי במשחק. בזמן נעילת הראש משתמשים בכיוון המקורי. שכיבה על הגב אינה מתוקנת כדי לשמור את הכיוון המקורי כלפי מעלה.

### תמונות סמלי התפריט

- יצירת סמלי תנוחות יוצרת תמונות של האווטאר בכל תנוחה ומציגה אותן בתפריט. כך קל יותר לזהות תנוחות, אך יצירת התמונות מאריכה את הבנייה.
- הקטנת נפח סמלים מורידה את רזולוציית התמונות כדי לצמצם את גודל האווטאר.

בבנייה ל-Android לא נוצרים סמלי תנוחות. לאחר שינוי בגדים או מראה השתמשו בצילום סמלים מחדש. תמונות רשימת התנוחות מתעדכנות באמצעות עדכון תמונות התנוחות. פעולות אלה אורכות זמן; קראו את חלון האישור לפני הפעלתן.

## הוספה, סידור ותצוגה מקדימה של תנוחות

בחרו סוג יציבה בצד רשימת התנוחות. כרטיסיית זכוכית המגדלת בראש הרשימה מחפשת שמות בין כל הקטגוריות. פתיחת פרטים מרכזת את האנימציה, הסמל, MotionTime והגדרות נוספות.

להוספת כמה אנימציות, גררו אותן לאזור ההוספה או בחרו אותן ב-Project ולחצו על ייבוא קליפים שנבחרו ב-Project. כפילויות של אותו קליפ מסוננות.

לשינוי הסדר, בחרו יעד בפרטים > סדר. אפשר להשתמש גם בכפתורי מעלה ומטה. ההעברה שומרת אם פרטי התנוחה פתוחים או סגורים.

תצוגה מקדימה של תנוחה מציגה אותה ב-Scene בלי לפתוח את חלון ההתאמה. סיומה מחזיר את התצוגה המקורית. היא אינה מריצה בנייה של MA או NDMF ולכן עשויה להיות שונה מהבגדים או מתוצאת FloorAdjuster המשולבים בזמן בנייה. בדקו גם את הבגדים הסופיים והמגע ברצפה אחרי בניית האווטאר.

## התאמת אנימציה והתאמה אוטומטית של גפיים (IK)

פתחו התאמת אנימציה בתנוחות כדי לכוון את הגוף והגפיים תוך תצוגה מקדימה. בסיום שמרו את אנימציית ההתאמה באמצעות פעולת השמירה בחלון.

במוצרים ובתנוחות נתמכים, ההתאמה האוטומטית מתאימה את מיקום הגפיים למבנה גוף האווטאר. הפעלת התאמה אוטומטית של גפיים בחלון התאמת האנימציה שולטת בהפעלה הכללית, והפעלת IK לתנוחה הזאת שולטת בתנוחה יחידה. בתנוחות שאין להן התאמה אוטומטית מוצגת הודעה על כך.

כדי לסיים ידנית את התוצאה האוטומטית, לחצו על הטמעת IK בהתאמות. התוצאה הנוכחית נכתבת לאנימציית התאמה חדשה ו-IK נכבה לתנוחה הזאת באווטאר הזה. אנימציית המקור נשמרת. הכפתור זמין כשההתאמה האוטומטית הכללית והפרטנית מופעלות וקיימות הגדרות IK שאפשר להחיל.

בהגדרת אווטאר, מניעת כיפוף ברכיים לאחור מפעילה את תיקון הברכיים. בפרטים מגדירים כיפוף ברך מזערי (מעלות). הפעלת תיקון ייחודי לאווטאר זמינה רק כשקיימים נתוני תיקון מתאימים. ייתכן שלא ניתן לשלב תיקונים החופפים להתאמה האוטומטית של הגפיים.

## תנוחות מקוריות, תנועות אישיות ותצורות מוכנות

האפשרויות האלה נמצאות בהגדרת אווטאר.

- שימוש בתנוחות העמידה, הכריעה והשכיבה על הבטן המקוריות מייבא אוטומטית את התנוחות שהוגדרו באווטאר מלכתחילה.
- שימוש בתנועות שלכם פותח הגדרות ייבוא להקצאת תנועה לכל סוג, למשל עמידה, Crouching או Prone. בדרך כלל מקצים תנועה אחת לכל סוג.
- שילוב נעילות מעקב עם כלים אחרים מיועד למקרים שבהם הנעילות אינן פועלות היטב לצד גימיקים אחרים.

הקצאה ידנית של תנועות בהגדרות הייבוא היא תכונה נפרדת מייבוא אוטומטי של התנוחות המקוריות.

התצורות המוכנות נמצאות בתחתית הכרטיסייה. חפשו לפי שם ולחצו על החלת התצורה המוכנה הזאת כדי להחליף את הגדרות התנוחות. תצורה מוכנה משמשת בעיקר כנקודת התחלה להתקנה ומחליפה את ההגדרות הנוכחיות; שמרו התאמות קיימות לפני המעבר.

הצגת רשימת התצורות המוכנות טוענת רק שמות ומידע על אווטארים נתמכים. אנימציות ההתאמה נטענות כשמחילים את התצורה שנבחרה. גם ביצירת הרשימה הראשונה לא נטענות מראש אנימציות לכל האווטארים.

הרשימה מחולקת למתאים לאווטאר, תצורות מוכנות של משתמשים ותצורות מוכנות רשמיות של Unisaki Studio. הסתרת תצורות מוכנות כלולות היא העדפת תצוגה משותפת בפרויקט. הוספה, עריכה או מחיקה מעדכנות את הרשימה. לחצו על טעינה מחדש אם התצוגה לא השתנתה.

## חישוב מקדים ואזהרות

כאשר שימוש בתנוחות העמידה, הכריעה והשכיבה על הבטן המקוריות מופעל, התנועות מזוהות מה-Base של האווטאר בכל יצירה. התוצאה אינה נכתבת להגדרות הייבוא הידניות, ולכן סוג שמיובא אוטומטית בלבד נשאר ללא הקצאה ברשימה. שינוי תנועות ה-Base או מצב הייבוא האוטומטי חל ביצירה הבאה.

ייבוא אוטומטי בזמן העלאה חל על עותק הבנייה. הוא אינו משנה את אובייקט המקור בסצנה, הגדרות הייבוא, ה-Controller או התנועות המקוריים. תוצאת חישוב מקדים קיימת ממוחזרת כשהקלט לא השתנה.

אם לסוג תנועה יש הקצאה ידנית, היא מקבלת עדיפות, כולל סיבוב, אנימציית התאמה ומיקום ניגון. כיבוי שימוש או הסרת תנועה שהוקצתה עוצרים את הייבוא האוטומטי לסוג הזה. ניקוי בחירה ידנית מסיר את ההגדרות וההתאמות לסוג; אם הייבוא האוטומטי מופעל, הוא מזוהה מחדש ביצירה הבאה. אפשר לבטל באמצעות Undo. כשיש כמה הגדרות ישנות לאותו סוג, ההגדרה התקינה שנבחרה ב-Inspector מקבלת עדיפות.

הגדרות שנוספו לרשימה בייבוא אוטומטי ישן אינן ניתנות להבחנה מהגדרות שנרשמו או הותאמו ידנית, ולכן אינן נמחקות אוטומטית. השתמשו בניקוי בחירה ידנית רק לסוגים שתרצו להחזיר לייבוא אוטומטי. כשכמה מוצרים מותקנים באותו אווטאר, גם ההקצאות הידניות במוצרים האחרים משפיעות על התנוחות המקוריות המשותפות.

חישוב מקדים ממחזר נתונים שנוצרו כדי לקצר את בניית האווטאר. יוצרים או מעדכנים אותם באמצעות עדכון חישוב מקדים. גם בנייה רגילה יוצרת את הנתונים הדרושים, ולכן אין צורך להפעיל חישוב מקדים ידנית בכל פעם.

שינוי הגדרות מסמן שנדרש עדכון חישוב מקדים. בדיקת הגדרות בראש ה-Inspector וסימונים ב-Hierarchy מודיעים על כך. עדכון חישוב מקדים לאחר שינוי תנוחות או IK מקצר את הבניות הבאות.

הגדרות הצגת אזהרות נמצאות בתוך בדיקת הגדרות. אפשר להסתיר סוגי אזהרות או את הסימונים ב-Hierarchy. ההסתרה אינה פותרת בעיית הגדרה ואינה מעדכנת נתונים שנוצרו. שגיאות ותהליכי יצירה נחוצים נשארים בתוקף.

## הערות לשימוש

- הכלי מיועד למעקב של שלוש נקודות ולמצב שולחן עבודה. נעילת תנוחות בזמן מעקב גוף מלא אינה נתמכת.
- מבנה הגוף ושינויים באווטאר עשויים לדרוש התאמות נוספות למגע הגפיים או למראה הבגדים.
- שכבות Base מיוחדות או גימיקים אחרים לשינוי תנוחות עלולים למנוע את הפעולה הרצויה.
- תנועה וסיבוב במצב צילום וגובה רצפה מתקנים גם תנוחות של הכלי וגם תנועות רגילות ואישיות כאשר לא נבחרה תנוחה. בדקו בלקוח VRChat את נקודת המבט והתנועות הרגילות שהוחלפו.
