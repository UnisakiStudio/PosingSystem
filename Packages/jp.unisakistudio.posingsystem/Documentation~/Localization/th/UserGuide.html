Unisaki Posing System 3.2.0 — คู่มือภาษาไทย

Unisaki Posing System เป็นระบบหลักร่วมของ Kawaii Posing, Cool Posing และเครื่องมือที่เกี่ยวข้อง ติดตั้งสินค้าที่ซื้อพร้อมระบบหลักนี้ผ่าน VCC หรือ ALCOM ใช้ Unity 2022.3, VRChat Avatars SDK 3.10.4+, Modular Avatar 1.15.1+ และ NDMF 1.14.0+

ภาษา

เลือก Language / 言語 ด้านบนของ Inspector เครื่องมือ ตัวเลือกเดียวควบคุม Inspector และเมนู VRChat ที่สร้าง ให้อัปโหลดอวาตาร์ใหม่หลังเปลี่ยนภาษา ตัวเลือกล่าสุดจะจดจำสำหรับโปรเจกต์อื่นของผู้ใช้ OS เดียวกันบนคอมพิวเตอร์นี้ หากไม่มีค่าที่บันทึกไว้ จะใช้ภาษา OS และใช้ภาษาอังกฤษเมื่อไม่รองรับ เครื่องมือโพสท่าทั้งหมดและอวาตาร์ทุกตัวใช้ภาษาเดียวกัน การเปลี่ยนภาษาใน Inspector ของเครื่องมือใดก็ตามจะอัปเดตค่าที่ใช้ร่วมกัน โดยไม่ใช้ตัวเลือกภาษาเฉพาะอวาตาร์ ความชอบภาษาไม่ซิงค์ไปคอมพิวเตอร์อื่น ปุ่มภาษาจะแสดงเฉพาะในการยืนยันการติดตั้งครั้งแรกเมื่อยังไม่ได้บันทึกภาษา หลังจากนั้นให้เปลี่ยนภาษาใน Inspector

ตั้งค่าอวาตาร์

เลือกอวาตาร์ในซีนที่มี VRC Avatar Descriptor ใน Hierarchy แล้วเลือก Unisaki Studio > เพิ่ม Kawaii Posing หรือ เพิ่ม Cool Posing ใช้พรีเซ็ตที่ตรงกับอวาตาร์หากมีให้ Inspector มีแท็บ ฟังก์ชัน, ท่า และ ตั้งค่าอวาตาร์ เลือกท่าและตัวควบคุมเสริม ปรับให้พอดี แล้วอัปโหลดตามปกติ หากใช้ข้อมูลพรีบิลด์ที่เก็บไว้ ให้ใช้ อัปเดตพรีบิลด์ หลังเปลี่ยนการตั้งค่า

คู่มือโดยละเอียด

เปิด คู่มือ ใน Inspector ของสินค้าที่ซื้อเพื่ออ่านคู่มือออฟไลน์ตามภาษาที่เลือก Documentation~/UserGuide.en.html ของสินค้าอธิบายการติดตั้ง ปรับให้เข้ากับอวาตาร์ ควบคุมใน VRChat แก้ท่า หน่วยความจำพารามิเตอร์ อัปเดต และแก้ปัญหา ชื่อท่ามาตรฐานแปลเพื่อการแสดง ส่วนชื่อกำหนดเอง ชื่ออวาตาร์ ชื่อไฟล์แอสเซ็ต ชื่อออบเจ็กต์ที่บันทึก และตัวระบุพารามิเตอร์คงสะกดเดิม เลือกได้สามสิบภาษา โดย Inspector กล่องติดตั้ง ชื่อท่ามาตรฐาน และเมนูที่สร้างมีข้อมูลแสดงครบทุกตัวเลือก มีเอกสารออฟไลน์ในทุกภาษาที่เลือกได้

เอกสารอ้างอิงด่วน 30 ภาษา ครอบคลุมคำอธิบายฟังก์ชันและตารางชื่อท่ามาตรฐาน เป็นเอกสารสั้นสำหรับอ้างอิง ใช้สารบัญภาษาเพื่ออ่านเอกสารเต็ม

สิทธิ์ใช้งานและการสนับสนุน

ใช้ตัวติดตั้งที่ดาวน์โหลดจากร้านที่ซื้อสินค้า สิทธิ์ใช้งานสินค้ายังคงเก็บในรีจิสทรีหรือไฟล์รายผู้ใช้ตามเดิม แยกจาก EditorPrefs อ่านข้อตกลงต้นฉบับที่ให้กับแพ็กเกจ ข้อตกลงระบบร่วมภาษาอังกฤษเดิมเป็นคำแปลอ้างอิง และให้ข้อตกลงแต่ละสินค้าแยกไว้ด้วย
