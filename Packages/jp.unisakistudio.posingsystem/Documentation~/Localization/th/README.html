Unisaki Posing System

ระบบท่าร่วมสำหรับ Kawaii Posing Tool, Cool Posing Tool และเครื่องมืออื่น ใช้ Modular Avatar และ NDMF สร้างเมนูและแอนิเมชันที่จำเป็นเมื่ออัปโหลดอวาตาร์

README นี้สำหรับ v3.2.0 ที่อยู่ระหว่างพัฒนา ยังไม่กำหนดวันเผยแพร่อย่างเป็นทางการ ตรวจสอบเวอร์ชันที่ติดตั้งได้ที่ด้านบนของ Inspector ของเครื่องมือท่า ดูฟังก์ชันใหม่และประวัติการอัปเดตด้วย

ภาษาที่แสดงและเอกสารออฟไลน์

เลือกภาษาที่ «Language / 言語» ด้านบนสุดของ Inspector ตัวเลือกเดียวใช้กับทั้ง Inspector และเมนู VRChat ที่สร้างขึ้น ต้องอัปโหลดอวาตาร์ใหม่เพื่อเปลี่ยนภาษาในเกม

หากยังไม่เลือกจะใช้ภาษาของคอมพิวเตอร์ และใช้ภาษาอังกฤษเมื่อไม่รองรับภาษานั้น รองรับ Windows, macOS และ Linux ตัวเลือกล่าสุดจะบันทึกใน EditorPrefs และใช้ในโปรเจกต์อื่นของผู้ใช้ OS เดียวกันบนคอมพิวเตอร์นี้ด้วย เครื่องมือโพสท่าทั้งหมดและอวาตาร์ทุกตัวใช้ภาษาเดียวกัน การเปลี่ยนภาษาใน Inspector ของเครื่องมือใดก็ตามจะอัปเดตค่าที่ใช้ร่วมกัน โดยไม่ใช้ตัวเลือกภาษาเฉพาะอวาตาร์ ไม่ซิงค์ไปยังคอมพิวเตอร์อื่น และไม่เปลี่ยนวิธีเก็บสิทธิ์ใช้งาน ปุ่มภาษาจะแสดงเฉพาะในการยืนยันการติดตั้งครั้งแรกเมื่อยังไม่ได้บันทึกภาษา หลังจากนั้นให้เปลี่ยนภาษาใน Inspector

เลือก README ประวัติการอัปเดต และวิธีใช้ได้จากรายการภาษาที่ให้มา คู่มือและประวัติการอัปเดตใน Inspector ก็เปิดตามภาษาที่เลือกเช่นกัน ข้อตกลงต้นฉบับและคำแปลอ้างอิงยังแยกไว้ต่างหากตามเดิม

การสลับท่าในโหมดเดสก์ท็อป

ลดความล่าช้าก่อนแสดงท่าที่เลือกเมื่อสลับระหว่างยืน ย่อตัว และนั่งในโหมดเดสก์ท็อป ใช้ได้ทั้งบิลด์ปกติและพรีบิลด์โดยไม่ต้องใช้คำสั่งหรือการตั้งค่าเพิ่มเติม โหมด VR และสถานะพิเศษยังใช้กระบวนการเดิม ให้อัปเดตพรีบิลด์เก่าก่อนอัปโหลด

การติดตั้งและอัปเดตเวอร์ชัน

ใช้ไฟล์ที่ซื้อและขั้นตอนติดตั้งของสินค้าแต่ละรายการเพื่อเพิ่มเครื่องมือท่าผ่าน VCC หรือ ALCOM ระบบนี้จะติดตั้งเป็นแพ็กเกจที่เครื่องมือท่าต้องใช้

สภาพแวดล้อมที่ v3.2.0 ต้องใช้:

  • โปรเจกต์อวาตาร์ VRChat ใน Unity 2022.3
  • VRChat Avatars SDK 3.10.4 ขึ้นไป
  • Modular Avatar สาย 1.x เวอร์ชัน 1.15.1 ขึ้นไป
  • NDMF (Non-Destructive Modular Framework) สาย 1.x เวอร์ชัน 1.14.0 ขึ้นไป

หากใช้ Kawaii Posing Tool ให้อัปเดตเป็น 3.2.0 ใน ALCOM / VCC และตรวจสอบว่า Unisaki Posing System เป็น 3.2.0 ด้วย หากเคยใช้พรีบิลด์ ให้กด «อัปเดตพรีบิลด์» บันทึกซีน แล้วอัปโหลดอวาตาร์

Cool Posing Tool 1.2.0 ใช้ระบบร่วม 3.2.0 ให้อัปเดตสินค้าและระบบร่วมเป็นเวอร์ชันที่เข้ากันพร้อมกัน

สำหรับผู้ที่ใช้รุ่น 8bit

การเพิ่มใหม่รวมไว้ที่ Prefab ปกติแล้ว ปิดรายการที่ไม่จำเป็นใน «ฟังก์ชัน» เพื่อลดการใช้พารามิเตอร์ได้ หากใช้เพียงเลือกท่า การใช้งานพื้นฐานคือ 8 bit

Prefab รุ่น 8bit เก่ายังคงอยู่ใน «Editor/Legacy» ของแต่ละสินค้า เพื่อรักษาการอ้างอิงของอวาตาร์และพรีเซ็ตที่มีอยู่ ไม่จำเป็นต้องลบหรือแทนที่ Prefab เพื่อใช้รุ่น 8bit เดิมต่อไป ขั้นตอนเลือกรุ่น 8bit จากเมนูเพิ่มใหม่ของ Unity ถูกยกเลิกแล้ว

อ่านหน้าตั้งค่า

เลือก «可愛いポーズ», «カッコいいポーズ» หรือออบเจ็กต์เครื่องมือภายในอวาตาร์ใน Hierarchy เพื่อตั้งค่า

แท็บสิ่งที่ตั้งค่า
ฟังก์ชันรายการที่เพิ่มในเมนูเกม ฟังก์ชันอำนวยความสะดวก รูปไอคอน และการใช้ ExpressionParameters
ท่าเลือก เพิ่ม และเรียงท่า ดูตัวอย่างใน Scene รายละเอียดรายท่า และปรับแอนิเมชัน
ตั้งค่าอวาตาร์การแก้ไขตามรูปร่างและเข่า นำเข้าท่าเดิมหรือการเคลื่อนไหวของคุณ และพรีเซ็ต

รายการที่มีการตั้งค่าละเอียดสามารถกด «เปิดการตั้งค่า» เพื่อแสดงส่วนตั้งค่าด้านล่าง การตั้งค่าหายใจก็อยู่ใน «ฟังก์ชัน»

เปิดคู่มือ ติดต่อสอบถาม และประวัติการอัปเดตได้จาก «ช่วยเหลือ / ประวัติการอัปเดต» ด้านบน ในประวัติสามารถสลับอ่านระหว่างสินค้าและ Unisaki Posing System ได้

ฟังก์ชันและการใช้ ExpressionParameters

รายการที่เลือกใน «ฟังก์ชัน > ฟังก์ชันเมนู» จะแสดงในเมนูเกม เช่น การเลือก «กลับซ้ายขวา» จะเพิ่มตัวเลือกให้สลับในเกม ไม่ได้หมายความว่าเลือกใน Inspector แล้วทุกท่าจะกลับซ้ายขวาตลอดเวลา

ฟังก์ชันbit ที่ใช้เพิ่ม
กลับซ้ายขวา1 bit
ปิดท่ามือ1 bit
เพิ่มแอนิเมชันหายใจ0 bit
หายใจ (เปิด/ปิดในเกม)1 bit
ความสูงเท้า8 bit
ความสูงพื้น8 bit
โหมดถ่ายภาพ (เฉพาะหน้าจอคุณ)0 bit
ซิงค์โหมดถ่ายภาพ16 bit
แสดงศีรษะในโหมดถ่ายภาพ0 bit
ปิดการโยกตัวเริ่มต้นของ VRChat0 bit
ลดท่าผิดรูปจากการหมุนศีรษะ1 bit (ใช้ร่วมกับพลิกตัว)
พลิกตัว10 bit (ในจำนวนนี้ 1 bit ใช้ร่วมกับการลดท่าผิดรูป)

พลิกตัวใช้ 1 bit สำหรับเปิด/ปิด, 8 bit สำหรับการเอียงศีรษะ และ 1 bit สำหรับล็อกศีรษะ หากเปิดการลดท่าผิดรูปอยู่แล้ว การเพิ่มพลิกตัวจะใช้เพิ่ม 9 bit ส่วนที่ใช้ร่วมกันไม่นับซ้ำ และการแสดงผลจะอัปเดตเมื่อเปลี่ยนเครื่องหมายเลือก

ยอดรวมที่แสดงเป็นส่วนของเครื่องมือท่าที่ติดตั้งในอวาตาร์นั้น ไม่ใช่ยอดทั้งอวาตาร์รวมเสื้อผ้าและเครื่องมืออื่น แม้ใช้เครื่องมือท่าหลายตัว การตั้งค่าร่วมก็ไม่นับซ้ำ หากจำนวนท่าเกินช่วงหมายเลขพื้นฐาน การเลือกท่าจะต้องใช้ bit เพิ่มด้วย

ความสูงเท้าและความสูงพื้น

  • «ความสูงเท้า»: ปรับความสูงฝั่งเท้าโดยรักษาตำแหน่งศีรษะ ใช้เมื่ออยากให้เท้าตรงกับพื้นหรือเตียง
  • «ความสูงพื้น»: ย้ายทั้งตัวรวมศีรษะขึ้นลง 50% คือความสูงเดิม, 0% คือต่ำลง 3m, 100% คือสูงขึ้น 3m ค่าเริ่มต้นคือ 50%

ทั้งสองอยู่ใน «ตั้งค่า» ในเกม โดย «ความสูงพื้น» อยู่ถัดจาก «ความสูงเท้า» เมื่อขยับความสูงพื้นออกจากกึ่งกลางจะเคลื่อนขึ้นลง และเมื่อคืนใกล้ 50% จะกลับสู่ความสูงเดิมพร้อมจบการแก้ไข ไม่มีสวิตช์เปิด/ปิดการลอยแยกต่างหาก การแก้มุมมองทำตอนเริ่มลอยและระหว่างปรับความสูงพื้น

ความสูงเท้าเปลี่ยนวิธีสร้างแอนิเมชันปกติเพื่อไม่ต้องสร้างการเคลื่อนไหวทั้งตัวซ้ำสำหรับการปรับสูงต่ำ ช่วยลดข้อมูลแอนิเมชันที่สร้างขึ้น แต่ไม่ได้ทำให้ขนาดอวาตาร์ทั้งหมดเหลือหนึ่งในสามเสมอไป

โหมดถ่ายภาพ

  1. เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > โหมดถ่ายภาพ»
  2. เปิด «โหมดถ่ายภาพ» ใน VRChat และเลือกท่าที่ «เลือกท่า»
  3. ใช้ «ระยะ» เคลื่อนไปข้างหน้าได้สูงสุด 3m และ «ทิศทาง» เพื่อหมุน เมื่อระยะมากกว่า 0 อวาตาร์จะหันมาหาคุณ
  4. เปิด «ล็อกเท้า» ตามต้องการ ตอนเริ่มไม่บังคับล็อก จึงปรับตำแหน่งก่อนได้ หากเพิ่ม «ปิดท่ามือ» ในเมนู จะสลับรูปมือได้ในหน้าจอเดียวกัน
  5. ใช้ «จบการถ่ายภาพ» คืนระยะและทิศทาง พร้อมปลดล็อกเท้า

การเคลื่อนที่และหมุนในโหมดถ่ายภาพใช้ 0 bit หากแสดงเฉพาะหน้าจอคุณ หากต้องการให้คนอื่นเห็นตำแหน่งและทิศทางด้วย ให้เปิด «ฟังก์ชันอำนวยความสะดวก > ซิงค์โหมดถ่ายภาพ» ระยะและทิศทางรวมกันใช้ 16 bit

หากศีรษะอวาตาร์ของคุณหายไปเมื่ออยู่ใกล้ ให้เปิด «ฟังก์ชันอำนวยความสะดวก > แสดงศีรษะในโหมดถ่ายภาพ» มีผลเฉพาะหน้าจอคุณระหว่างถ่ายภาพ และคืนสู่การแสดงปกติเมื่อจบ

กระโดดเพื่อสลับท่านอน

เมื่อเลือกทั้งท่านอนหงายและนอนคว่ำ สามารถกระโดดอยู่กับที่เพื่อสลับได้ หากเลือกเพียงฝั่งเดียวจะรักษาท่านั้น หากไม่ต้องการสลับด้วยการกระโดด ให้ปิด «กระโดดเพื่อสลับท่านอน» ใน «ฟังก์ชัน → ฟังก์ชันอำนวยความสะดวก» ของ Unity ไม่ใช้พารามิเตอร์ซิงค์เพิ่ม (0 bit) สำหรับอวาตาร์ที่มีหลายเครื่องมือท่า การปิดในตัวใดตัวหนึ่งจะมีผลทั้งอวาตาร์

พลิกตัว

ในท่านอนที่รองรับ การเอียงศีรษะซ้ายขวาจะทำให้ร่างกายพลิกอย่างนุ่มนวล ไม่ได้ทำให้ท่านอนทุกท่ารองรับโดยอัตโนมัติ

  1. เปิด «ฟังก์ชัน > ฟังก์ชันเมนู > พลิกตัว»
  2. ใน «ท่า» เปิด «รายละเอียด» ของท่านอนที่จะใช้ แล้วเปิด «เปิดพลิกตัว»
  3. กำหนดแอนิเมชันด้านข้างใน «ท่าพลิกตัวด้านข้าง» ระบบจะสร้างการพลิกซ้ายขวาจากท่าเดิมและท่าด้านข้าง ปรับ «ความแรงการแก้ไขพื้น» ตามต้องการ
  4. เลือกท่าที่รองรับใน VRChat และเปิด «พลิกตัว» ใช้โดยปลดล็อกศีรษะไว้

ท่าที่ใช้พลิกตัวจะกำหนดตำแหน่งเล่นแอนิเมชันจากการเอียงศีรษะ จึงใช้การตั้งค่า MotionTime ปกติไม่ได้ หากใช้แอนิเมชันพลิกตัวที่ทำเสร็จแล้ว ให้ใส่ในช่องแอนิเมชันปกติและเว้น «ท่าพลิกตัวด้านข้าง» ว่าง เตรียมแอนิเมชันที่ตำแหน่งเล่น 0 คือซ้าย, 0.5 คือนอนหงาย และ 1 คือขวา

หายใจและการโยกตัวเริ่มต้น

«ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก > เพิ่มแอนิเมชันหายใจ» จะทำให้หน้าอกและส่วนอื่นเคลื่อนตามการหายใจ เปิด «เปิดการตั้งค่า» แล้วเลือก «ไม่มี, เบา, กลาง, แรง, เร็ว, กำหนดเอง» สำหรับแต่ละประเภทท่า «เร็ว» คือหายใจถี่ ส่วน «กำหนดเอง» ให้กำหนดแอนิเมชันหายใจของคุณ

การเคลื่อนไหวหายใจอย่างเดียวใช้ 0 bit หากต้องการหยุดหรือเริ่มใหม่ใน VRChat ให้เปิด «ฟังก์ชันเมนู > หายใจ» ด้วย ใช้ 1 bit เพื่อซิงค์เปิด/ปิด การเปลี่ยนความแรงไม่เพิ่มจำนวน bit

คอ ไหล่ แขน และส่วนอื่นเคลื่อนตามหน้าอกเพื่อลดการขยับของศีรษะและมือ ไม่ได้ล็อกตำแหน่งอย่างสมบูรณ์ จึงควรเลือกความแรงให้เหมาะกับรูปร่างและท่า

«ฟังก์ชันอำนวยความสะดวก > ปิดการโยกตัวเริ่มต้นของ VRChat» ลดการโยกร่างกายขณะอยู่นิ่งที่ VRChat ให้มา ค่าเริ่มต้นปิด โดยยังรักษาการหายใจของเครื่องมือท่าและการเคลื่อนไหวกำหนดเองอื่น เลือกได้แม้ไม่ใช้หายใจและไม่ใช้ bit เพิ่ม การโยกที่เกิดจากอย่างอื่นนอกเหนือจากการเคลื่อนไหวเริ่มต้นจะไม่หยุดด้วยการตั้งค่านี้

หากใช้เครื่องมือท่าหลายตัว การปิดการโยกตัวเริ่มต้นในตัวใดตัวหนึ่งจะมีผลทั้งอวาตาร์ หากต้องการคืนเดิม ให้ปิดตัวเลือกนี้ในทุกเครื่องมือแล้วอัปโหลดใหม่

ลดท่าผิดรูปจากการหมุนศีรษะ

ใช้เมื่อท่าผิดรูปหลังปลดล็อกศีรษะเพราะทิศคอต่างจากท่าต้นฉบับ อยู่ใน «ฟังก์ชัน > ฟังก์ชันอำนวยความสะดวก» และไม่เพิ่มเมนูแยกในเกม ระหว่างล็อกศีรษะจะใช้ทิศของท่าต้นฉบับ ไม่นับท่านอนหงายในการแก้ไขเพื่อรักษาทิศหงายหน้าต้นฉบับ

รูปไอคอนเมนู

  • «สร้างไอคอนท่า»: สร้างภาพอวาตาร์ในแต่ละท่าเพื่อแสดงในเมนู ช่วยแยกท่าได้ง่าย แต่การสร้างภาพทำให้บิลด์นานขึ้น
  • «ลดขนาดไอคอน»: ลดความละเอียดภาพเพื่อลดขนาดอวาตาร์

บิลด์สำหรับ Android ไม่สร้างไอคอนท่า หลังเปลี่ยนเสื้อผ้าหรือส่วนอื่น ให้ใช้ «ถ่ายไอคอนใหม่» ภาพในรายการท่าอัปเดตด้วย «อัปเดตภาพตัวอย่างท่า» เป็นงานที่ใช้เวลา จึงควรอ่านข้อความยืนยันก่อนดำเนินการ

เพิ่ม เรียง และดูตัวอย่างท่า

เลือกประเภทท่าทางด้านซ้ายของ «ท่า» แท็บแว่นขยายด้านบนสุดค้นหาชื่อข้ามประเภทได้ เปิด «รายละเอียด» เพื่อตั้งค่าแอนิเมชัน ไอคอน MotionTime และอื่น ๆ พร้อมกัน

เพิ่มหลายแอนิเมชันพร้อมกันได้ด้วยการลากลงช่องเพิ่ม หรือเลือกใน Project แล้วกด «นำเข้าคลิปที่เลือกใน Project» การอ้างอิงคลิปเดียวกันที่ซ้ำจะถูกตัดออก

เปลี่ยนลำดับโดยเลือกปลายทางใน «รายละเอียด > ลำดับ» หรือใช้ปุ่มขึ้นลงก็ได้ สถานะเปิด/ปิดรายละเอียดจะยังคงเดิมหลังย้าย

กด «ตัวอย่าง» ของแต่ละท่าเพื่อดูใน Scene โดยไม่เปิดหน้าต่างปรับแต่ง เมื่อจบจะคืนการแสดงเดิม ตัวอย่างแบบง่ายนี้ไม่รันการบิลด์ของ MA หรือ NDMF จึงอาจต่างจากผลสุดท้ายของเสื้อผ้า FloorAdjuster และส่วนอื่นที่ประกอบตอนบิลด์ ตรวจเสื้อผ้าและการสัมผัสพื้นอีกครั้งหลังบิลด์อวาตาร์

ปรับแอนิเมชันและปรับแขนขาอัตโนมัติ (IK)

เปิด «ปรับแอนิเมชัน» ใน «ท่า» เพื่อปรับร่างกายและแขนขาอย่างละเอียดพร้อมดูตัวอย่าง เมื่อเสร็จแล้วให้ใช้คำสั่งบันทึกในหน้าต่างเพื่อบันทึกแอนิเมชันปรับแต่ง

สินค้าและท่าที่รองรับการปรับแขนขาอัตโนมัติจะปรับตำแหน่งแขนขาตามรูปร่างอวาตาร์ ใช้ «เปิดการปรับแขนขาอัตโนมัติ» ในหน้าปรับแอนิเมชันเพื่อสลับทั้งระบบ และ «เปิด IK สำหรับท่านี้» สำหรับแต่ละท่า ท่าที่ไม่มีการปรับอัตโนมัติจะแสดงข้อความแจ้ง

หากต้องการใช้ผลอัตโนมัติเป็นจุดเริ่มแล้วทำต่อเอง ให้กด «บันทึกผล IK ลงการปรับแต่ง» ระบบจะเขียนผล IK ขณะนั้นลงแอนิเมชันปรับแต่งใหม่และปิด IK ของท่านั้นในอวาตาร์ โดยเก็บแอนิเมชันต้นฉบับไว้ ปุ่มนี้ใช้ได้เมื่อเปิดการปรับอัตโนมัติทั้งระบบและท่าเป้าหมาย พร้อมมีการตั้งค่า IK ที่ใช้ได้

«ป้องกันเข่างอกลับด้าน» ใน «ตั้งค่าอวาตาร์» ใช้สลับการแก้ไขเข่า กำหนดมุมที่ «มุมงอเข่าต่ำสุด (องศา)» ในรายละเอียด «ใช้การแก้ไขเฉพาะอวาตาร์» ใช้ได้เมื่อมีข้อมูลแก้ไขที่ตรงกัน การแก้ไขบางอย่างที่ทับซ้อนกับการปรับแขนขาอัตโนมัติอาจใช้ร่วมกันไม่ได้

ท่าเดิม การเคลื่อนไหวของคุณ และพรีเซ็ต

ตั้งค่ารายการเหล่านี้ใน «ตั้งค่าอวาตาร์»

  • «ใช้ท่ายืน ย่อตัว และนอนคว่ำเดิมของอวาตาร์»: นำเข้าท่าที่ตั้งไว้เดิมในอวาตาร์โดยอัตโนมัติ
  • «ใช้การเคลื่อนไหวของคุณ»: เปิดการตั้งค่านำเข้า แล้วกำหนดการเคลื่อนไหวแยกตามประเภท เช่น ยืน ย่อตัว (Crouching) และนอนคว่ำ (Prone) โดยทั่วไปให้ใช้หนึ่งการเคลื่อนไหวต่อหนึ่งประเภท
  • «รวมการล็อกการติดตามกับเครื่องมืออื่น»: เปิดเมื่อใช้เครื่องมืออื่นร่วมกันแล้วฟังก์ชันล็อกทำงานไม่ถูกต้อง

การตั้งค่านำเข้าที่ให้กำหนดการเคลื่อนไหวเองเป็นคนละฟังก์ชันกับการนำเข้าท่าเดิมอัตโนมัติ

พรีเซ็ตอยู่ล่างสุดของแท็บ ค้นหาตามชื่อแล้วใช้ «ใช้พรีเซ็ตนี้» เพื่อสลับการตั้งค่าท่า เน้นใช้เป็นค่าเริ่มต้นตอนติดตั้ง และจะแทนที่ค่าปัจจุบัน ดังนั้นหากปรับไว้แล้วให้บันทึกก่อนเปลี่ยน

เมื่อแสดงรายการพรีเซ็ต จะอ่านเพียงชื่อและข้อมูลอวาตาร์ที่รองรับ ส่วนแอนิเมชันปรับแต่งจะโหลดเมื่อใช้พรีเซ็ตที่เลือก แม้สร้างรายการครั้งแรกก็ไม่โหลดแอนิเมชันของทุกอวาตาร์ล่วงหน้า

รายการแบ่งเป็น «อวาตาร์ที่รองรับ», «พรีเซ็ตผู้ใช้» และ «พรีเซ็ตทางการ Unisaki Studio» ตัวเลือก «ซ่อนพรีเซ็ตที่ให้มา» เป็นค่าการแสดงร่วมกันในโปรเจกต์เดียวกัน รายการจะอัปเดตเมื่อเพิ่ม แก้ไข หรือลบพรีเซ็ต หากยังไม่เปลี่ยนให้กด «โหลดใหม่»

พรีบิลด์และคำเตือน

เมื่อเปิด «ใช้ท่ายืน ย่อตัว และนอนคว่ำเดิมของอวาตาร์» จะตรวจการเคลื่อนไหวจาก Base ทุกครั้งที่สร้าง ไม่เขียนผลกลับไปยังการตั้งค่านำเข้าเอง ดังนั้นหากใช้แต่อัตโนมัติ รายการจะยังไม่ระบุ การเปลี่ยนการเคลื่อนไหวใน Base หรือเปิด/ปิดนำเข้าอัตโนมัติจะมีผลในการสร้างครั้งถัดไป

การนำเข้าอัตโนมัติตอนอัปโหลดมีผลกับสำเนาสำหรับบิลด์ ไม่แก้ออบเจ็กต์เดิมในซีน การตั้งค่านำเข้า Controller ต้นทาง หรือการเคลื่อนไหวต้นทาง หากมีพรีบิลด์และอินพุตไม่เปลี่ยน จะใช้ผลนั้นซ้ำ

ประเภทที่ระบุเองจะให้ความสำคัญกับค่าที่ระบุ และใช้ค่าหมุน แอนิเมชันปรับแต่ง และตำแหน่งเล่นด้วย การปิด «ใช้งาน» หรือเอาการเคลื่อนไหวที่ระบุไว้ออกจะหยุดนำเข้าอัตโนมัติของประเภทนั้น หากใช้ «ล้างการเลือกเอง» เพื่อล้างค่าและการปรับของประเภทนั้น เมื่อเปิดนำเข้าอัตโนมัติจะตรวจใหม่ในการสร้างครั้งหน้า ย้อนกลับได้ด้วย Undo หากมีค่าเก่าหลายรายการประเภทเดียวกัน จะให้ความสำคัญกับค่าที่ใช้ได้ซึ่งเลือกใน Inspector

รายการที่การนำเข้าอัตโนมัติรุ่นเก่าเพิ่มไว้ไม่ถูกลบเอง เพราะแยกจากรายการที่ลงทะเบียนหรือปรับเองไม่ได้ ใช้ «ล้างการเลือกเอง» เฉพาะประเภทที่ต้องการกลับสู่อัตโนมัติ หากติดตั้งหลายสินค้าในอวาตาร์เดียวกัน การตั้งค่าเองในสินค้าอื่นจะมีผลกับท่าเดิมร่วมกันด้วย

พรีบิลด์นำข้อมูลที่สร้างไว้กลับมาใช้เพื่อลดเวลาบิลด์อวาตาร์ สร้างหรืออัปเดตได้ด้วย «อัปเดตพรีบิลด์» การบิลด์ปกติก็สร้างข้อมูลที่จำเป็นได้ จึงไม่ต้องพรีบิลด์เองทุกครั้ง

เมื่อเปลี่ยนการตั้งค่า จะเข้าสถานะต้องอัปเดตและแจ้งด้วย «ตรวจสอบการตั้งค่า» ด้านบน Inspector หรือเครื่องหมายใน Hierarchy หลังเปลี่ยนท่าหรือ IK การอัปเดตพรีบิลด์ช่วยลดเวลาบิลด์ครั้งต่อไป

«การแสดงคำเตือน» อยู่ในกรอบ «ตรวจสอบการตั้งค่า» ซ่อนคำเตือนแต่ละชนิดหรือเครื่องหมายใน Hierarchy ได้ การซ่อนไม่ได้แก้ปัญหาการตั้งค่าหรืออัปเดตข้อมูลที่สร้างไว้ ข้อผิดพลาดและขั้นตอนสร้างที่จำเป็นยังคงเดิม

ข้อควรทราบในการใช้งาน

  • ออกแบบสำหรับการติดตามสามจุดและเดสก์ท็อป ไม่รองรับการล็อกท่าขณะใช้ฟูลบอดี้แทร็กกิง
  • รูปร่างและการดัดแปลงอาจทำให้ต้องปรับการสัมผัสพื้นของแขนขาหรือรูปลักษณ์เสื้อผ้าเพิ่มเติม
  • การใช้ Base แบบพิเศษหรือเครื่องมือเปลี่ยนท่าอื่นร่วมกันอาจให้ผลต่างจากที่คาด
  • การเคลื่อนที่/หมุนของโหมดถ่ายภาพและความสูงพื้นแก้ไขทั้งท่าของเครื่องมือและการเคลื่อนไหวเริ่มต้น/กำหนดเองเมื่อไม่เลือกท่า โปรดตรวจการเคลื่อนไหวเริ่มต้นที่ถูกแทนและพฤติกรรมมุมมองใน VRChat จริง
