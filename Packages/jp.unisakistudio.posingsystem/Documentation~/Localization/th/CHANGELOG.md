## [3.1.4] - 2026-11-11

- แก้ผมหรือแว่นตาที่ติดด้วย MA Bone Proxy ค้างอยู่ตำแหน่งเดิมระหว่างแก้หรือดูตัวอย่างท่า ตอนนี้ติดตามท่าตัวอย่างโดยรักษาค่าตั้งและการจัดวางอวาตาร์ต้นฉบับ
- แก้การปรับท่าด้วยตำแหน่งมุมมองล้มเหลวเมื่อถ่ายภาพท่า เช่น «仰向け寝_お疲れ» ภาพจะใช้แอนิเมชันที่รวมการแก้ท่าและปรับพื้นตอนบิลด์แล้ว

อัปเดต Unisaki Posing System เป็น 3.1.4 ใน ALCOM / VCC ใช้ Kawaii Posing Tool 3.1.2 และ Cool Posing Tool 1.1.0 ต่อได้ หากเคยใช้พรีบิลด์ หลังอัปเดตให้กด «อัปเดตพรีบิลด์» บันทึกซีน แล้วบิลด์และอัปโหลดอวาตาร์ใหม่

## [3.1.3] - 2026-11-09

- การใช้ «อัปเดตภาพตัวอย่างท่า» หรือพรีบิลด์บนอวาตาร์ที่ทำสำเนาจะไม่ลบภาพท่าของอวาตาร์ต้นฉบับอีก
- แก้แสดง «การตั้งค่าเปลี่ยน» เพียงถ่ายภาพใหม่ หลังพรีบิลด์ก่อนบันทึกซีนครั้งแรกหรือในหน้าต่างแก้ Prefab
- แก้ข้อมูลท่าที่สร้างจากพรีบิลด์ครั้งก่อนเหลืออยู่แล้วอาจทำให้พรีบิลด์ครั้งถัดไปหยุดกลางทาง
- ลดภาระเปิดรายการเมื่อยังไม่มีภาพท่า และปรับกระบวนการเริ่มพรีบิลด์หรือบิลด์ที่หยุดการใช้งาน Unity จนกว่าจะรับข้อมูลแพ็กเกจเสร็จ
- ลบค่าตั้งสำหรับแก้ไขของเครื่องมือท่าที่ปิดไว้ในอวาตาร์ระหว่างบิลด์ทั้ง PC และ Android ด้วย
- «สอบถามเกี่ยวกับข้อผิดพลาดนี้» ใส่หมายเลขวินิจฉัยและข้อมูลอื่นที่อยู่ภายหลังลงร่างได้ แม้ต้น Console มีข้อผิดพลาดที่อ่านสาเหตุไม่ได้เรียงอยู่ หากตั้งค่าคลิปพลิกตัวผิดพลาด ร่างจะระบุจุดที่ควรตรวจด้วย

อัปเดต Unisaki Posing System เป็น 3.1.3 ใน ALCOM / VCC ใช้ Kawaii Posing Tool 3.1.2 และ Cool Posing Tool 1.1.0 ต่อได้ สินค้าเหล่านี้ระบุระบบร่วมเวอร์ชันเก่าจึงอาจมีข้อความยืนยันความขัดแย้งตอนอัปเดต หากเคยใช้พรีบิลด์ หลังอัปเดตให้กด «อัปเดตพรีบิลด์» บันทึกซีน แล้วบิลด์และอัปโหลดอวาตาร์ใหม่

## [3.1.2] - 2026-11-09

- แก้ปัญหาหน้ายังคงแหงนหลังลุกจากนอนคว่ำเมื่อเปิด «ลดท่าผิดรูปจากการหมุนศีรษะ»
- แม้ปิด «ความสูงเท้า» ก็สลับล็อกศีรษะได้จาก «ตั้งค่า → ล็อกศีรษะอัตโนมัติเมื่อนอนหงาย» ในเมนู EX อวาตาร์ที่รายการหายไปใน 3.1.0 หรือ 3.1.1 จะได้รายการคืนเมื่ออัปเดตแล้วบิลด์ใหม่
- ใช้ «อัปเดตพรีบิลด์» ได้แม้ปิดเครื่องหมายเลือกตัวอวาตาร์ใน Unity
- แก้ปัญหา Controller ท่าร่วมรุ่นเก่าที่เหลือใน Assets ทำให้สร้างท่าไม่ได้หลังอัปเดต และรักษาการตั้งค่า Controller ที่คุณแก้ไว้ด้วย
- หากเครื่องมือหรือออบเจ็กต์แม่ปิดอยู่จนใช้ Animator ท่าร่วมไม่ได้ จะแสดงชื่อเป้าหมาย เปิดตำแหน่งได้จาก «ตรวจสอบการตั้งค่า → เลือกเป้าหมาย»
- เมื่อพรีบิลด์แสดงว่าการตั้งค่าเปลี่ยนแล้ว ใช้ «รายละเอียด → ดูการตั้งค่าที่เปลี่ยนหลังพรีบิลด์» ตรวจความแตกต่างจากครั้งก่อนได้
- เมื่อบิลด์หยุดเพราะสคริปต์ผิดพลาด (PS050) จะแสดงข้อผิดพลาดต้นทางที่ Unity พบสูงสุด 5 รายการ ใช้ «สอบถามเกี่ยวกับข้อผิดพลาดนี้» เพื่อตรวจ แก้ไข และส่งร่างที่มีเวอร์ชัน Unity/เครื่องมือที่รองรับและหมายเลขข้อผิดพลาดได้

หากเคยใช้พรีบิลด์ หลังอัปเดตให้กด «อัปเดตพรีบิลด์» บันทึกซีน แล้วบิลด์และอัปโหลดอวาตาร์ใหม่

## [3.1.1] - 2026-11-08

- แม้ปิด «กลับซ้ายขวา» รายการ «ความสูงพื้น» และ «พลิกตัว» ที่เปิดไว้จะแสดงใน «ตั้งค่า» ของเมนู EX ใน VRChat
- แม้เรียง ลบ หรือเปลี่ยนชื่อท่าในรุ่นเก่า จะสืบทอดการพลิกตัวที่ถูกต้องให้ «เหยียดขา», «ผ่อนคลาย» และ «ชันเข่าข้างเดียว» หาก Unpack ทั้งหมดแต่ยังระบุท่าเดิมได้ก็สืบทอดได้ รักษาท่าสร้างเอง การพลิกที่คุณปิดเอง และการเคลื่อนไหวด้านข้างที่เปลี่ยนไว้
- แก้ปัญหานอนคว่ำชั่วขณะตอนเลือกอวาตาร์ใน VRChat และหงายชั่วขณะเมื่อกระโดดทั้งที่เลือกนอนคว่ำอย่างเดียว ปิดการสลับด้วยการกระโดดได้ใน «ฟังก์ชัน → ฟังก์ชันอำนวยความสะดวก → กระโดดเพื่อสลับท่านอน» ค่าเริ่มต้นเปิด
- หากการอ้างอิง Animator Controller ของท่าร่วมหลุดหลังอัปเดตและกู้ได้ จะแจ้งเตือนแล้วสร้างใหม่จากการตั้งค่า รักษาการอ้างอิง Controller ที่หลายอวาตาร์ใช้ร่วมกันด้วย
- หากมีข้อผิดพลาดคอมไพล์ในโปรเจกต์ จะแจ้งสาเหตุและหยุดตั้งแต่ต้นบิลด์ ระหว่างตรวจการอ้างอิงไม่ได้เพราะสคริปต์ผิดพลาด จะไม่จัดเก็บ Controller ที่สร้างไว้อัตโนมัติ
- แม้มี Prefab ชื่อเดียวกับสินค้าในโปรเจกต์ จะเลือก Prefab ทางการก่อนเมื่อเพิ่มเครื่องมือ หาก Controller ร่วมต่างกันเพียงรูปแบบขึ้นบรรทัด ก็พรีบิลด์ต่อได้
- Write Defaults ของเลเยอร์ FX ที่เครื่องมือท่าเพิ่ม (เช่น ความสูงพื้น) จะตรงกับการตั้งค่าของอวาตาร์

หากเคยใช้พรีบิลด์ หลังอัปเดตให้กด «อัปเดตพรีบิลด์» บนเครื่องมือในซีน บันทึกซีน แล้วบิลด์และอัปโหลดอวาตาร์ใหม่

## [3.1.0] - 2026-11-07

- รองรับการปรับแขนขาอัตโนมัติ (IK) ให้เข้ารูปร่างสำหรับท่าที่รองรับ การแก้ไขเฉพาะอวาตาร์ และป้องกันเข่างอกลับด้าน
- ปรับตำแหน่งและทิศทางอวาตาร์ในโหมดถ่ายภาพได้ เลือกซิงค์ตำแหน่ง/ทิศทางและแสดงศีรษะตัวเองขณะถ่ายได้ด้วย
- «ความสูงพื้น» ย้ายทั้งตัวขึ้นลงได้สูงสุด 3m ใช้แยกจาก «ความสูงเท้า» ได้
- เพิ่มการหายใจ ตัวเลือกหยุดการโยกตัวขณะอยู่นิ่งเริ่มต้น และลดท่าผิดรูปจากทิศคอ
- ตรวจฟังก์ชันและการใช้พารามิเตอร์ใน Inspector ได้ รองรับค้นหาท่า เพิ่มหลายท่า เรียงใหม่ และดูตัวอย่างแบบง่ายใน Scene
- เร่งการสลับยืน ย่อตัว และนั่งในโหมดเดสก์ท็อป
- ปรับปรุงคำเตือนพรีบิลด์หลังเปลี่ยนค่า ภาระการเลื่อน Inspector และการหยุดนานตอนจัดเก็บสิ่งที่สร้างไว้
- แก้ปัญหานำเข้าอัตโนมัติเปิดอยู่แล้วเตือนให้อัปเดตพรีบิลด์ทั้งที่ไม่เปลี่ยนค่าและสร้างใหม่ตอนอัปโหลด ผลนำเข้ามีผลกับอวาตาร์ที่สร้าง ไม่แก้การตั้งค่านำเข้าของออบเจ็กต์ต้นฉบับ
- เพิ่มการพลิกตัวตามการเอียงศีรษะและการตั้งค่าการเคลื่อนไหวรายท่า
- ปรับปรุงการสืบทอดค่าพลิกตัวจากพรีเซ็ตเก่า การนำเข้าการเคลื่อนไหวของคุณ และการจัดการแอสเซ็ตที่สร้าง

## [3.1.0-beta.2] - โอเพนเบต้า (2026-11-05)

- เพิ่มความยาวคงที่ ความต่างสูงต่ำ (Y) และหน้าหลัง (Z) จาก Head ถึง Viewpoint ใน «เกณฑ์ความยาวตำแหน่ง» ของ IK
- แสดงคำเตือน Inspector ด้านซ้ายชื่อออบเจ็กต์ใน Hierarchy ด้วย ทั้งยังไม่พรีบิลด์ เปลี่ยนค่า และคำเตือนที่แสดงจากนำเข้าการเคลื่อนไหวหรือใช้พรีเซ็ต
- แก้ Unity หยุดนานเมื่อการจัดเก็บอัตโนมัติตอนเปิดซีนโหลด Controller ที่สร้างจากซีนอื่น
- แก้ประวัติพรีบิลด์หายเมื่อเปลี่ยนรายการท่าหรือฟังก์ชัน แสดงว่าเปลี่ยนค่าหลังพรีบิลด์แทนยังไม่ทำ และเตือนต้องอัปเดตใน Hierarchy ด้วย
- ใช้ผลเทียบพรีบิลด์ร่วมกันสำหรับ Inspector/Hierarchy เพื่อลดภาระการเลื่อนเมื่อค่าและแอสเซ็ตอ้างอิงไม่เปลี่ยน การเทียบตอนบิลด์ยังทำทุกครั้งตามเดิม

## [3.1.0-beta.1] - โอเพนเบต้า (2026-11-04)

- เปลี่ยนการสลับท่าปกติในเดสก์ท็อปเป็นวิธีประเมิน 1 ครั้ง ใช้ทั้งบิลด์ปกติและพรีบิลด์ ส่วน VR และเงื่อนไขพิเศษใช้เส้นทางเดิม
- ตรวจว่าพรีบิลด์จาก alpha.3 หรือก่อนหน้าต้องอัปเดต
- รักษามุมมองเมื่อปรับความสูงพื้นขณะถ่ายภาพ และกลับสู่ความสูงพื้นล่าสุดเมื่อจบการถ่าย

- เปลี่ยนนำเข้าอัตโนมัติให้ตรวจเฉพาะตอนสร้าง ไม่เพิ่มหรือแก้การตั้งค่านำเข้าเองตอนพรีบิลด์/บิลด์
- การเปิด/ปิดนำเข้าอัตโนมัติ เปลี่ยน Base และล้างค่าเองมีผลกับการสร้างใหม่ รักษาค่าและการปรับเองที่หลายสินค้าใช้ร่วมกัน พร้อมคืนการเคลื่อนไหวนำเข้าเก่าเป็นท่ามาตรฐาน
- จัดการ Controller พรีบิลด์เป็นหนึ่งไฟล์ต่อ GUID ซีนและอวาตาร์ แยกการอ้างอิงร่วมจากสำเนา ซีนอื่น และ Prefab ก่อนอัปเดต
- ตอนบิลด์ใช้การจัดการแอสเซ็ตชั่วคราวของ NDMF โดยไม่เพิ่มไฟล์สร้างสำหรับแก้ไข
- ตรวจสิ่งที่สร้างเมื่อเปิดและบันทึกซีน รักษารายการที่มีการแก้ยังไม่บันทึก Undo/Redo หรือการอ้างอิงภายนอก ย้ายเฉพาะไฟล์ไม่ใช้ที่ระบุเจ้าของชัดเจนไปถังขยะ
- ใช้ค่าหมุน แอนิเมชันปรับแต่ง และตำแหน่งเล่นของการเคลื่อนไหวนำเข้า รวมกระบวนการหมุน RootT/RootQ และปรับ Humanoid เข้ากับท่าปกติ
- สำเนาการปรับ BlendTree ซ้อนเฉพาะสำหรับปลายทาง รักษาต้นฉบับและค่าผสมสำหรับเดิน
- ตำแหน่งเล่นของ «ยืนอย่างเดียว» จะแปลงเป็นท่านิ่งที่อัตราเฟรมต้นฉบับ โดยไม่หยุดเล่นฝั่งเดิน

## [3.1.0-alpha.2] - รุ่นทดสอบแบบปิด (2026-10-26)

### แก้ไขและเปลี่ยนแปลง

- ใช้การแก้ไขโหมดถ่ายภาพและความสูงพื้นกับการเคลื่อนไหวเริ่มต้น/กำหนดเองเมื่อไม่เลือกท่าของเครื่องมือด้วย
- ขยายความสูงพื้นขึ้นลงเป็น 3m กำหนด 50% เป็นความสูงเดิมและค่าเริ่มต้น, 0% ต่ำลง 3m, 100% สูงขึ้น 3m

## [3.1.0-alpha.1] - ก่อนเผยแพร่

### เพิ่ม

- เพิ่มเปิด/ปิดรายฟังก์ชันและแสดงการใช้ ExpressionParameters
- เพิ่มโหมดถ่ายภาพที่ย้ายอวาตาร์ไปข้างหน้าและหมุนได้

- เพิ่มตัวเลือกไม่ซ่อนศีรษะอวาตาร์ของคุณในโหมดถ่ายภาพ

- เพิ่มพลิกตัวตามการเอียงศีรษะและกำหนดแอนิเมชันที่รองรับรายท่า
- เพิ่มการเคลื่อนไหวหายใจและค่าเบา กลาง แรง เร็ว กำหนดเอง

- เพิ่มตัวเลือกหยุดการโยกจากท่าพักเริ่มต้นของ VRChat
- เพิ่มตัวเลือกลดท่าผิดรูปจากการหมุนศีรษะ
- เพิ่มปรับแขนขาอัตโนมัติ (IK) ตามรูปร่างในท่าที่รองรับ พร้อมเปิด/ปิดทั้งอวาตาร์และรายท่า
- เพิ่ม «บันทึกผล IK ลงการปรับแต่ง» เพื่อเก็บผลในแอนิเมชันปรับแต่ง
- เพิ่มการแก้ท่าเฉพาะอวาตาร์ ป้องกันเข่างอกลับด้าน และมุมงอขั้นต่ำ
- เพิ่มตัวอย่างแบบง่ายใน Scene จากรายการท่า
- เพิ่มแท็บประเภทท่า ค้นหาข้ามประเภท เพิ่มหลายแอนิเมชันพร้อมกัน และระบุลำดับปลายทาง
- เพิ่มแสดงประวัติการอัปเดตสินค้า/ระบบร่วมใน Inspector

### เปลี่ยนแปลง

- เร่งการโหลดพรีเซ็ต ลดเวลารอตอนเพิ่มเครื่องมือหรือแสดงรายการ
- การเพิ่ม แก้ไข หรือลบพรีเซ็ตสะท้อนในรายการอัตโนมัติ
- จัด Inspector เป็นสามแท็บ «ฟังก์ชัน», «ท่า» และ «ตั้งค่าอวาตาร์»
- เพิ่มคำอธิบายและไอคอนให้รายการตั้งค่า พร้อมรวมรูปแบบเปิด/ปิดรายละเอียด
