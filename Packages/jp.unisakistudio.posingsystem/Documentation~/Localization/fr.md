# Choisir la langue — v3.2.0

Par défaut, l’outil suit la langue de votre ordinateur, indépendamment de Unity ; une langue non prise en charge utilise l’anglais. Modifiez-la avec Language / 言語 en haut de l’Inspector. Le choix est mémorisé pour les autres projets Unity du même utilisateur sur cet ordinateur. Les confirmations d’installation proposent aussi un bouton Language....

## Langue du menu VRChat

La langue choisie en haut de l’Inspector s’applique à l’interface de l’outil et au menu en jeu. Le choix est enregistré sur l’outil dans votre avatar. Téléversez à nouveau l’avatar pour appliquer le changement dans VRChat.

## Noms des poses

La liste affiche les noms traduits. La recherche accepte le nom japonais ou sa traduction. Les noms d’origine, animations et paramètres internes sont conservés. Les noms personnalisés sans traduction restent inchangés.

## Langues disponibles

La version v3.2.0 fournit les textes standard et les 128 noms de poses inclus pour 30 langues. L’Inspector, les dialogues d’installation et le menu généré en jeu utilisent la même langue. Les noms personnalisés restent inchangés. Le manuel complet hors ligne est disponible en anglais.
