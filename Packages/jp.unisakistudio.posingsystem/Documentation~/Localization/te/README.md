# Unisaki Posing System

Kawaii Posing Tool, Cool Posing Tool వంటి సాధనాలు ఉపయోగించే ఉమ్మడి భంగిమ వ్యవస్థ ఇది. Modular Avatar, NDMF ద్వారా అవతార్ అప్‌లోడ్ సమయంలో అవసరమైన మెనూలు, యానిమేషన్‌లను సృష్టిస్తుంది.

ఈ README అభివృద్ధిలో ఉన్న v3.2.0 కోసం. అధికారిక విడుదల తేదీ ఇంకా నిర్ణయించలేదు. ఇన్‌స్టాల్ చేసిన సంచికను భంగిమ సాధనం Inspector పైభాగంలో చూడవచ్చు. [కొత్త ఫీచర్లు, మార్పుల చరిత్రను](CHANGELOG.md) కూడా చూడండి.

## ప్రదర్శన భాష, ఆఫ్‌లైన్ పత్రాలు

Inspector పైభాగంలోని «Language / 言語»లో భాషను ఎంచుకోండి. ఒకే ఎంపిక Inspectorకు, సృష్టించే VRChat మెనూకు వర్తిస్తుంది. ఆటలోని భాషను మార్చాలంటే అవతార్‌ను మళ్లీ అప్‌లోడ్ చేయండి.

ఎంపిక లేకపోతే కంప్యూటర్ భాషను, మద్దతు లేని భాషలకు ఆంగ్లాన్ని ఉపయోగిస్తుంది. Windows, macOS, Linuxకు మద్దతు ఉంది. చివరి ఎంపిక EditorPrefsలో భద్రపడి ఈ కంప్యూటర్‌లో అదే OS వినియోగదారుని ఇతర ప్రాజెక్టులకూ వర్తిస్తుంది. అన్ని పోజ్ సాధనాలు, అవతార్‌లు ఒకే భాషను ఉపయోగిస్తాయి. ఏ సాధనం Inspectorలో భాష మార్చినా ఉమ్మడి సెట్టింగ్ నవీకరించబడుతుంది; ఒక్కో అవతార్‌కు విడిగా చేసిన భాషా ఎంపికలను ఉపయోగించదు. ఇతర కంప్యూటర్‌లకు సమకాలీకరించదు. లైసెన్స్ నిల్వ విధానం మారదు. భాష భద్రపరచబడకపోతే మొదటి ఇన్‌స్టాలేషన్ నిర్ధారణలో మాత్రమే భాష బటన్ కనిపిస్తుంది. ఆ తర్వాత Inspectorలో భాషను మార్చవచ్చు.

README, మార్పుల చరిత్ర, మార్గదర్శినిని చేర్చిన [భాషల సూచికలో](../index.html) ఎంచుకోవచ్చు. Inspectorలోని మార్గదర్శిని, మార్పుల చరిత్ర కూడా ఎంచుకున్న భాషను అనుసరిస్తాయి. అసలు ఒప్పందాలు, సూచన అనువాదాలు మునుపటిలాగే విడిగా అందుబాటులో ఉన్నాయి.

## డెస్క్‌టాప్ మోడ్‌లో భంగిమ మార్చడం

డెస్క్‌టాప్‌లో నిలబడడం, వంగడం, కూర్చోవడం మధ్య మారినప్పుడు ఎంచుకున్న భంగిమ వర్తించే ఆలస్యం తగ్గింది. సాధారణ బిల్డ్‌లకూ ప్రీబిల్డ్‌లకూ వర్తిస్తుంది; ప్రత్యేక ఆదేశాలు, అదనపు సెట్టింగ్‌లు అవసరం లేదు. VR, ప్రత్యేక పరిస్థితుల్లో మునుపటి విధానం కొనసాగుతుంది. పాత ప్రీబిల్డ్‌లను నవీకరించి అప్‌లోడ్ చేయండి.

## ఇన్‌స్టాలేషన్, సంచిక నవీకరణ

ప్రతి ఉత్పత్తి కొనుగోలు ఫైళ్లను, ఇన్‌స్టాలేషన్ సూచనలను అనుసరించి VCC లేదా ALCOM ద్వారా భంగిమ సాధనాన్ని జోడించండి. ఈ వ్యవస్థ భంగిమ సాధనం ఆధారిత ప్యాకేజీగా ఇన్‌స్టాల్ అవుతుంది.

v3.2.0కు కావలసిన వాతావరణం:

- Unity 2022.3 VRChat అవతార్ ప్రాజెక్టు
- VRChat Avatars SDK 3.10.4 లేదా కొత్తది
- Modular Avatar 1.x శ్రేణిలో 1.15.1 లేదా కొత్తది
- NDMF (Non-Destructive Modular Framework) 1.x శ్రేణిలో 1.14.0 లేదా కొత్తది

Kawaii Posing Tool ఉపయోగిస్తే ALCOM / VCCలో దాన్ని 3.2.0కు నవీకరించి Unisaki Posing System కూడా 3.2.0 అయిందని నిర్ధారించండి. ప్రీబిల్డ్ ఉపయోగించినట్లయితే «ప్రీబిల్డ్ నవీకరించు» నొక్కి సీన్‌ను భద్రపరిచి అవతార్‌ను అప్‌లోడ్ చేయండి.

Cool Posing Tool 1.2.0 ఉమ్మడి 3.2.0ను ఉపయోగిస్తుంది. ఉత్పత్తిని, ఉమ్మడి వ్యవస్థను అనుకూల సంచికలకు కలిపి నవీకరించండి.

### 8bit సంచిక ఉపయోగించినవారికి

కొత్త జోడింపులు సాధారణ Prefabలో ఏకీకృతమయ్యాయి. «ఫీచర్లు»లో అవసరం లేనివి ఆపి వినియోగాన్ని తగ్గించవచ్చు. భంగిమ ఎంపిక మాత్రమే ఉంటే ప్రాథమిక వినియోగం 8 bit.

ఇప్పటికే అమర్చిన అవతార్‌లు, ప్రీసెట్‌ల సూచనలను కాపాడడానికి పాత 8bit Prefab ప్రతి ఉత్పత్తి «Editor/Legacy»లో ఉంది. ప్రస్తుత 8bit సంచిక వాడటానికి Prefabను తొలగించాల్సిన లేదా మార్చాల్సిన అవసరం లేదు. Unity కొత్త జోడింపు మెనూలో 8bit ఎంచుకునే విధానం తొలగించబడింది.

## సెట్టింగ్‌ల తెరను అర్థం చేసుకోవడం

Hierarchyలో అవతార్ లోపలి «可愛いポーズ», «カッコいいポーズ» వంటి వస్తువులను ఎంచుకుని అమర్చవచ్చు.

| ట్యాబ్ | సెట్టింగ్‌లు |
| --- | --- |
| ఫీచర్లు | ఆట మెనూలో జోడించే అంశాలు, సౌకర్య ఎంపికలు, చిహ్న చిత్రాలు, ExpressionParameters వినియోగం |
| భంగిమలు | భంగిమ ఎంపిక, జోడింపు, క్రమం, Scene ముందుచూపు, భంగిమ వివరాలు, యానిమేషన్ సర్దుబాటు |
| అవతార్ అమరిక | శరీరాకృతి సవరణ, మోకాలి సవరణ, అసలు భంగిమలు/సొంత కదలికల దిగుమతి, ప్రీసెట్‌లు |

వివరమైన సెట్టింగ్‌లున్న అంశాల్లో «సెట్టింగ్‌లు తెరువు» నొక్కితే కింద సెట్టింగ్‌లు తెరుచుకుంటాయి. శ్వాస సెట్టింగ్‌లు కూడా «ఫీచర్లు»లో ఉన్నాయి.

పైభాగంలోని «సహాయం / మార్పుల చరిత్ర» ద్వారా మార్గదర్శిని, మద్దతు, మార్పుల చరిత్రను తెరవవచ్చు. చరిత్రలో ఉత్పత్తి, Unisaki Posing System మధ్య మారి చదవవచ్చు.

## ఫీచర్లు, ExpressionParameters వినియోగం

«ఫీచర్లు»లో «మెనూ ఫీచర్లు» కింద ఎంచుకున్నవి ఆట మెనూలో కనిపిస్తాయి. ఉదాహరణకు «ప్రతిబింబం» ఎంచుకుంటే ఆటలో ప్రతిబింబాన్ని మార్చవచ్చు. Inspectorలో ఎంచుకోవడం వల్ల మాత్రమే అన్ని భంగిమలు ఎప్పుడూ ప్రతిబింబించవు.

| ఫీచర్ | అదనపు bit వినియోగం |
| --- | ---: |
| ప్రతిబింబం | 1 bit |
| సంజ్ఞలు ఆపు | 1 bit |
| శ్వాస యానిమేషన్ నడుపు | 0 bit |
| శ్వాస (ఆటలో ఆన్/ఆఫ్) | 1 bit |
| పాదాల ఎత్తు | 8 bit |
| నేల ఎత్తు | 8 bit |
| ఫోటో మోడ్ (మీ తెరపై మాత్రమే) | 0 bit |
| ఫోటో మోడ్‌ను సమకాలీకరించు | 16 bit |
| ఫోటో మోడ్‌లో తలను కనిపించేలా ఉంచు | 0 bit |
| VRChat సాధారణ నిలుచున్న ఊగుడును ఆపు | 0 bit |
| తల భ్రమణంతో భంగిమ వక్రీకరణ తగ్గించు | 1 bit (పక్కకు తిరగడంతో పంచుకుంటుంది) |
| పక్కకు తిరుగు | 10 bit (అందులో 1 bit భంగిమ వక్రీకరణ సవరణతో పంచుకుంటుంది) |

పక్కకు తిరగడంలో ఆన్/ఆఫ్‌కు 1 bit, తల వాల్పుకు 8 bit, మెడ లాక్‌కు 1 bit ఉంటాయి. భంగిమ వక్రీకరణ సవరణ ఇప్పటికే సక్రియమైతే పక్కకు తిరగడం జోడించినప్పుడు 9 bit మాత్రమే పెరుగుతుంది. ఉమ్మడి వినియోగం రెండుసార్లు లెక్కించబడదు; ఎంపిక మారితే ప్రదర్శన నవీకరిస్తుంది.

చూపే మొత్తం ఆ అవతార్‌లోని భంగిమ సాధనాలది మాత్రమే; దుస్తులు, ఇతర సాధనాలు సహా మొత్తం అవతార్‌ది కాదు. అనేక భంగిమ సాధనాలు వాడినా ఉమ్మడి సెట్టింగ్‌లు రెండుసార్లు లెక్కించబడవు. భంగిమల సంఖ్య ప్రాథమిక సంఖ్యా పరిధిని దాటితే ఎంపికకు అదనపు bit అవసరం.

### పాదాల ఎత్తు, నేల ఎత్తు

- «పాదాల ఎత్తు»: తల స్థానాన్ని అలాగే ఉంచి పాదాల వైపు ఎత్తును సర్దుతుంది. పాదాలను నేలకు లేదా మంచానికి సరిపోల్చడానికి వాడండి.
- «నేల ఎత్తు»: తలతో సహా మొత్తం శరీరాన్ని పైకి/కిందికి కదిలిస్తుంది. 50% అసలు ఎత్తు, 0% దానికంటే 3m కింద, 100% దానికంటే 3m పైన. ప్రారంభ విలువ 50%.

రెండూ ఆటలోని «సెట్టింగ్‌లు»లో ఉంటాయి; «నేల ఎత్తు», «పాదాల ఎత్తు» తర్వాత వస్తుంది. మధ్య నుంచి మార్చితే పైకి/కిందికి కదులుతుంది; సుమారు 50%కు తిరిగిస్తే అసలు ఎత్తుకు వచ్చి సవరణ ముగుస్తుంది. వేరుగా తేలడం ఆన్/ఆఫ్ స్విచ్ లేదు. తేలడం మొదలైనప్పుడు, నేల ఎత్తు మారుస్తున్నప్పుడు దృక్కోణం సవరిస్తుంది.

సాధారణ యానిమేషన్‌లలో ఎత్తు సర్దడానికి మొత్తం శరీర కదలికలను మళ్లీ సృష్టించని విధానానికి పాదాల ఎత్తు మార్చబడింది. సృష్టించే యానిమేషన్ డేటా తగ్గుతుంది; మొత్తం అవతార్ పరిమాణం ఎప్పుడూ మూడో వంతు అవుతుందని అర్థం కాదు.

### ఫోటో మోడ్

1. «ఫీచర్లు > మెనూ ఫీచర్లు > ఫోటో మోడ్» సక్రియం చేయండి.
2. VRChatలో «ఫోటో మోడ్» తెరిచి «భంగిమ ఎంచుకో»లో భంగిమ ఎంచుకోండి.
3. «దూరం»తో గరిష్ఠంగా 3m ముందుకు కదిలించి «దిశ»తో తిప్పండి. దూరం 0కంటే ఎక్కువైతే అవతార్ మీ వైపు చూస్తుంది.
4. అవసరమైతే «పాదాలు లాక్» సక్రియం చేయండి. మొదట లాక్‌ను బలవంతం చేయదు కాబట్టి ముందే స్థానాన్ని సర్దవచ్చు. «సంజ్ఞలు ఆపు» మెనూలో ఉంటే అదే తెరలో చేతి ఆకారమూ మార్చవచ్చు.
5. «ఫోటో ముగించు»తో దూరం, దిశను తిరిగి ఉంచి పాదాల లాక్ విడదీయండి.

మీ తెరలో మాత్రమే ఫోటో మోడ్ కదలిక/భ్రమణం వాడితే 0 bit. ఇతరులకూ స్థానం, దిశ చూపాలంటే «సౌకర్య ఎంపికలు > ఫోటో మోడ్‌ను సమకాలీకరించు» సక్రియం చేయండి. దూరం, దిశకు కలిపి 16 bit అవసరం.

సమీపంలో మీ అవతార్ తల కనిపించకపోతే «సౌకర్య ఎంపికలు > ఫోటో మోడ్‌లో తలను కనిపించేలా ఉంచు» సక్రియం చేయండి. ఫోటో సమయంలో మీ తెరలో మాత్రమే వర్తించి ముగిశాక సాధారణ స్థితికి వస్తుంది.

### దూకి పడుకున్న భంగిమలు మార్చు

వెల్లకిలా, బోర్లా రెండూ ఎంచుకుంటే ఉన్నచోటే దూకి మార్చవచ్చు. ఒక్కటే ఎంచుకుంటే అదే ఉంచుతుంది. దూకి మార్చవద్దనుకుంటే Unity «ఫీచర్లు → సౌకర్య ఎంపికలు»లో «దూకి పడుకున్న భంగిమలు మార్చు» ఆపండి. అదనపు సమకాలీకరణ పరామితి వినియోగం 0 bit. అనేక భంగిమ సాధనాలున్న అవతార్‌లో ఒక్కదానిలో ఆపినా మొత్తం అవతార్‌కు వర్తిస్తుంది.

### పక్కకు తిరుగు

మద్దతున్న పడుకున్న భంగిమలో తలను ఎడమ/కుడికి వాలిస్తే శరీరమూ సున్నితంగా పక్కకు తిరుగుతుంది. అన్ని పడుకున్న భంగిమలకు స్వయంగా మద్దతు ఉండదు.

1. «ఫీచర్లు > మెనూ ఫీచర్లు > పక్కకు తిరుగు» సక్రియం చేయండి.
2. «భంగిమలు»లో కావలసిన పడుకున్న భంగిమ «వివరాలు» తెరిచి «పక్కకు తిరగడం సక్రియం చేయి» సక్రియం చేయండి.
3. «పక్కకు తిరిగే పక్క భంగిమ»లో పక్క యానిమేషన్ అమర్చండి. అసలు, పక్క భంగిమల నుంచి ఎడమ/కుడి తిరగడం సృష్టిస్తుంది. అవసరమైతే «నేల తాకే సవరణ బలం» సర్దండి.
4. VRChatలో మద్దతున్న భంగిమను ఎంచుకుని «పక్కకు తిరుగు» సక్రియం చేయండి. మెడ లాక్ విడదీసి వాడండి.

పక్కకు తిరిగే భంగిమల్లో తల వాల్పు యానిమేషన్ ప్లేబ్యాక్ స్థానాన్ని నిర్ణయిస్తుంది కాబట్టి సాధారణ MotionTime సెట్టింగ్ అందుబాటులో ఉండదు. పూర్తిగా సిద్ధమైన పక్కకు తిరిగే యానిమేషన్ వాడితే సాధారణ యానిమేషన్ ఫీల్డ్‌లో పెట్టి «పక్కకు తిరిగే పక్క భంగిమ» ఖాళీగా ఉంచండి. ప్లేబ్యాక్ 0 ఎడమ, 0.5 వెల్లకిలా, 1 కుడిగా ఉండే యానిమేషన్ సిద్ధం చేయండి.

### శ్వాస, సాధారణ ఊగుడు

«ఫీచర్లు > సౌకర్య ఎంపికలు > శ్వాస యానిమేషన్ నడుపు» ద్వారా ఛాతీ వంటివి శ్వాసకు అనుగుణంగా కదులుతాయి. «సెట్టింగ్‌లు తెరువు»లో ప్రతి భంగిమ రకానికి «ఏదీ లేదు, తక్కువ, మధ్యస్థం, బలంగా, వేగంగా, సొంత» ఎంచుకోవచ్చు. «వేగంగా» త్వరిత శ్వాస. «సొంత»లో మీ శ్వాస యానిమేషన్ అమర్చవచ్చు.

శ్వాస కదలిక మాత్రమే 0 bit. VRChatలో ఆపడానికి/తిరిగి మొదలుపెట్టడానికి «మెనూ ఫీచర్లు > శ్వాస» కూడా సక్రియం చేయండి. ఆన్/ఆఫ్ సమకాలీకరణకు 1 bit. బలం మార్చినా bit పెరగదు.

ఛాతీతో పాటు మెడ, భుజాలు, చేతులూ కదిలించి తల, చేతుల స్థాన మార్పును తగ్గిస్తుంది. పూర్తిగా స్థానం లాక్ కాదు కాబట్టి శరీరాకృతి, భంగిమకు తగిన బలం ఎంచుకోండి.

«సౌకర్య ఎంపికలు > VRChat సాధారణ నిలుచున్న ఊగుడును ఆపు» VRChat ఇచ్చే సాధారణ విశ్రాంతి శరీర ఊగుడును తగ్గిస్తుంది. ప్రారంభంలో ఆఫ్; భంగిమ సాధనం శ్వాస, ఇతర సొంత కదలికలను అలాగే ఉంచుతుంది. శ్వాస వాడకపోయినా ఎంచుకోవచ్చు; bit పెరగదు. ఇతర కారణాల ఊగుడును ఈ సెట్టింగ్ ఆపదు.

అనేక భంగిమ సాధనాల్లో ఒక్కదానిలో సాధారణ ఊగుడు ఆపినా మొత్తం అవతార్‌కు వర్తిస్తుంది. తిరిగి రావడానికి అన్ని సాధనాల్లో ఆపి మళ్లీ అప్‌లోడ్ చేయండి.

### తల భ్రమణంతో భంగిమ వక్రీకరణ తగ్గించు

మెడ లాక్ విడదీసినప్పుడు అసలు భంగిమతో మెడ దిశ తేడా వల్ల భంగిమ వక్రీకరిస్తే వాడండి. «ఫీచర్లు > సౌకర్య ఎంపికలు»లో ఉంది; ఆటలో ప్రత్యేక మెనూ జోడించదు. మెడ లాక్ ఉన్నప్పుడు అసలు భంగిమ దిశ వాడుతుంది. వెల్లకిలా భంగిమలో అసలు పైదిశను ఉంచడానికి సవరణ నుంచి మినహాయిస్తుంది.

### మెనూ చిహ్న చిత్రాలు

- «భంగిమ చిహ్నాలు సృష్టించు»: అవతార్ ప్రతి భంగిమ తీసుకున్న చిత్రాలను సృష్టించి మెనూలో చూపుతుంది. భంగిమలను గుర్తించడం సులభం; చిత్ర సృష్టి వల్ల బిల్డ్ సమయం పెరుగుతుంది.
- «చిహ్నం పరిమాణం తగ్గించు»: చిత్ర రిజల్యూషన్ తగ్గించి అవతార్ పరిమాణం తగ్గిస్తుంది.

Android బిల్డ్‌లలో భంగిమ చిహ్నాలు సృష్టించదు. దుస్తులు వంటివి మార్చాక «చిహ్నాల చిత్రాలు మళ్లీ తీయి» వాడండి. భంగిమ జాబితా చిత్రాలకు «భంగిమ చిన్న చిత్రాలను నవీకరించు» వాడండి. సమయం పట్టే ప్రక్రియ కాబట్టి నిర్ధారణ సందేశం చదివి కొనసాగండి.

## భంగిమ జోడింపు, క్రమం, ముందుచూపు

«భంగిమలు» ఎడమవైపు రకాన్ని ఎంచుకోండి. పైనున్న భూతద్దం ట్యాబ్‌తో అన్ని రకాల పేర్లను వెతకవచ్చు. «వివరాలు» తెరిచి యానిమేషన్, చిహ్నం, MotionTime వంటివి కలిపి అమర్చవచ్చు.

అనేక యానిమేషన్‌లను జోడింపు ప్రాంతంలోకి లాగి వదలండి; లేదా Projectలో ఎంచుకుని «Projectలో ఎంచుకున్న క్లిప్‌లు దిగుమతి చేయి» నొక్కండి. ఒకే క్లిప్ నకళ్లు తొలగిస్తారు.

క్రమం మార్చడానికి «వివరాలు»లో «క్రమం»తో గమ్యాన్ని ఎంచుకోండి. పైకి/కిందికి బటన్‌లూ వాడవచ్చు. మార్చినా వివరాలు తెరిచిన/మూసిన స్థితి అలాగే ఉంటుంది.

ప్రతి భంగిమ «ముందుచూపు» నొక్కితే సర్దుబాటు కిటికీ తెరవకుండా Sceneలో చూపుతుంది. ముగిస్తే అసలు ప్రదర్శనకు వస్తుంది. ఈ సరళ ముందుచూపు MA లేదా NDMF బిల్డ్‌ను నడపదు; అందువల్ల బిల్డ్‌లో చేరే దుస్తులు, FloorAdjuster తదితరాల తుది ఫలితం వేరుగా ఉండవచ్చు. అవతార్ బిల్డ్ తర్వాత దుస్తులు, నేల తాకడాన్ని కూడా తనిఖీ చేయండి.

## యానిమేషన్ సర్దుబాటు, స్వయంచాలక చేతికాళ్ల సర్దుబాటు (IK)

«భంగిమలు»లో «యానిమేషన్ సర్దుబాటు» తెరిస్తే ముందుచూపుతో శరీరం, చేతికాళ్లను సూక్ష్మంగా సర్దవచ్చు. పూర్తయ్యాక కిటికీలోని భద్రపరిచే చర్యతో సర్దుబాటు యానిమేషన్‌ను భద్రపరచండి.

స్వయంచాలక చేతికాళ్ల సర్దుబాటుకు మద్దతున్న ఉత్పత్తులు/భంగిమల్లో అవతార్ శరీరాకృతికి అనుగుణంగా చేతికాళ్ల స్థానాలు మారతాయి. యానిమేషన్ సర్దుబాటు తెరలో «స్వయంచాలక చేతికాళ్ల సర్దుబాటు సక్రియం చేయి»తో మొత్తానికీ, «ఈ భంగిమకు IK సక్రియం చేయి»తో ఒక్కో భంగిమకూ మార్చవచ్చు. స్వయంచాలక సర్దుబాటు లేని భంగిమలకు ఆ సమాచారం కనిపిస్తుంది.

స్వయంచాలక సర్దుబాటుతో మొదలుపెట్టి చేతితో పూర్తి చేయాలంటే «IK ఫలితాన్ని సర్దుబాటులో స్థిరపరచు» నొక్కండి. అప్పటి IK ఫలితాన్ని కొత్త సర్దుబాటు యానిమేషన్‌లో రాసి ఆ అవతార్‌లోని ఆ భంగిమకు IK ఆపుతుంది. అసలు యానిమేషన్ అలాగే ఉంటుంది. మొత్తానికీ, ఆ భంగిమకూ స్వయంచాలక సర్దుబాటు సక్రియమై అనుకూల IK సెట్టింగ్‌లు ఉంటే ఈ బటన్ వాడవచ్చు.

«అవతార్ అమరిక»లో «మోకాలు వెనక్కి వంగకుండా ఆపు» మోకాలి సవరణను మారుస్తుంది. వివరాల్లో «కనిష్ఠ మోకాలి వంపు (డిగ్రీలు)»తో కోణం పెట్టండి. సంబంధిత సవరణ డేటా ఉన్నప్పుడు «అవతార్ సవరణ సక్రియం చేయి» అందుబాటులో ఉంటుంది. స్వయంచాలక చేతికాళ్ల సర్దుబాటుతో అతివ్యాప్తి చేసే కొన్ని సవరణలను కలిపి వాడలేరు.

## అసలు భంగిమలు, సొంత కదలికలు, ప్రీసెట్‌లు

వీటిని «అవతార్ అమరిక»లో అమర్చండి.

- «అసలు నిలబడే, వంగే, బోర్లా భంగిమలు వాడు»: అవతార్‌లో మొదట ఉన్న భంగిమలను స్వయంగా దిగుమతి చేస్తుంది.
- «మీ సొంత కదలికలు వాడు»: దిగుమతి సెట్టింగ్‌లు తెరిచి నిలబడడం, వంగడం (Crouching), బోర్లా (Prone) వంటి ప్రతి రకానికి విడిగా కదలికను ఇవ్వండి. సాధారణంగా ఒక్కో రకానికి ఒక్క కదలిక పెట్టండి.
- «ఇతర సాధనాలతో ట్రాకింగ్ లాక్‌లను కలుపు»: ఇతర సాధనాలతో వాడినప్పుడు లాక్‌లు సరిగా పనిచేయకపోతే సక్రియం చేయండి.

మీ కదలికలను నిర్దేశించే దిగుమతి సెట్టింగ్‌లు, అసలు భంగిమలను స్వయంగా దిగుమతి చేసే సెట్టింగ్‌కి వేరైనవి.

ప్రీసెట్‌లు ట్యాబ్ అడుగున ఉన్నాయి. పేరుతో వెతికి «ఈ ప్రీసెట్ వర్తింపజేయి»తో భంగిమ సెట్టింగ్‌లను మార్చండి. ప్రధానంగా ప్రారంభ అమరికకు ఉద్దేశించినవి; ప్రస్తుత సెట్టింగ్‌లను భర్తీ చేస్తాయి కాబట్టి సర్దుబాట్లు ఉంటే ముందుగా భద్రపరచండి.

ప్రీసెట్ జాబితా చూపేటప్పుడు పేర్లు, అనుకూల అవతార్ సమాచారం మాత్రమే లోడ్ అవుతాయి; సర్దుబాటు యానిమేషన్‌లు ఎంచుకున్న ప్రీసెట్ వర్తింపజేసేటప్పుడు లోడ్ అవుతాయి. మొదటి జాబితా సృష్టిలోనూ అన్ని అవతార్‌ల యానిమేషన్‌లను ముందుగా లోడ్ చేయదు.

జాబితా «అవతార్‌కు సరిపోతుంది», «వినియోగదారు ప్రీసెట్‌లు», «Unisaki Studio అధికారిక ప్రీసెట్‌లు»గా విభజించబడింది. «చేర్చిన ప్రీసెట్‌లను దాచు» ఒకే ప్రాజెక్టులో ఉమ్మడి ప్రదర్శన సెట్టింగ్. ప్రీసెట్ జోడింపు/మార్పు/తొలగింపుతో జాబితా నవీకరిస్తుంది. ప్రదర్శన మారకపోతే «మళ్లీ లోడ్ చేయి» నొక్కండి.

## ప్రీబిల్డ్, హెచ్చరికలు

«అసలు నిలబడే, వంగే, బోర్లా భంగిమలు వాడు» ఆన్ అయితే ప్రతి సృష్టిలో అవతార్ Base నుంచి కదలికలను గుర్తిస్తుంది. ఫలితాలను చేతితో చేసిన దిగుమతి సెట్టింగ్‌లలో రాయదు కాబట్టి స్వయంచాలక దిగుమతి మాత్రమే వాడితే జాబితా నిర్దేశించనట్లే ఉంటుంది. Base కదలిక మార్పులు, స్వయంచాలక దిగుమతి ఆన్/ఆఫ్ తదుపరి సృష్టిలో వర్తిస్తాయి.

అప్‌లోడ్ సమయంలో స్వయంచాలక దిగుమతి బిల్డ్ కాపీకి వర్తిస్తుంది. సీన్‌లోని అసలు వస్తువు, దిగుమతి సెట్టింగ్‌లు, మూల Controller/కదలికలను మార్చదు. ప్రీబిల్డ్ ఉండి ఇన్‌పుట్ మారకపోతే ఆ ఫలితాన్ని మళ్లీ వాడుతుంది.

చేతితో ఎంపిక చేసిన రకాల్లో దానికి ప్రాధాన్యమిస్తూ భ్రమణం, సర్దుబాటు యానిమేషన్, ప్లేబ్యాక్ స్థానం కూడా వర్తిస్తాయి. «ఉపయోగించు» ఆపిన సెట్టింగ్ లేదా నిర్దేశించిన కదలికను తీసేసిన సెట్టింగ్ ఆ రకం స్వయంచాలక దిగుమతిని ఆపుతుంది. «చేతితో చేసిన ఎంపికను తుడిచివేయి»తో ఆ రకం అమరిక/సర్దుబాటు తొలగిస్తే స్వయంచాలక దిగుమతి ఆన్‌లో ఉన్నప్పుడు తదుపరి సృష్టిలో మళ్లీ గుర్తిస్తుంది. Undoతో వెనక్కి తేవచ్చు. ఒకే రకానికి అనేక పాత సెట్టింగ్‌లు ఉంటే Inspectorలో ఎంచుకున్న క్రియాశీల సెట్టింగ్‌కు ప్రాధాన్యం.

పాత స్వయంచాలక దిగుమతి జాబితాలో చేర్చిన సెట్టింగ్‌లను చేతితో నమోదు/సర్దిన వాటినుంచి వేరు చేయలేము కాబట్టి స్వయంగా తొలగించదు. తిరిగి స్వయంచాలక దిగుమతి కావలసిన రకాలకు మాత్రమే «చేతితో చేసిన ఎంపికను తుడిచివేయి» వాడండి. ఒకే అవతార్‌లో అనేక ఉత్పత్తులు ఉంటే ఇతర ఉత్పత్తుల చేతి సెట్టింగ్‌లు కూడా ఉమ్మడి అసలు భంగిమలకు వర్తిస్తాయి.

ప్రీబిల్డ్ సృష్టించిన డేటాను మళ్లీ ఉపయోగించి అవతార్ బిల్డ్ సమయాన్ని తగ్గిస్తుంది. «ప్రీబిల్డ్ నవీకరించు»తో సృష్టించవచ్చు/నవీకరించవచ్చు. సాధారణ అవతార్ బిల్డ్ కూడా అవసరమైన డేటాను సృష్టిస్తుంది కాబట్టి ప్రతిసారీ చేతితో ప్రీబిల్డ్ అవసరం లేదు.

సెట్టింగ్‌లు మార్చితే నవీకరణ అవసరమై Inspector పైభాగంలోని «సెట్టింగ్‌లను తనిఖీ చేయి» లేదా Hierarchy గుర్తు తెలియజేస్తుంది. భంగిమ/IK సెట్టింగ్‌లు మార్చాక ప్రీబిల్డ్ నవీకరిస్తే తదుపరి బిల్డ్ సమయం తగ్గుతుంది.

«హెచ్చరిక ప్రదర్శన సెట్టింగ్‌లు», «సెట్టింగ్‌లను తనిఖీ చేయి» పెట్టెలో ఉన్నాయి. హెచ్చరిక రకాలనో Hierarchy గుర్తులనో దాచవచ్చు. దాచడం వల్ల సెట్టింగ్ సమస్య పరిష్కారం కాదు; సృష్టించిన డేటా నవీకరించబడదు. లోపాలు, అవసరమైన సృష్టి చర్యలు అలాగే ఉంటాయి.

## వినియోగ గమనికలు

- మూడు పాయింట్ల ట్రాకింగ్, డెస్క్‌టాప్ వినియోగానికి ఉద్దేశించబడింది. పూర్తి శరీర ట్రాకింగ్‌లో భంగిమ లాక్‌కు మద్దతు లేదు.
- శరీరాకృతి, మార్పులను బట్టి చేతికాళ్ల నేల తాకడం, దుస్తుల రూపానికి అదనపు సర్దుబాట్లు అవసరం కావచ్చు.
- ప్రత్యేక Base లేయర్లు లేదా ఇతర భంగిమ మార్చే సాధనాలతో ఆశించినట్లు పనిచేయకపోవచ్చు.
- ఫోటో మోడ్ కదలిక/భ్రమణం, నేల ఎత్తు సాధనం భంగిమలను, ఎంపిక లేనప్పటి సాధారణ/సొంత కదలికలను సవరిస్తాయి. VRChatలో మార్చే సాధారణ కదలికలు, దృక్కోణ ప్రవర్తనను నిజమైన క్లయింట్‌లో తనిఖీ చేయండి.
