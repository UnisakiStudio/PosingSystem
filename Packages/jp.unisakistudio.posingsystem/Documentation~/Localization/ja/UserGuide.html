ゆにさきポーズシステム 3.2.0 — 使い方

ゆにさきポーズシステムは、可愛いポーズツール・カッコいいポーズツールなどで使う共通システムです。購入した商品と一緒にVCCまたはALCOMから導入してください。必要環境はUnity 2022.3、VRChat Avatars SDK 3.10.4以上、Modular Avatar 1.15.1以上、NDMF 1.14.0以上です。

表示言語

ツールのInspector最上部の Language / 言語 で選択します。一つの選択がInspectorと生成するVRChatメニューに適用されます。言語を変更したらアバターを再アップロードしてください。最後の選択は、このパソコンの同じOSユーザーの別プロジェクトでも使用します。未選択の場合はOSの言語を使い、対応していない言語では英語を使います。既存のアバターに保存済みの明示的な選択は維持します。別のパソコンには同期しません。

アバターへの追加

HierarchyでVRC Avatar Descriptorのあるシーン上のアバターを選び、ゆにさきスタジオ > 可愛いポーズツール追加 または カッコいいポーズツール追加 を選択します。対応するアバタープリセットが案内されたら適用してください。Inspectorには 機能・ポーズ一覧・アバター調整 の3タブがあります。使う姿勢と機能を選び、体格に合わせて調整した後、通常どおりアップロードします。プレビルドを使っている場合は、設定変更後に プレビルドを更新 を押してください。

詳しいマニュアル

購入した商品のInspectorで 使い方 を開くと、選択言語のオフラインガイドを読めます。商品の Documentation~/UserGuide.en.html には、導入、体格に合わせた調整、VRChat内の操作、ポーズ編集、パラメーター使用量、更新、トラブルへの対処がまとまっています。標準姿勢名は表示用に翻訳します。独自の名前、アバター名、アセットのファイル名、保存済みオブジェクト名、パラメーター識別子は元の表記を維持します。30言語から選択でき、Inspector・導入ダイアログ・標準姿勢名・生成メニューには全言語の表示データを同梱しています。各選択言語のオフライン文書も用意しています。

30言語の簡易リファレンスには、機能の説明と標準姿勢名の対照表があります。簡潔な参照用の文書です。全文書は言語一覧から開いてください。

ライセンスとサポート

購入したストアからダウンロードしたインストーラーを使用してください。商品ライセンスは従来のユーザー別レジストリ／ファイルへ保存し、EditorPrefsとは別に扱います。同梱の元の利用規約をお読みください。既存の共通システムの英語規約は参照訳です。各商品の規約も別途同梱しています。
