変更履歴

[3.2.0] - 未リリース

追加

  • Inspector、編集操作、導入ダイアログ、標準姿勢名、生成するVRChatメニューを30言語で表示できるようにしました。
  • Inspectorとゲーム内メニューの言語選択を統一しました。初期値はパソコンの言語を使い、最後の選択を同じOSユーザーの別プロジェクトでも使用します。
  • README・変更履歴・オフラインの使い方を選択言語で開けるようにしました。
  • 標準姿勢128件の表示名と各機能の説明を、既存の用語に合わせて用意しました。

互換性

  • アバターの既存設定、独自の名前、アセット参照、パラメーター識別子、ライセンスの保存方法を維持します。

[3.1.4] - 2026-11-11

  • アバター固有のしゃがみ・伏せに指定したアニメーションが反映されず、VRChat標準の姿勢になる問題を修正しました。自動取り込みと手動指定の両方が対象です。
  • ポーズの編集・プレビュー中に、MA Bone Proxyで取り付けた髪や眼鏡などが元の位置に残る問題を修正しました。元のアバターの設定や配置を保ったまま、プレビューの姿勢に追従します。
  • 「仰向け寝_お疲れ」などのポーズ画像を撮るとき、視点位置を使った姿勢補正に失敗する問題を修正しました。画像には、ビルド時の姿勢補正や床の調整を反映したアニメーションを使います。

ALCOM / VCCで「ゆにさきポーズシステム」を3.1.4に更新してください。「可愛いポーズツール」3.1.2・「カッコいいポーズツール」1.1.0はそのまま使えます。プレビルドを使っていた方は、更新後に「プレビルドを更新」を押してシーンを保存し、アバターを再度ビルド・アップロードしてください。

[3.1.3] - 2026-11-09

  • 複製したアバターで「ポーズ画像を更新」やプレビルドをしても、元のアバターのポーズ画像が消えなくなりました。
  • 初めてシーンを保存する前やPrefabの編集画面でプレビルドした場合に、画像を撮り直しただけで「設定の更新あり」と表示される問題を修正しました。
  • 以前のプレビルドで作ったポーズデータが残っていると、次のプレビルドが途中で止まることがある問題を修正しました。
  • ポーズ画像がまだないときに一覧を開く処理を軽くしました。プレビルドやビルドの開始時に、パッケージ情報の取得が終わるまでUnityの操作が止まる処理も見直しました。
  • アバター内で無効にしているポーズツールの編集用設定も、PC版・Android版のビルド時に取り除くようにしました。
  • 「このエラーについて相談する」で、Consoleの先頭に原因を読み取れないエラーが並んでいても、後ろにある診断番号などを下書きに含められるようにしました。寝返りのクリップ設定でエラーが出たときは、確認箇所も下書きに入ります。

ALCOM / VCCで「ゆにさきポーズシステム」を3.1.3に更新してください。「可愛いポーズツール」3.1.2・「カッコいいポーズツール」1.1.0はそのまま使えます。これらの商品が以前の共通バージョンを指定しているため、更新時に競合の確認が出ることがあります。プレビルドを使っていた方は、更新後に「プレビルドを更新」を押し、シーンを保存してからアバターを再度ビルド・アップロードしてください。

[3.1.2] - 2026-11-09

  • 「首の向きの違いによる姿勢崩れを抑制」をオンにしていると、伏せから立ち上がったあとも顔が上を向いたままになる問題を修正しました。
  • 「足の高さ」をオフにしても、EXメニューの「設定 → あおむけ時自動頭固定」で頭の固定を切り替えられるようになりました。3.1.0・3.1.1で項目が消えたアバターも、更新後にビルドすると項目が戻ります。
  • Unityでアバター本体のチェックを外していても、「プレビルドを更新」できるようになりました。
  • 旧版の共通ポージングControllerがAssetsに残っていると、更新後にポーズを生成できないことがある問題を修正しました。ご自身で編集したControllerの設定も引き継ぎます。
  • ツールやその親が無効で共通ポージングAnimatorを使えないときは、対象の名前を表示します。「設定の確認 → 対象を選択」からその場所を開けます。
  • プレビルドに「設定の更新あり」と表示されたとき、「詳細 → 保存時から変わった項目を確認」で、前回と違う設定を確認できるようになりました。
  • スクリプトのエラーでビルドが止まったとき（PS050）は、Unityが検出した元のエラーを最大5件表示します。「このエラーについて相談する」から、Unityや対応ツールのバージョンとエラー番号が入った下書きを確認・編集して送信できます。

プレビルドを使っていた場合は、更新後に「プレビルドを更新」を押してシーンを保存し、アバターを再度ビルド・アップロードしてください。

[3.1.1] - 2026-11-08

  • 「左右反転」をオフにしても、有効にした「床の高さ」と「寝返り」がVRChatのEXメニューの「設定」に表示されるようになりました。
  • 旧版でポーズを並べ替えたり、削除・改名したりしても、「足伸ばし」「リラックス」「膝立て」にそれぞれ正しい寝返りを引き継ぎます。完全にUnpackした場合も、元のポーズを特定できれば引き継ぎます。自作ポーズや、ご自身でオフにした寝返り、差し替えた横向きモーションは保持されます。
  • VRChatのアバター選択時に、一瞬うつ伏せになる問題を修正しました。うつ伏せだけを選んだ状態でジャンプすると一瞬仰向けになる問題も修正しました。ジャンプでの切り替えは「機能 → 便利機能 → ジャンプで寝姿勢を切り替える」でオフにできます。初期設定はオンです。
  • 更新後に共通ポージング用のAnimator Controllerの参照が外れた場合、復元できるときは警告を表示して設定から作り直します。複数のアバターで共有しているControllerの参照も保持します。
  • プロジェクトにコンパイルエラーがあるときは、ビルドの最初に原因を案内して停止します。スクリプトのエラーで参照を確認できない間は、生成済みControllerの自動整理を見合わせます。
  • プロジェクト内に商品と同名のPrefabがあっても、ツール追加時に正式なPrefabを優先します。共通Controllerの改行だけが違う場合もプレビルドを続行できます。
  • ポーズツールが追加するFXレイヤー（床の高さなど）のWrite Defaultsを、アバター側の設定に合わせるようにしました。

プレビルドを使っていた場合は、更新後にシーン上のツールで「プレビルドを更新」を押してシーンを保存し、アバターを再度ビルド・アップロードしてください。

[3.1.0] - 2026-11-07

  • 対応ポーズの手足を体格に合わせる自動調整（IK）と、アバター固有補正・膝の逆曲がり防止に対応しました。
  • 撮影モードでアバターの位置と向きを調整できます。位置・向きの同期と、撮影中の自分の頭の表示も選べます。
  • 「床の高さ」で身体全体を上下3mまで移動できます。「足の高さ」と使い分けられます。
  • 呼吸の動き、標準の待機中の揺れを止める設定、首の向きによる姿勢崩れを抑える設定を追加しました。
  • 使用する機能とパラメーター使用量をInspectorで確認できます。ポーズ検索・一括追加・並べ替え・Sceneでの簡易プレビューにも対応しました。
  • デスクトップモードの立ち・中腰・座りの切り替えを高速化しました。
  • 設定変更後のプレビルド警告、Inspectorのスクロール負荷、生成物整理時の長時間停止を改善しました。
  • 自動取り込みがONのとき、設定を変えていないプレビルドに更新警告が出て、アップロード時に再生成する問題を修正しました。取り込み結果は生成するアバターへ反映し、元オブジェクトの取り込み設定は変更しません。
  • 頭の傾きによる寝返りと、ポーズごとの対応モーション設定を追加しました。
  • 旧プリセットの寝返り設定の引き継ぎ、自作モーションの取り込み、生成アセットの管理を改善しました。

[3.1.0-beta.2] - オープンベータ版（2026-11-05）

  • IKの「位置の長さの基準」に、固定長と、HeadからViewpointまでの高低差（Y）・前後差（Z）を追加。
  • Inspectorの警告をHierarchyのオブジェクト名の左にも表示。プレビルド未実行・設定変更のほか、モーション取り込みやプリセット操作で表示中の警告にも対応。
  • シーンを開いたときなどの生成物の自動整理で、別シーンの生成Controllerを読み込んでUnityが長時間止まる問題を修正。
  • ポーズ一覧や機能を変更したときにプレビルド履歴が消える問題を修正。「未実行」ではなく「プレビルド後に設定が変更されています」と表示し、Hierarchyにも更新が必要な警告を表示。
  • Inspector・Hierarchy表示用のプレビルド比較結果を共有し、設定や参照アセットが変わっていない間のスクロール負荷を軽減。ビルド時の比較は従来どおり毎回実行。

[3.1.0-beta.1] - オープンベータ版（2026-11-04）

  • デスクトップモードの通常姿勢切り替えを1評価方式へ変更。通常のビルドとプレビルドで有効になり、VRや特殊条件は従来の経路を維持。
  • alpha.3以前のプレビルドを更新対象として認識。
  • 撮影中に床の高さを変えたときの視点を保持し、撮影終了後に最新の床の高さへ復帰。
  • 自動取り込みを生成時だけの検出に変更し、プレビルド／ビルドで手動の取り込み設定を追加・変更しないよう修正。
  • 自動取り込みのON/OFF、Baseの変更、手動設定の解除を再生成へ反映。複数製品で共有する手動指定と調整を保持し、古い取り込みモーションを標準姿勢へ戻す。
  • プレビルドの生成ControllerをシーンGUID別・アバターごとの1ファイルで管理。複製・別シーン・Prefabからの共有参照は更新前に分離。
  • ビルド時はNDMFの一時アセット管理を使用し、編集用の生成ファイルを増やさない。
  • シーンを開いた時と保存時に生成物を確認。未保存編集・Undo/Redo・外部参照がある場合は保持し、所有が明確な未使用ファイルだけをごみ箱へ移動。
  • 取り込みモーションの回転・調整アニメーション・再生位置指定を反映。回転・RootT/RootQ・Humanoid調整の処理を通常ポーズと共通化。
  • 入れ子BlendTreeの調整は取り込み先専用に複製し、元モーションと歩行用のブレンド設定を保持。
  • 「立ちのみ」の再生位置指定は元フレームレートで静止姿勢へ展開し、歩行側の再生を停止しない。

[3.1.0-alpha.2] - クローズドテスト版（2026-10-26）

修正・変更

  • ツールポーズ未選択時の標準・独自モーションにも撮影モードと床の高さの補正を適用。
  • 床の高さを上下3mへ拡張。50%を元の高さと初期値、0%を3m下、100%を3m上に変更。
  • 「立ちのみ」の上書きで取り込み元BlendTreeを変更する問題を修正。
  • IKルールのない姿勢では手動補正を使用し、不要な生成警告を抑制。
  • 同名ポーズの調整下書きの混同、同一アセット内のモーション変更の見落としを修正。
  • 無効な初期ポーズの番号が別ポーズを初期選択する問題を修正。
  • 非対応AnimatorOverrideControllerの取込み時に例外の代わりに案内を表示。
  • 旧プリセット適用時に明示的な寝返りOFFを保持。
  • 明るいEditorテーマで機能アイコンを見やすく改善。

VRChatクライアントでの視点・標準モーション置換後の確認は継続中です。

[3.1.0-alpha.1] - 公開前

追加

  • 機能ごとのON/OFFと、ExpressionParameters使用量の表示を追加。
  • アバターを前方へ移動・回転できる撮影モードを追加。
  • 撮影モードの同期を選択する設定を追加。ローカルのみは0 bit、同期時は16 bit。
  • 撮影モード中、自分のアバターの頭を非表示にしない設定を追加。
  • 頭を含む身体全体を上下3m移動する「床の高さ」を追加。50%が元の高さと初期値、0%が3m下、100%が3m上。
  • 頭の傾きに合わせた寝返りと、ポーズごとの対応アニメーション設定を追加。
  • 呼吸の動きと、弱・中・強・急・カスタムの設定を追加。
  • 呼吸の動きとゲーム内ON/OFFメニューを個別に選択する設定を追加。動きのみは0 bit、ON/OFFの同期は1 bit。
  • VRChat標準の待機動作による揺れを止める設定を追加。
  • 首の向きの違いによる姿勢崩れを抑制する設定を追加。
  • 対応ポーズを体格に合わせる手足の自動調整（IK）と、アバター全体・ポーズごとのON/OFFを追加。
  • IKの結果を調整アニメーションへ保存する「IKを調整に反映」を追加。
  • アバター固有の姿勢補正と、膝の逆曲がり防止・最低曲げ角度の設定を追加。
  • ポーズ一覧からSceneで姿勢を確認する簡易プレビューを追加。
  • ポーズの分類別タブ、横断検索、複数アニメーションの一括追加、移動先の順番指定を追加。
  • Inspector内で商品・共通システムの変更履歴を表示する機能を追加。

変更

  • プリセットの読み込みを高速化し、ツール追加時やプリセット一覧表示時の待ち時間を短縮。
  • プリセットの追加・編集・削除を一覧へ自動反映するよう改善。
  • Inspectorを「機能」「ポーズ一覧」「アバター調整」の3タブに整理。
  • 設定項目に説明とアイコンを追加し、詳細設定の開閉表示を統一。
  • 呼吸の詳細を機能設定内へ、プリセットをアバター調整の末尾へ移動。
  • 自作モーションの個別指定と、アバターの元の姿勢の自動取り込みを別の設定に整理。
  • 足の高さ調整で生成する全身アニメーションの重複を削減。
  • ポーズ画像更新を確認ダイアログ付きのボタンに変更。
  • 警告の表示設定を「設定の確認」内に集約。
  • 8bit専用Prefabの新規追加を廃止し、通常Prefabの機能選択に統一。既存の参照は維持。
  • VRChat Avatars SDKの最低バージョンを3.10.4へ変更。

修正

  • ツールポーズ未選択時の標準・独自モーションも、撮影モードと床の高さの補正対象に変更。
  • 「立ちのみ」の上書き時に、取り込み元のBlendTreeを変更してしまう問題を修正。
  • 有効なIKルールがない姿勢では手動調整を使用し、不要なIK生成警告を抑制。
  • 同名ポーズの調整内容が混ざる問題と、同じアセット内のモーション差し替えが再生成に反映されない問題を修正。
  • 無効化した初期ポーズの番号が別のポーズに再利用されても、初期選択されないよう修正。
  • 元の姿勢の取り込みで非対応のAnimatorOverrideControllerを検出した場合、例外の代わりに案内を表示。
  • 旧プリセットの適用時に、明示的にOFFにした寝返り設定を保持。
  • 明るいEditorテーマでも機能アイコンを識別できるよう、Inspectorのアイコン背景を改善。
  • アバターへの追加時に「寝返り」「床の高さ」「撮影モード」のアイコンが表示されない問題を修正。
  • 旧バージョンのプリセットを適用すると、対応ポーズの寝返り設定が失われる問題を修正。
  • ポーズ名の編集中に別の詳細を開くと、入力が別のポーズへ移る問題を修正。
  • ポーズの並べ替えで詳細が閉じる問題と、設定変更のUndo・Redo処理を修正。
  • プレビューで元のアバターが重なる問題と、配置位置が二重に加算される問題を修正。
  • 欠けたコンポーネントを持つアバターのプレビューでエラーになる問題を修正。
  • アバターの骨の向き・スケールの違いによる、IKの手足の向きや位置のずれを修正。
  • 設定変更直後に警告やプレビルドの状態が更新されない問題を修正。
  • IK設定の変更後に古いプレビルド結果を再利用する問題を修正。
  • 一部の構成で追加機能の生成に失敗するビルドエラーを修正。
