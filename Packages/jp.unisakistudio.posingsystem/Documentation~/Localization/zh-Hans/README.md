# Unisaki Posing System

这是Kawaii Posing Tool、Cool Posing Tool等产品使用的共用姿势系统。通过Modular Avatar和NDMF，在上传虚拟形象时生成所需的菜单和动画。

本README面向开发中的v3.2.0。正式发布日期尚未确定。已安装的版本可在姿势工具的Inspector顶部查看。另请参阅[新增功能与更新记录](CHANGELOG.md)。

## 显示语言与离线文档

在Inspector最上方的“Language / 言語”中选择显示语言。同一项选择会同时应用于Inspector和生成的VRChat菜单。要更改游戏内的显示语言，请重新上传虚拟形象。

未选择语言时，使用计算机的语言；不支持该语言时使用英语。支持Windows、macOS和Linux。最后选择的语言保存在EditorPrefs中，同一台计算机上同一个OS用户的其他项目也会使用此设置。所有姿势工具和虚拟形象都使用同一种语言。在任意工具的Inspector中更改语言，都会更新共用设置；不采用单个虚拟形象的语言选择。语言设置不会同步到其他计算机。许可证的保存方式不变。 仅在尚未保存语言时的首次安装确认中显示语言按钮。之后请在Inspector中更改语言。

可通过随附的[语言列表](../index.html)选择README、更新记录和使用说明。Inspector中的“使用说明”和“更新记录”也会遵循所选语言。原始使用条款和参考译文仍按原有方式另行提供。

## 桌面模式下的姿势切换

在桌面模式下切换站立、半蹲和坐姿时，缩短了所选姿势生效前的延迟。普通构建和预构建均会启用此改进，无需专用命令或额外设置。VR模式及特殊状态下保留原有处理方式。使用旧版预构建时，请先更新预构建再上传。

## 安装与版本更新

请按照各商品购买文件中的安装说明，通过VCC或ALCOM添加姿势工具。本系统会作为姿势工具的依赖软件包一同安装。

v3.2.0所需环境如下。

- 使用Unity 2022.3的VRChat虚拟形象项目
- VRChat Avatars SDK 3.10.4或更高版本
- Modular Avatar 1.15.1或更高版本，须为1.x系列
- NDMF（Non-Destructive Modular Framework）1.14.0或更高版本，须为1.x系列

使用Kawaii Posing Tool时，请在ALCOM / VCC中将其更新为3.2.0，并确认Unisaki Posing System也已更新为3.2.0。如果使用过预构建，请点击“更新预构建”，保存场景后再上传虚拟形象。

Cool Posing Tool 1.2.0使用共用系统3.2.0。请将商品和共用系统一同更新至对应版本。

### 曾使用8bit版本的用户

新添加的对象统一使用普通Prefab。在“功能”中关闭不需要的项目，可以降低参数用量。仅使用姿势选择时，基本用量为8 bit。

为保留已放置的虚拟形象和预设的引用，各商品的旧8bit版Prefab仍保存在“Editor/Legacy”中。继续使用现有8bit版本时，无需删除或替换Prefab。Unity新建菜单中选择8bit版本的操作已取消。

## 设置界面说明

在Hierarchy中选中虚拟形象内的“可愛いポーズ”“カッコいいポーズ”等对象，即可进行设置。

| 选项卡 | 设置内容 |
| --- | --- |
| 功能 | 添加到游戏内菜单的项目、便捷功能、图标图片、ExpressionParameters用量 |
| 姿势 | 选择、添加和调整姿势顺序，在Scene中预览，各姿势的详情与动画调整 |
| 头像设置 | 根据体型进行修正、膝部修正、导入原始姿势或自定义动作、预设 |

有详细设置的项目可点击“打开设置”，在其下方展开设置区域。呼吸设置也位于“功能”中。

可通过顶部的“帮助 / 更新记录”打开使用说明、咨询页面和更新记录。更新记录可在商品和Unisaki Posing System之间切换查看。

## 功能与ExpressionParameters用量

在“功能”的“菜单功能”中选中的项目会显示在游戏内菜单中。例如，选中“左右镜像”后，就能在游戏内切换镜像。仅在Inspector中选中此项，并不意味着始终对所有姿势进行镜像。

| 功能 | 额外使用的bit数 |
| --- | ---: |
| 左右镜像 | 1 bit |
| 禁用手势 | 1 bit |
| 启用呼吸动画 | 0 bit |
| 呼吸（游戏内开关） | 1 bit |
| 脚部高度 | 8 bit |
| 地面高度 | 8 bit |
| 拍照模式（仅自己的画面） | 0 bit |
| 同步拍照模式 | 16 bit |
| 拍照模式中保持头部可见 | 0 bit |
| 关闭VRChat默认站立摇摆 | 0 bit |
| 减轻头部旋转造成的姿势变形 | 1 bit（与翻身共用） |
| 翻身 | 10 bit（其中1 bit与姿势变形抑制共用） |

翻身功能的用量分别为：开关1 bit、头部倾斜8 bit、颈部固定1 bit。如果已经启用姿势变形抑制，添加翻身功能时新增用量为9 bit。共用部分不会重复计算，更改勾选项时显示用量也会更新。

显示的合计值仅涵盖安装在该虚拟形象中的姿势工具，不是包含服装和其他功能组件在内的整个虚拟形象的总量。并用多个姿势工具时，共用设置也不会重复计数。当姿势数量超出基本编号范围时，姿势选择还需要额外的bit。

### 脚部高度与地面高度

- “脚部高度”：保持头部位置，调整脚部一侧的高度。用于让脚与地面或床面贴合。
- “地面高度”：上下移动包含头部在内的整个身体。50%为原始高度，0%为向下3m，100%为向上3m。初始值为50%。

两者均位于游戏内的“设置”中，“地面高度”排在“脚部高度”之后。将“地面高度”从中央移开时会上下移动，恢复至50%附近时会返回原始高度并结束修正。没有单独的悬浮开关。视点修正在开始悬浮及操作地面高度时进行。

脚部高度的处理方式已改为：对于普通动画，不再为了高度调整而重复生成全身动作。这样可减少所生成动画的数据量，但并不表示整个虚拟形象的体积一律缩小至原来的3分之1。

### 拍照模式

1. 启用“功能 > 菜单功能 > 拍照模式”。
2. 在VRChat中打开“拍照模式”，通过“选择姿势”选择姿势。
3. 使用“距离”向前移动，最远可达3m，使用“朝向”进行旋转。距离大于0时，虚拟形象会朝向自己。
4. 按需启用“固定双脚”。启动时不会强制固定双脚，因此可在固定前调整位置。如果在菜单中添加了“禁用手势”，也可以在同一界面切换手型。
5. 通过“结束拍照”恢复距离和朝向，并解除双脚固定。

拍照模式的移动和旋转仅在自己的画面中使用时，用量为0 bit。希望其他人也能看到位置和朝向时，请启用“便捷功能 > 同步拍照模式”。距离和朝向合计使用16 bit。

如果自己的虚拟形象靠近时头部消失，请启用“便捷功能 > 拍照模式中保持头部可见”。此设置只影响拍照期间自己的画面，结束拍照后会恢复普通显示。

### 跳跃切换躺姿

同时选择仰卧和俯卧姿势后，可通过原地跳跃进行切换。如果只选择其中一种，则保持该姿势。不希望通过跳跃切换时，请在Unity的“功能 → 便捷功能”中关闭“跳跃切换躺姿”。不会额外消耗同步参数，新增用量为0 bit。虚拟形象使用多个姿势工具时，在任意一个工具中关闭此功能，都会应用于整个虚拟形象。

### 翻身

在支持的躺姿中，向左右倾斜头部，身体也会平滑翻身。并非所有躺姿都会自动支持此功能。

1. 启用“功能 > 菜单功能 > 翻身”。
2. 在“姿势”中打开所需躺姿的“详情”，启用“启用翻身”。
3. 在“翻身侧向姿势”中指定侧躺动画。系统会根据原始姿势和侧躺姿势生成左右翻身。按需调整“接地修正强度”。
4. 在VRChat中选择支持的姿势并打开“翻身”。使用时请解除颈部固定。

启用翻身的姿势会根据头部倾斜确定动画的播放位置，因此无法再使用普通MotionTime设置。如果使用已经制作好的翻身动画，请将其指定到普通动画栏，并清空“翻身侧向姿势”。动画的播放位置应设置为0时向左、0.5时仰卧、1时向右。

### 呼吸与默认摇摆

在“功能 > 便捷功能 > 启用呼吸动画”中，可让胸部等部位随呼吸移动。通过“打开设置”，可以为各姿势分类选择“无、弱、中、强、急、自定义”。“急”表示较快的呼吸。“自定义”可指定自己准备的呼吸动画。

仅使用呼吸动作时，用量为0 bit。若要在VRChat中暂停或恢复呼吸，也请启用“菜单功能 > 呼吸”。开关同步使用1 bit。改变强度不会增加bit数。

颈部、肩部、手臂等也会随胸部一起移动，以减少头部和双手的位置变化。这不是完全固定位置，请根据体型和姿势选择合适的强度。

“便捷功能 > 关闭VRChat默认站立摇摆”可抑制VRChat默认添加的待机身体摇摆。初始为关闭，且会保留姿势工具自身的呼吸及其他自定义动作。即使不使用呼吸动作，也可以启用此项，且不会增加bit数。由默认待机动作以外的因素造成的摇摆，无法通过此设置停止。

并用多个姿势工具时，在任意一个工具中停止默认摇摆，都会应用于整个虚拟形象。若要恢复，请在所有工具中关闭此设置，然后重新上传。

### 减轻头部旋转造成的姿势变形

当头部朝向与原始姿势不同时，解除颈部固定后可能导致姿势变形，此时可使用此功能。它位于“功能 > 便捷功能”中，不会添加专用的游戏内菜单。颈部固定时使用原始姿势的朝向。仰卧姿势会保持原本的向上朝向，因此不属于修正对象。

### 菜单图标

- “生成姿势图标”：生成虚拟形象摆出各姿势的图片，并显示在菜单中。更容易辨认姿势，但生成图片会增加构建时间。
- “减小图标容量”：降低图片分辨率，以缩小虚拟形象体积。

面向Android构建时不会生成姿势图标。更换服装等之后，请使用“重新拍摄图标”。姿势列表中的图片可通过“更新姿势缩略图”更新。这些操作较为耗时，请先阅读确认对话框再执行。

## 添加、排序与预览姿势

在“姿势”的左侧选择姿势分类。最上方的放大镜选项卡可跨分类搜索姿势名。打开“详情”，即可集中设置动画、图标和MotionTime等。

可将多个动画拖放到添加区域，或先在Project中选中，再点击“导入Project中选择的片段”批量添加。同一片段的重复项会被排除。

要调整顺序，请在“详情”的“顺序”中选择目标位置。也可使用上下移动按钮；移动后会保留详情的展开或折叠状态。

点击各姿势的“预览”，无需打开调整窗口即可在Scene中查看姿势。结束预览后恢复原始显示。此简易预览不会执行MA或NDMF的构建处理，因此可能与构建时整合的服装或FloorAdjuster等的最终结果不同。最终服装效果和接地情况也请在构建虚拟形象后确认。

## 动画调整与手脚自动调整（IK）

在“姿势”中打开“动画调整”，即可一边预览，一边细调身体与手脚。调整后，请通过窗口中的保存操作保存调整动画。

对于支持手脚自动调整的商品和姿势，系统会根据虚拟形象的体型调整手脚位置。可在动画调整界面通过“启用手脚自动调整”切换整体设置，通过“对此姿势启用IK”单独切换各姿势。未提供自动调整的姿势会显示相应说明。

如果希望在自动调整的基础上手动完成，请点击“将IK烘焙到调整中”。此操作会将当时的IK结果写入新的调整动画，并关闭该虚拟形象中对应姿势的IK。原始动画会保留。只有整体和目标姿势的自动调整均已启用，且存在可应用的IK设置时，此按钮才可用。

可在“头像设置”的“防止膝盖反折”中切换膝部修正。在详情的“最小膝盖弯曲角度（度）”中设置弯曲角度。“启用头像专属修正”仅在存在对应修正数据时可用。与手脚自动调整重叠的修正可能无法并用。

## 原始姿势、自定义动作与预设

这些项目在“头像设置”中设置。

- “使用头像原有的站立、蹲下和俯卧姿势”：自动导入虚拟形象原本设置的姿势。
- “使用自定义动作”：打开导入设置，为站立、蹲下（Crouching）、俯卧（Prone）等各类型分别指定动作。原则上每种类型设置一个动作。
- “与其他工具整合跟踪锁定”：与其他功能组件并用时，若固定功能无法正常工作，可启用此项。

自行指定动作的导入设置，与自动导入原始姿势的设置是两个独立功能。

预设位于选项卡最下方。可按名称搜索，并通过“应用此预设”切换姿势设置。预设主要用于初次安装时的设置，会替换当前设置；如果已有调整内容，请保存后再切换。

显示预设列表时，仅加载名称和适用虚拟形象等信息；应用所选预设时才加载调整动画。即使首次创建列表，也不会预先加载所有虚拟形象的动画。

列表分为“适用于头像”“用户预设”“Unisaki Studio官方预设”。“隐藏内置预设”是同一项目共用的显示设置。添加、编辑或删除预设后，列表会更新。如果显示未变化，请点击“重新加载”。

## 预构建与警告

启用“使用头像原有的站立、蹲下和俯卧姿势”后，每次生成时都会从虚拟形象的Base检测动作。检测结果不会写回手动导入设置，因此仅使用自动导入时，列表会保持未指定状态。Base中的动作变化和自动导入的开关会在下次生成时生效。

上传时的自动导入会应用于构建用副本，不会改写场景中的原始对象、导入设置或导入来源的Controller和动作。如果已有预构建且输入未变化，会复用其结果。

某一类型存在手动指定时，优先使用手动设置，并应用旋转、调整动画和播放位置指定。关闭“使用”或移除已指定动作的设置，会停止该类型的自动导入。通过“清除手动指定”移除该类型的设置和调整后，如果自动导入已启用，下次生成时会重新检测。此操作可通过Undo撤销。同一类型存在多个旧设置时，优先使用Inspector中选中的有效设置。

旧版自动导入添加到列表中的设置，无法与手动注册或已经调整过的设置区分，因此不会自动删除。请仅对需要恢复自动导入的类型使用“清除手动指定”。同一虚拟形象安装多个产品时，其他产品中的手动设置也会应用于共用的原始姿势。

预构建通过复用已生成的数据，缩短虚拟形象的构建时间。可通过“更新预构建”创建或更新。普通虚拟形象构建也会生成所需数据，因此不必每次都手动执行预构建。

更改设置后，会进入需要更新的状态，并通过Inspector顶部的“检查设置”和Hierarchy标记提示。更改姿势或IK设置后，更新预构建可减少后续构建时间。

“警告显示设置”位于“检查设置”区域内，可按警告类型隐藏提示，也可隐藏Hierarchy标记。隐藏提示并不意味着设置问题已解决或生成数据已更新。错误和必要的生成处理仍然保留。

## 使用注意事项

- 适用于3点跟踪和桌面模式，不支持全身跟踪期间的姿势固定。
- 根据体型和修改内容，手脚接地及服装效果可能需要额外调整。
- 与特殊Base层或其他姿势切换组件组合时，可能无法按预期工作。
- 拍照模式的移动、旋转和地面高度，会修正工具姿势以及未选择工具姿势时的默认和自定义动作。VRChat中替换后的默认动作及视点表现，请在实际客户端中确认。
