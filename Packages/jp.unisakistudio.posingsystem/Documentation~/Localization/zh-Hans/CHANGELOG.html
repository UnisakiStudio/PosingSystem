更新记录

[3.2.0] - 尚未发布

新增

  • Inspector、编辑操作、安装对话框、标准姿势名和生成的VRChat菜单现支持30种显示语言。
  • 统一了Inspector和游戏内菜单的语言选择。初始使用计算机语言，同一OS用户的其他项目也会使用最后的选择。
  • 支持以所选语言打开README、更新记录和离线使用说明。
  • 依照现有术语，补齐了128个标准姿势的显示名和各功能说明。

兼容性

  • 保留虚拟形象的现有设置、自定义名称、资源引用、参数标识符和许可证保存方式。

[3.1.4] - 2026-11-11

  • 修复了为虚拟形象指定的专用蹲下、俯卧动画未生效，反而使用VRChat默认姿势的问题。自动导入和手动指定均已修复。
  • 修复了编辑或预览姿势时，通过MA Bone Proxy安装的头发、眼镜等仍留在原位的问题。它们现在会跟随预览姿势，同时保持原虚拟形象的设置和摆放不变。
  • 修复了拍摄“仰向け寝_お疲れ”等姿势缩略图时，利用视点位置进行姿势校正失败的问题。拍摄时会使用已应用构建时姿势校正和地板调整的动画。

请在ALCOM / VCC中将Unisaki Posing System更新为3.1.4。Kawaii Posing Tool 3.1.2和Cool Posing Tool 1.1.0可继续使用。如果此前使用过预构建，请在更新后点击“更新预构建”并保存场景，然后重新构建、上传虚拟形象。

[3.1.3] - 2026-11-09

  • 在复制的虚拟形象上执行“更新姿势缩略图”或预构建时，不再删除原虚拟形象的姿势缩略图。
  • 修复了在首次保存场景前或Prefab编辑界面中执行预构建后，仅重拍缩略图就显示“设置已更改”的问题。
  • 修复了上次预构建生成的姿势数据残留时，下一次预构建可能中途停止的问题。
  • 减轻了尚无姿势缩略图时打开列表的处理负担。还调整了预构建或构建开始时，在获取软件包信息完成前阻止Unity操作的处理。
  • PC和Android构建时，也会移除虚拟形象中已禁用的姿势工具的编辑设置。
  • 使用“咨询此错误”时，即使Console开头排列着无法判断原因的错误，也能将后面的诊断编号等加入草稿。若翻身片段设置发生错误，草稿还会包含需要检查的项目。

请在ALCOM / VCC中将Unisaki Posing System更新为3.1.3。Kawaii Posing Tool 3.1.2和Cool Posing Tool 1.1.0可继续使用。这些产品仍指定较早的共用系统版本，因此更新时可能显示冲突确认。如果此前使用过预构建，请在更新后点击“更新预构建”，保存场景，再重新构建、上传虚拟形象。

[3.1.2] - 2026-11-09

  • 修复了启用“减轻头部旋转造成的姿势变形”时，从俯卧站起后面部仍保持朝上的问题。
  • 即使关闭“脚部高度”，也可通过EX菜单的“设置 → 仰卧时自动锁定头部”切换头部固定。在3.1.0、3.1.1中该项目消失的虚拟形象，更新后构建即可恢复。
  • 即使在Unity中取消勾选虚拟形象本体，也可执行“更新预构建”。
  • 修复了Assets中残留旧版共用姿势Controller时，更新后可能无法生成姿势的问题。用户自行编辑的Controller设置也会保留。
  • 当工具或其父对象停用，导致无法使用共用姿势Animator时，会显示目标名称。可通过“检查设置 → 选择对象”定位。
  • 预构建显示“设置有更新”时，可通过“详情 → 查看预构建后的设置变化”检查与上次不同的设置。
  • 脚本错误导致构建停止（PS050）时，最多显示Unity检测到的5条原始错误。通过“咨询此错误”，可查看、编辑并发送包含Unity和相关工具版本及错误编号的草稿。

如果使用过预构建，更新后请点击“更新预构建”并保存场景，然后重新构建、上传虚拟形象。

[3.1.1] - 2026-11-08

  • 即使关闭“左右镜像”，已启用的“地面高度”和“翻身”也会显示在VRChat EX菜单的“设置”中。
  • 即使旧版中对姿势进行了排序、删除或改名，也能将正确的翻身分别继承到“伸腿坐”“放松”“支起单膝”。完全Unpack后，只要能识别原始姿势，也能继承。自定义姿势、用户自行关闭的翻身和替换的侧躺动作会保留。
  • 修复了在VRChat选择虚拟形象时会瞬间俯卧的问题，也修复了仅选择俯卧姿势时，跳跃会瞬间变为仰卧的问题。跳跃切换可通过“功能 → 便捷功能 → 跳跃切换躺姿”关闭，默认启用。
  • 更新后，如果共用姿势Animator Controller的引用丢失，在可恢复时会显示警告并根据设置重建。多个虚拟形象共用的Controller引用也会保留。
  • 项目存在编译错误时，会在构建开始时说明原因并停止。脚本错误导致无法检查引用期间，暂缓自动清理已生成的Controller。
  • 即使项目中存在与商品同名的Prefab，添加工具时也会优先使用正式Prefab。共用Controller仅换行符不同时，也可继续预构建。
  • 姿势工具添加的FX层（如地面高度）的Write Defaults现会遵循虚拟形象一侧的设置。

如果使用过预构建，更新后请在场景中的工具上点击“更新预构建”并保存场景，然后重新构建、上传虚拟形象。

[3.1.0] - 2026-11-07

  • 支持根据体型调整适用姿势手脚的自动调整（IK）、头像专属修正及防止膝盖反折。
  • 拍照模式可调整虚拟形象的位置和朝向，也可选择同步位置、朝向，以及拍照时显示自己的头部。
  • “地面高度”可上下移动整个身体，最大距离为3m，可与“脚部高度”分别使用。
  • 新增呼吸动作、关闭默认待机摇摆，以及减轻头部朝向导致姿势变形的设置。
  • 可在Inspector查看启用的功能和参数用量，并支持姿势搜索、批量添加、排序及Scene简易预览。
  • 加快桌面模式中站立、半蹲和坐姿的切换。
  • 改善更改设置后的预构建警告、Inspector滚动负担，以及清理生成资源时的长时间停顿。
  • 修复了自动导入启用时，未更改设置的预构建仍出现更新警告，且上传时重新生成的问题。导入结果会应用于生成用虚拟形象，不改动原始对象的导入设置。
  • 新增根据头部倾斜翻身，以及为各姿势指定对应动作的设置。
  • 改善旧预设翻身设置的继承、自定义动作导入及生成资源管理。

[3.1.0-beta.2] - 公开测试版（2026-11-05）

  • 在IK的“位置长度基准”中，新增固定长度，以及Head到Viewpoint的高度差（Y）和前后差（Z）。
  • 除Inspector外，也在Hierarchy对象名左侧显示警告。除未执行预构建和设置变化外，也支持动作导入或预设操作当前显示的警告。
  • 修复了打开场景等时自动清理生成资源，会加载其他场景生成的Controller并导致Unity长时间停顿的问题。
  • 修复了修改姿势列表或功能时预构建历史丢失的问题。现会显示“预构建后设置已更改”，而非“未执行”，Hierarchy也会显示需要更新的警告。
  • 共享Inspector和Hierarchy显示使用的预构建比较结果，在设置和引用资源未变化时减少滚动负担。构建时仍会像以前一样每次进行比较。

[3.1.0-beta.1] - 公开测试版（2026-11-04）

  • 将桌面模式的普通姿势切换改为1次求值方式。普通构建和预构建均启用，VR及特殊条件下保留原有流程。
  • 将alpha.3及更早版本的预构建识别为需要更新。
  • 拍照期间改变地面高度时保持视点，并在结束拍照后恢复至最新地面高度。
  • 将自动导入改为仅在生成时检测，预构建和构建不会再添加或更改手动导入设置。
  • 自动导入开关、Base变化和清除手动设置会触发重新生成。保留多个产品共享的手动指定和调整，并将旧导入动作恢复为默认姿势。
  • 按场景GUID和各虚拟形象，将预构建生成的Controller管理为一个文件。更新前会拆分复制对象、不同场景或Prefab共用的引用。
  • 构建时使用NDMF的临时资源管理，不增加编辑用生成文件。
  • 打开和保存场景时检查生成资源。存在未保存编辑、Undo/Redo或外部引用时会保留，仅将归属明确且未使用的文件移至回收站。
  • 应用导入动作的旋转、调整动画和播放位置指定。将旋转、RootT/RootQ及Humanoid调整处理与普通姿势统一。
  • 对嵌套BlendTree的调整会复制为导入目标专用，保留原始动作和行走用混合设置。
  • “仅站立”的播放位置指定会按原始帧率展开为静态姿势，不停止行走一侧的播放。

[3.1.0-alpha.2] - 封闭测试版（2026-10-26）

修复与更改

  • 对未选择工具姿势时的默认和自定义动作，也应用拍照模式与地面高度修正。
  • 将地面高度扩展为上下3m。50%为原始高度及初始值，0%为向下3m，100%为向上3m。
  • 修复了“仅站立”覆盖会修改导入来源BlendTree的问题。
  • 没有IK规则的姿势使用手动修正，并减少不必要的生成警告。
  • 修复了同名姿势调整草稿混淆，以及未检测到同一资源内动作更改的问题。
  • 修复了无效初始姿势的编号导致其他姿势被初始选中的问题。
  • 导入不支持的AnimatorOverrideController时，显示说明而非抛出异常。
  • 应用旧预设时，保留明确关闭的翻身设置。
  • 改善了浅色Editor主题下功能图标的可辨识性。

VRChat客户端中的视点和默认动作替换后的验证仍在进行。

[3.1.0-alpha.1] - 发布前

新增

  • 新增各功能开关和ExpressionParameters用量显示。
  • 新增可将虚拟形象向前移动和旋转的拍照模式。
  • 新增拍照模式同步选择。仅本地显示为0 bit，同步时为16 bit。
  • 新增拍照模式中保持自身虚拟形象头部可见的设置。
  • 新增“地面高度”，可将包含头部的整个身体上下移动3m。50%为原始高度及初始值，0%为向下3m，100%为向上3m。
  • 新增根据头部倾斜翻身及各姿势的对应动画设置。
  • 新增呼吸动作及弱、中、强、急、自定义设置。
  • 新增分别选择呼吸动作和游戏内开关菜单的设置。仅动作使用0 bit，开关同步使用1 bit。
  • 新增关闭VRChat默认待机动作摇摆的设置。
  • 新增减轻头部朝向不同造成姿势变形的设置。
  • 新增根据体型调整适用姿势手脚的自动调整（IK），并提供虚拟形象整体及各姿势的开关。
  • 新增“将IK烘焙到调整中”，将IK结果保存为调整动画。
  • 新增头像专属姿势修正、防止膝盖反折及最小弯曲角度设置。
  • 新增从姿势列表在Scene中查看姿势的简易预览。
  • 新增姿势分类选项卡、跨分类搜索、多个动画批量添加及指定移动后的顺序。
  • 新增在Inspector中显示商品与共用系统更新记录的功能。

更改

  • 加快预设加载，缩短添加工具和显示预设列表时的等待时间。
  • 添加、编辑和删除预设后，列表现会自动更新。
  • 将Inspector整理为“功能”“姿势”“头像设置”3个选项卡。
  • 为设置项目添加说明和图标，并统一详细设置的展开与折叠显示。
  • 将呼吸详情移至功能设置内，将预设移至头像设置末尾。
  • 将自定义动作的单独指定与虚拟形象原始姿势的自动导入整理为独立设置。
  • 减少脚部高度调整所生成全身动画的重复。
  • 将姿势图片更新改为带确认对话框的按钮。
  • 将警告显示设置集中到“检查设置”中。
  • 取消8bit专用Prefab的新建入口，统一为普通Prefab中的功能选择。保留现有引用。
  • 将VRChat Avatars SDK的最低版本改为3.10.4。

修复

  • 将未选择工具姿势时的默认和自定义动作也纳入拍照模式及地面高度的修正范围。
  • 修复了“仅站立”覆盖时改动导入来源BlendTree的问题。
  • 没有有效IK规则的姿势使用手动调整，减少不必要的IK生成警告。
  • 修复了同名姿势调整内容混合，以及同一资源内替换动作未触发重新生成的问题。
  • 即使已停用初始姿势的编号被其他姿势复用，也不会再被初始选中。
  • 导入原始姿势时检测到不支持的AnimatorOverrideController，会显示说明而非抛出异常。
  • 应用旧预设时，保留明确关闭的翻身设置。
  • 改善Inspector图标背景，确保浅色Editor主题下也能辨认功能图标。
  • 修复了向虚拟形象添加工具时，“翻身”“地面高度”“拍照模式”图标不显示的问题。
  • 修复了应用旧版本预设时，适用姿势的翻身设置丢失的问题。
  • 修复了编辑姿势名时打开其他详情，输入会转移到另一姿势的问题。
  • 修复了姿势排序时详情关闭的问题，并修正设置更改的Undo、Redo处理。
  • 修复了预览与原始虚拟形象重叠，以及放置位置被重复相加的问题。
  • 修复了预览缺少组件的虚拟形象时报错的问题。
  • 修复了虚拟形象骨骼朝向和缩放差异导致的IK手脚方向及位置偏移。
  • 修复了更改设置后，警告和预构建状态未立即更新的问题。
  • 修复了更改IK设置后仍复用旧预构建结果的问题。
  • 修复了某些配置下附加功能生成失败的构建错误。
