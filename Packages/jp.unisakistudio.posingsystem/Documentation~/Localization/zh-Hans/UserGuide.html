Unisaki Posing System 3.2.0 — 简体中文指南

Unisaki Posing System是Kawaii Posing、Cool Posing及相关工具的共用核心。 请通过VCC或ALCOM将购买的商品与此核心一同安装。使用Unity 2022.3、 VRChat Avatars SDK 3.10.4+、Modular Avatar 1.15.1+及NDMF 1.14.0+。

语言

在工具Inspector顶部选择Language / 言語。同一项选择同时控制Inspector和生成的VRChat菜单。 更改语言后请重新上传虚拟形象。最后的选择会用于此计算机上同一OS用户的其他项目。 没有已保存的选择时，工具使用OS语言，不支持时回退为英语。 所有姿势工具和虚拟形象都使用同一种语言。在任意工具的Inspector中更改语言，都会更新共用设置；不采用单个虚拟形象的语言选择。语言偏好不会同步到其他计算机。 仅在尚未保存语言时的首次安装确认中显示语言按钮。之后请在Inspector中更改语言。

设置虚拟形象

在Hierarchy中选中场景内带有VRC Avatar Descriptor的虚拟形象，再选择 Unisaki Studio > 添加Kawaii Posing或添加Cool Posing。如提示存在适用的虚拟形象预设，请应用。 工具Inspector包含功能、姿势和头像设置选项卡。 选择所需姿势与可选控件、调整适配后，按普通流程上传。 如果使用缓存的预构建数据，更改设置后请执行更新预构建。

详细手册

在所购商品的Inspector中打开使用说明，即可查看所选语言的离线指南。 商品的Documentation~/UserGuide.en.html包含安装、虚拟形象适配、VRChat操作、 姿势编辑、参数内存、更新与故障排查说明。 标准姿势名会翻译后显示；自定义名称、虚拟形象名称、资源文件名、 保存的对象名和参数标识符均保留原始拼写。 可选择30种语言。随附的Inspector、安装对话框、标准姿势名和生成菜单 已为每种选择提供完整显示目录。所有可选语言均有离线文档。

30种语言的快速参考涵盖功能说明和标准姿势名表。这是简明参考；完整文档请从语言列表进入。

许可证与支持

请使用购买商品的商店提供的安装程序。商品许可证保留现有的按用户注册表或文件保存方式， 与EditorPrefs分开。请阅读软件包随附的原始协议。 现有共用系统英文协议为参考译文；各商品的协议也单独提供。
