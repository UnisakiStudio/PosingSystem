# 言語の選択 — v3.2.0

ツールを初めて使うとき、インスペクター上部で言語を選び「選択 / Continue」を押してください。Unity自体の表示言語とは別に選べます。後から同じ場所で変更できます。

## VRChatのメニュー

「機能」タブの「ゲーム内メニューの言語」で選び、アバターをアップロードしてください。Unity内の表示言語とは別の設定です。すでにアップロードしたアバターの表示を変えるには再アップロードが必要です。

## 姿勢名と翻訳

一覧では翻訳した姿勢名を表示します。日本語の元の名前でも翻訳後の名前でも検索できます。元の姿勢名・アニメーション・内部パラメーターは維持します。独自に付けた名前に翻訳がない場合は、その名前を表示します。

## 開発中の翻訳

v3.2.0開発版では翻訳を順次追加しています。未翻訳の項目は日本語（独自名は元の名前）で表示します。言語によって翻訳済みの範囲が異なります。
