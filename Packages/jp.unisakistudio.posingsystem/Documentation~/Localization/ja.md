# 言語の選択 — v3.2.0

初期状態ではパソコンの言語を使います。Unity自体の表示言語とは独立しており、非対応の言語では英語を使います。Inspector上部の「Language / 言語」から変更でき、選択はこのPCの同じユーザーの別プロジェクトでも引き継がれます。導入時の確認画面でも「Language...」から変更できます。

## VRChatのメニュー

Inspector上部で選んだ言語を、ツールの画面表示とゲーム内メニューの両方に使います。選択はアバター上のツールに保存されます。ゲーム内メニューへ反映するにはアバターを再アップロードしてください。

## 姿勢名と翻訳

一覧では翻訳した姿勢名を表示します。日本語の元の名前でも翻訳後の名前でも検索できます。元の姿勢名・アニメーション・内部パラメーターは維持します。独自に付けた名前に翻訳がない場合は、その名前を表示します。

## 対応言語

v3.2.0では30言語の標準表示文言と、収録された128の姿勢名を用意しています。Inspector、導入画面、生成するゲーム内メニューで同じ言語を使います。独自名は元の名前を保ちます。全文のオフラインマニュアルは英語で用意しています。
