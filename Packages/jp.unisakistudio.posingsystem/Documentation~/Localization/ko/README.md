# Unisaki Posing System

Kawaii Posing, Cool Posing 등에서 사용하는 공통 포즈 시스템입니다. Modular Avatar와 NDMF를 사용하여 아바타 업로드 시 필요한 메뉴와 애니메이션을 생성합니다.

이 README는 개발 중인 v3.2.0용입니다. 정식 출시일은 정해지지 않았습니다. 설치된 버전은 포즈 도구의 Inspector 상단에서 확인할 수 있습니다. [추가 기능과 변경 내역](CHANGELOG.md)도 확인하세요.

## 표시 언어와 오프라인 문서

Inspector 최상단의 Language / 言語에서 표시 언어를 선택합니다. 하나의 선택이 Inspector와 생성되는 VRChat 메뉴에 모두 적용됩니다. 게임 내 표시 언어를 바꾸려면 아바타를 다시 업로드하세요.

선택한 언어가 없으면 컴퓨터의 언어를 사용하고, 지원하지 않는 언어이면 영어를 사용합니다. Windows·macOS·Linux를 지원합니다. 마지막으로 선택한 언어를 EditorPrefs에 저장하여 이 컴퓨터의 같은 OS 사용자에 속한 다른 프로젝트에서도 사용합니다. 아바타에 명시적으로 저장된 선택은 유지합니다. 다른 컴퓨터에는 동기화하지 않습니다. 라이선스 저장 방식은 변경하지 않습니다.

동봉된 [언어 목록](../index.html)에서 README·변경 내역·사용 설명서를 선택할 수 있습니다. Inspector의 사용 설명서와 변경 내역도 선택한 언어를 따릅니다. 원본 이용 약관과 참고 번역은 기존처럼 별도로 제공합니다.

## 데스크톱 모드의 자세 전환

데스크톱 모드에서 서기·웅크리기·앉기로 전환할 때 지정한 포즈가 반영되기까지의 지연을 줄였습니다. 일반 빌드와 프리빌드에 적용되며 별도 명령이나 추가 설정은 필요하지 않습니다. VR 모드나 특수한 상태에서는 기존 처리를 유지합니다. 이전 버전의 프리빌드는 업데이트한 뒤 업로드하세요.

## 설치와 업데이트

각 상품의 구매 파일과 설치 안내에 따라 VCC 또는 ALCOM에서 포즈 도구를 추가하세요. 이 시스템은 포즈 도구의 의존 패키지로 설치됩니다.

v3.2.0의 필요 환경은 다음과 같습니다.

- Unity 2022.3의 VRChat 아바타 프로젝트
- VRChat Avatars SDK 3.10.4 이상
- Modular Avatar 1.x 중 1.15.1 이상
- NDMF(Non-Destructive Modular Framework) 1.x 중 1.14.0 이상

Kawaii Posing 사용자는 ALCOM / VCC에서 Kawaii Posing을 3.2.0으로 업데이트하고 Unisaki Posing System도 3.2.0인지 확인하세요. 프리빌드를 사용했다면 프리빌드 업데이트를 누르고 씬을 저장한 뒤 아바타를 업로드합니다.

Cool Posing 1.2.0은 공통 시스템 3.2.0을 사용합니다. 상품과 공통 시스템을 서로 호환되는 버전으로 함께 업데이트하세요.

### 8bit 버전을 사용했던 분께

새로 추가할 때는 일반 Prefab으로 통일했습니다. 기능에서 불필요한 항목을 끄면 사용량을 줄일 수 있습니다. 자세 선택만 사용할 때의 기본 사용량은 8 bit입니다.

이전 8bit Prefab은 이미 배치한 아바타와 프리셋의 참조를 유지하기 위해 각 상품의 Editor/Legacy에 남아 있습니다. 기존 8bit 버전을 사용하기 위해 Prefab을 삭제하거나 교체할 필요는 없습니다. Unity의 새로 추가 메뉴에서 8bit 버전을 선택하는 방식은 폐지했습니다.

| 아바타 설정 | 체형에 맞춘 보정, 무릎 보정, 원래 포즈·자체 모션 가져오기, 프리셋 |

상세 설정이 있는 항목은 설정 열기를 누르면 아래에 설정란이 펼쳐집니다. 호흡 설정도 기능에 있습니다.

상단의 도움말 / 변경 내역에서 사용 설명서·문의·변경 내역을 열 수 있습니다. 변경 내역은 상품과 Unisaki Posing System을 전환하여 읽을 수 있습니다.

## 기능과 ExpressionParameters 사용량

기능의 메뉴 기능에서 선택한 항목이 게임 내 메뉴에 표시됩니다. 예를 들어 좌우 반전을 선택하면 게임 안에서 반전을 전환할 수 있습니다. Inspector에서 체크했다고 모든 포즈가 항상 반전되는 설정은 아닙니다.

| 기능 | 추가 bit 사용량 |
| --- | ---: |
| 좌우 반전 | 1 bit |
| 제스처 끄기 | 1 bit |
| 호흡 애니메이션 사용 | 0 bit |
| 호흡(게임 내 ON/OFF) | 1 bit |
| 발 높이 | 8 bit |
| 바닥 높이 | 8 bit |
| 촬영 모드(자신의 화면만) | 0 bit |
| 촬영 모드 동기화 | 16 bit |
| 촬영 모드에서 머리 표시 유지 | 0 bit |
| VRChat 기본 대기 흔들림 끄기 | 0 bit |
| 머리 회전에 의한 포즈 변형 줄이기 | 1 bit(뒤척이기와 공유) |
| 뒤척이기 | 10 bit(이 중 1 bit를 포즈 변형 줄이기와 공유) |

뒤척이기는 ON/OFF에 1 bit, 머리 기울기에 8 bit, 머리 고정에 1 bit를 사용합니다. 포즈 변형 줄이기를 이미 켰다면 뒤척이기를 추가할 때 증가하는 양은 9 bit입니다. 공유하는 부분은 중복 계산하지 않으며 체크를 바꾸면 표시도 갱신됩니다.

표시되는 합계는 해당 아바타에 설치한 포즈 도구의 사용량입니다. 의상이나 다른 기믹을 포함한 아바타 전체의 합계는 아닙니다. 여러 포즈 도구를 함께 사용해도 공통 설정을 중복 계산하지 않습니다. 포즈 수가 기본 번호 범위를 넘는 구성에서는 자세 선택에도 추가 bit가 필요할 수 있습니다.

### 발 높이와 바닥 높이

- 발 높이: 머리 위치를 유지하면서 발 쪽 높이를 조절합니다. 발을 바닥이나 침대에 맞출 때 사용합니다.
- 바닥 높이: 머리를 포함한 몸 전체를 위아래로 이동합니다. 50%가 원래 높이, 0%가 3m 아래, 100%가 3m 위입니다. 기본값은 50%입니다.

둘 다 게임 내 설정에 있으며 바닥 높이가 발 높이 다음에 배치됩니다. 바닥 높이를 중앙에서 움직이면 위아래로 이동하고, 50% 부근으로 되돌리면 원래 높이로 돌아가며 보정이 끝납니다. 별도의 부유 ON/OFF 스위치는 없습니다. 시점 보정은 부유를 시작할 때와 바닥 높이를 조작하는 동안 적용됩니다.

발 높이는 일반 애니메이션에서 높이 조절을 위해 전신 모션을 중복 생성하지 않는 방식으로 변경했습니다. 생성되는 애니메이션 데이터는 줄어들지만 아바타 전체 용량이 일률적으로 3분의 1이 되는 것은 아닙니다.

### 촬영 모드

1. 기능 > 메뉴 기능 > 촬영 모드를 켭니다.
2. VRChat에서 촬영 모드를 열고 자세 선택에서 포즈를 고릅니다.
3. 거리로 앞쪽 최대 3m까지 이동하고 방향으로 회전합니다. 거리가 0보다 크면 아바타가 자신을 바라봅니다.
4. 필요에 따라 발 고정을 켭니다. 시작할 때 발 고정을 강제하지 않으므로 고정 전에 위치를 조절할 수 있습니다. 메뉴에 제스처 끄기를 추가했다면 같은 화면에서 손 모양도 바꿀 수 있습니다.
5. 촬영 종료로 거리와 방향을 되돌리고 발 고정을 해제합니다.

촬영 모드의 이동·회전을 자신의 화면에만 사용할 때는 0 bit입니다. 다른 사람에게도 위치와 방향을 보이려면 편의 기능 > 촬영 모드 동기화를 켜세요. 거리와 방향에 합계 16 bit를 사용합니다.

가까이 있는 자신의 아바타 머리가 사라진다면 편의 기능 > 촬영 모드에서 머리 표시 유지를 켜세요. 촬영 중 자신의 화면에만 적용되며 종료하면 평소 표시로 돌아갑니다.

### 점프로 누운 자세 전환

바로 눕기와 엎드리기를 모두 선택하면 제자리에서 점프하여 전환할 수 있습니다. 한쪽만 선택하면 그 자세를 유지합니다. 점프로 바꾸고 싶지 않으면 Unity의 기능 > 편의 기능에서 점프로 누운 자세 전환을 끄세요. 동기화 파라미터의 추가 사용량은 0 bit입니다. 여러 포즈 도구를 사용하는 아바타에서는 어느 하나에서 끄면 아바타 전체에 적용됩니다.

### 뒤척이기

지원되는 누운 자세에서 머리를 좌우로 기울이면 몸도 부드럽게 뒤척입니다. 모든 누운 자세가 자동으로 지원되는 기능은 아닙니다.

1. 기능 > 메뉴 기능 > 뒤척이기를 켭니다.
2. 포즈에서 사용할 누운 자세의 상세를 열고 뒤척이기 사용을 켭니다.
3. 뒤척이기용 옆으로 누운 포즈에 옆으로 눕는 애니메이션을 지정합니다. 원래 자세와 옆으로 누운 자세를 바탕으로 양쪽 뒤척이기를 만듭니다. 필요하면 접지 보정 강도를 조절하세요.
4. VRChat에서 지원되는 자세를 선택하고 뒤척이기를 켭니다. 머리 고정을 해제한 상태에서 사용하세요.

뒤척이기를 사용하는 포즈는 머리 기울기로 애니메이션의 재생 위치를 결정하므로 일반 MotionTime 설정을 사용할 수 없습니다. 완성된 뒤척이기 애니메이션을 쓴다면 일반 애니메이션란에 지정하고 뒤척이기용 옆으로 누운 포즈를 비워 둡니다. 재생 위치 0이 왼쪽, 0.5가 바로 눕기, 1이 오른쪽인 애니메이션을 준비하세요.

### 호흡과 기본 대기 흔들림

기능 > 편의 기능 > 호흡 애니메이션 사용을 켜면 가슴 등이 호흡에 맞춰 움직입니다. 설정 열기에서 자세 분류별로 없음·약·중·강·빠름·사용자 지정을 선택할 수 있습니다. 빠름은 빠른 호흡입니다. 사용자 지정에서는 직접 준비한 호흡 애니메이션을 지정할 수 있습니다.

호흡 동작만 사용할 때는 0 bit입니다. VRChat에서 호흡을 멈추거나 다시 시작하려면 메뉴 기능 > 호흡도 켜세요. ON/OFF 동기화에 1 bit를 사용합니다. 강도를 바꿔도 bit 수는 증가하지 않습니다.

가슴에 맞춰 목·어깨·팔도 움직여 머리와 손의 이동을 줄입니다. 위치를 완전히 고정하는 기능은 아니므로 체형과 포즈에 맞는 강도를 선택하세요.

편의 기능 > VRChat 기본 대기 흔들림 끄기는 VRChat이 기본으로 적용하는 대기 중 몸 흔들림을 줄입니다. 기본값은 꺼짐이며 포즈 도구의 호흡과 다른 사용자 지정 동작은 유지합니다. 호흡을 사용하지 않아도 선택할 수 있고 bit 수가 늘어나지 않습니다. 기본 대기 동작 외의 원인으로 생기는 흔들림은 멈추지 않습니다.

여러 포즈 도구를 함께 쓸 때 어느 하나에서 기본 대기 흔들림을 끄면 아바타 전체에 적용됩니다. 되돌리려면 모든 도구에서 이 설정을 끄고 다시 업로드하세요.

### 머리 회전에 의한 포즈 변형 줄이기

머리 고정을 해제했을 때 원래 포즈와 목 방향이 달라 자세가 무너지는 경우 사용합니다. 기능 > 편의 기능에 있으며 전용 게임 내 메뉴를 추가하지 않습니다. 머리 고정 중에는 원래 포즈의 방향을 사용합니다. 바로 누운 자세는 원래의 위를 향하는 방향을 유지하기 위해 보정 대상에서 제외합니다.

### 메뉴 아이콘 이미지

- 포즈 아이콘 생성: 아바타가 각 포즈를 취한 이미지를 만들어 메뉴에 표시합니다. 포즈를 구분하기 쉬워지지만 이미지 생성만큼 빌드 시간이 늘어납니다.
- 아이콘 용량 줄이기: 이미지 해상도를 낮춰 아바타 용량을 줄입니다.

Android 빌드에서는 포즈 아이콘을 생성하지 않습니다. 의상이나 외형을 바꾼 뒤에는 아이콘 다시 촬영을 사용하세요. 포즈 목록의 이미지는 포즈 미리보기 이미지 업데이트로 갱신합니다. 시간이 걸리는 작업이므로 확인 대화 상자를 읽고 실행하세요.

## 포즈 추가·정렬·미리보기

포즈의 왼쪽에서 자세 분류를 선택합니다. 맨 위 돋보기 탭에서는 분류를 가로질러 포즈 이름을 검색할 수 있습니다. 상세를 열면 애니메이션·아이콘·MotionTime 등을 함께 설정할 수 있습니다.

여러 애니메이션을 추가하려면 추가란에 드래그 앤 드롭하거나 Project에서 선택한 뒤 Project에서 선택한 클립 가져오기를 누르세요. 같은 클립의 중복은 제외됩니다.

순서를 바꾸려면 상세의 순서에서 이동할 위치를 선택합니다. 위아래 이동 버튼도 사용할 수 있으며 이동해도 상세의 펼침 상태는 유지됩니다.

각 포즈의 미리보기를 누르면 조정 창을 열지 않고 Scene에서 자세를 확인할 수 있습니다. 미리보기를 끝내면 원래 표시로 돌아갑니다. 이 간단한 미리보기는 MA·NDMF 빌드를 실행하지 않으므로 빌드 시 통합되는 의상이나 FloorAdjuster의 최종 결과와 다를 수 있습니다. 아바타 빌드 후에도 최종 의상과 접지를 확인하세요.

## 애니메이션 조정과 팔다리 자동 조정(IK)

포즈에서 애니메이션 조정을 열면 미리보기를 보며 몸과 팔다리를 세밀하게 조정할 수 있습니다. 조정이 끝나면 해당 창의 저장 기능으로 조정 애니메이션을 저장하세요.

지원되는 상품·포즈는 아바타 체형에 맞춰 팔다리 위치를 자동 조정합니다. 애니메이션 조정 창의 팔다리 자동 조정 사용으로 전체를, 이 포즈에 IK 사용으로 개별 포즈를 전환할 수 있습니다. 자동 조정이 준비되지 않은 포즈에는 그 안내가 표시됩니다.

자동 조정 결과를 바탕으로 수동 마무리를 하려면 IK 결과를 조정에 저장을 누르세요. 현재 IK 결과를 새 조정 애니메이션에 기록하고 해당 아바타의 해당 포즈 IK를 끕니다. 원본 애니메이션은 유지합니다. 전체와 대상 포즈의 자동 조정이 켜져 있고 적용 가능한 IK 설정이 있을 때 사용할 수 있습니다.

아바타 설정의 무릎이 반대로 꺾이지 않게 하기에서 무릎 보정을 전환합니다. 상세의 최소 무릎 굽힘(도)으로 각도를 정합니다. 아바타별 보정 사용은 대응하는 보정 데이터가 있을 때 사용할 수 있습니다. 팔다리 자동 조정과 겹치는 보정은 함께 쓰지 못할 수 있습니다.

## 원래 포즈·자체 모션·프리셋

이 항목들은 아바타 설정에서 설정합니다.

- 아바타의 원래 서기·웅크리기·엎드리기 포즈 사용: 아바타에 원래 설정된 자세를 자동으로 가져옵니다.
- 자신의 모션 사용: 가져오기 설정을 열어 서기·웅크리기(Crouching)·엎드리기(Prone) 등 종류별 모션을 개별 지정합니다. 원칙적으로 종류마다 하나의 모션을 설정합니다.
- 다른 도구와 트래킹 고정 통합: 다른 기믹과 함께 사용할 때 고정 기능이 제대로 작동하지 않으면 켭니다.

자체 모션을 지정하는 가져오기 설정은 원래 포즈를 자동으로 가져오는 설정과 별개의 기능입니다.

프리셋은 탭 맨 아래에 있습니다. 이름으로 검색하고 이 프리셋 적용을 눌러 포즈 설정을 바꿉니다. 주로 설치 시 초기 설정에 사용하며 현재 설정을 덮어쓰므로 이미 조정한 내용이 있다면 저장한 뒤 전환하세요.

프리셋 목록을 표시할 때는 이름과 지원 아바타 정보만 읽고, 조정 애니메이션은 선택한 프리셋을 적용할 때 읽습니다. 처음 목록을 만들 때도 모든 아바타의 애니메이션을 미리 읽지 않습니다.

목록은 아바타와 호환·사용자 프리셋·Unisaki Studio 공식 프리셋으로 구분됩니다. 기본 제공 프리셋 숨기기는 같은 프로젝트에서 공유하는 표시 설정입니다. 프리셋을 추가·편집·삭제하면 목록이 갱신됩니다. 바뀌지 않으면 새로고침을 누르세요.

## 프리빌드와 경고

아바타의 원래 서기·웅크리기·엎드리기 포즈 사용이 켜져 있으면 생성할 때마다 아바타의 Base에서 모션을 찾습니다. 결과를 수동 가져오기 설정에 기록하지 않으므로 자동 가져오기만 사용하는 종류는 목록에서 미지정으로 남습니다. Base 모션 변경과 자동 가져오기 ON/OFF는 다음 생성에 반영됩니다.

업로드 시 자동 가져오기는 빌드용 복사본에 적용합니다. 씬의 원본 오브젝트·가져오기 설정·원본 Controller·모션은 변경하지 않습니다. 프리빌드가 있고 입력이 바뀌지 않았다면 그 결과를 재사용합니다.

수동 지정이 있는 종류는 해당 설정을 우선하며 회전·조정 애니메이션·재생 위치도 반영합니다. 사용을 끄거나 지정한 모션을 제거하면 해당 종류의 자동 가져오기를 중지합니다. 수동 선택 지우기로 해당 종류의 설정과 조정을 지우면 자동 가져오기가 켜져 있을 경우 다음 생성에서 다시 검출합니다. Undo로 되돌릴 수 있습니다. 한 종류에 이전 설정이 여러 개 있다면 Inspector에서 선택된 유효한 설정을 우선합니다.

이전 버전의 자동 가져오기가 목록에 추가한 설정은 수동 등록·조정한 설정과 구분할 수 없어 자동 삭제하지 않습니다. 자동 가져오기로 되돌릴 종류에만 수동 선택 지우기를 사용하세요. 한 아바타에 여러 상품을 설치했다면 다른 상품의 수동 설정도 공통 원래 포즈에 반영됩니다.

프리빌드는 생성한 데이터를 재사용하여 아바타 빌드 시간을 줄이는 기능입니다. 프리빌드 업데이트로 생성·갱신할 수 있습니다. 일반 아바타 빌드에서도 필요한 데이터가 생성되므로 매번 수동으로 프리빌드할 필요는 없습니다.

설정을 바꾸면 업데이트가 필요한 상태가 되며 Inspector 상단의 설정 확인과 Hierarchy 표시로 알립니다. 포즈나 IK 설정을 바꾼 뒤 프리빌드를 갱신하면 이후 빌드 시간을 줄일 수 있습니다.

경고 표시 설정은 설정 확인 영역 안에 있습니다. 경고 종류별 표시나 Hierarchy 표시를 숨길 수 있습니다. 숨겨도 설정 문제가 해결되거나 생성 데이터가 갱신되지는 않습니다. 오류와 필요한 생성 처리는 그대로 유지됩니다.

## 사용 시 주의 사항

- 3점 트래킹과 데스크톱 사용을 전제로 합니다. 풀 바디 트래킹 중의 자세 고정은 지원하지 않습니다.
- 체형과 개조 내용에 따라 손발의 접지나 의상 표시를 추가 조정해야 할 수 있습니다.
- 특수한 Base 레이어나 다른 자세 변경 기믹과 함께 사용하면 의도대로 작동하지 않을 수 있습니다.
- 촬영 모드의 이동·회전과 바닥 높이는 도구의 포즈뿐 아니라 포즈를 선택하지 않았을 때의 기본·자체 모션도 보정합니다. VRChat에서 교체된 기본 모션과 시점 동작은 실제 클라이언트에서 확인하세요.
