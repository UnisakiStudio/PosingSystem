변경 내역

[3.2.0] - 미출시

추가

  • Inspector, 편집 작업, 설치 대화 상자, 표준 포즈 이름, 생성되는 VRChat 메뉴를 30개 언어로 표시할 수 있도록 했습니다.
  • Inspector와 게임 내 메뉴의 언어 선택을 통합했습니다. 기본값은 컴퓨터의 언어를 사용하고 마지막 선택을 같은 OS 사용자의 다른 프로젝트에서도 재사용합니다.
  • README·변경 내역·오프라인 사용 설명서를 선택한 언어로 열 수 있게 했습니다.
  • 표준 포즈 128개의 표시 이름과 각 기능 설명을 기존 용어에 맞춰 준비했습니다.

호환성

  • 기존 아바타 설정, 자체 이름, 에셋 참조, 파라미터 식별자, 라이선스 저장 방식은 유지합니다.

[3.1.2] - 2026-11-09

  • 머리 회전에 의한 포즈 변형 줄이기가 켜져 있을 때 엎드린 자세에서 일어나도 얼굴이 계속 위를 향하는 문제를 수정했습니다.
  • 발 높이를 꺼도 EX 메뉴의 설정 > 바로 누울 때 머리 자동 고정에서 머리 고정을 전환할 수 있게 했습니다. 3.1.0·3.1.1에서 항목이 사라진 아바타도 업데이트 후 빌드하면 복원됩니다.
  • Unity에서 아바타 자체의 체크를 꺼도 프리빌드 업데이트를 할 수 있게 했습니다.
  • 이전 공통 포즈 Controller가 Assets에 남아 있으면 업데이트 후 포즈 생성이 실패할 수 있는 문제를 수정했습니다. 직접 수정한 Controller 설정도 유지합니다.
  • 도구나 부모가 비활성화되어 공통 포즈 Animator를 사용할 수 없으면 대상 이름을 표시합니다. 설정 확인 > 대상 선택으로 해당 위치를 열 수 있습니다.
  • 프리빌드에 설정 변경이 표시되면 상세 > 저장 이후 변경 사항 확인에서 이전과 달라진 설정을 확인할 수 있게 했습니다.
  • 스크립트 오류로 빌드가 멈추면(PS050) Unity가 검출한 원래 오류를 최대 5개 표시합니다. 이 오류에 대해 문의하기에서 Unity·지원 도구의 버전과 오류 번호가 포함된 초안을 확인·수정한 뒤 보낼 수 있습니다.

프리빌드를 사용했다면 업데이트 후 프리빌드 업데이트를 누르고 씬을 저장한 다음 아바타를 다시 빌드·업로드하세요.

[3.1.1] - 2026-11-08

  • 좌우 반전을 꺼도 활성화한 바닥 높이와 뒤척이기가 VRChat EX 메뉴의 설정에 표시되도록 했습니다.
  • 이전 버전에서 포즈를 재정렬·삭제·개명했어도 다리 뻗기·릴랙스·한쪽 무릎 세우기에 올바른 뒤척이기 설정을 유지합니다. 완전히 Unpack했더라도 원래 포즈를 식별할 수 있으면 이어받습니다. 자체 포즈, 직접 끈 뒤척이기, 교체한 옆으로 눕기 모션은 보존됩니다.
  • VRChat에서 아바타를 선택할 때 잠깐 엎드리는 문제를 수정했습니다. 엎드리기만 선택하고 점프할 때 잠깐 바로 눕는 문제도 수정했습니다. 점프 전환은 기능 > 편의 기능 > 점프로 누운 자세 전환에서 끌 수 있으며 기본값은 켜짐입니다.
  • 업데이트 후 공통 포즈 Animator Controller 참조가 끊어지면 복구 가능한 경우 경고를 표시하고 설정에서 다시 생성합니다. 여러 아바타가 공유하는 Controller 참조도 유지합니다.
  • 프로젝트에 컴파일 오류가 있으면 빌드 시작 시 원인을 안내하고 중지합니다. 스크립트 오류로 참조를 확인할 수 없는 동안은 생성된 Controller의 자동 정리를 보류합니다.
  • 프로젝트에 상품과 같은 이름의 Prefab이 있어도 도구 추가 시 공식 Prefab을 우선합니다. 공통 Controller가 줄바꿈만 다른 경우에도 프리빌드를 계속할 수 있습니다.
  • 포즈 도구가 추가하는 FX 레이어(바닥 높이 등)의 Write Defaults를 아바타 설정에 맞추도록 했습니다.

프리빌드를 사용했다면 업데이트 후 씬의 도구에서 프리빌드 업데이트를 누르고 씬을 저장한 다음 아바타를 다시 빌드·업로드하세요.

[3.1.0] - 2026-11-07

  • 지원되는 포즈의 손발을 체형에 맞추는 자동 조정(IK), 아바타별 보정, 무릎 역방향 굽힘 방지를 추가했습니다.
  • 촬영 모드에서 아바타 위치와 방향을 조절할 수 있습니다. 위치·방향 동기화와 촬영 중 자신의 머리 표시도 선택할 수 있습니다.
  • 바닥 높이로 몸 전체를 위아래 최대 3m 이동할 수 있으며 발 높이와 구분하여 사용할 수 있습니다.
  • 호흡 동작, 기본 대기 흔들림 끄기, 목 방향에 의한 포즈 변형 줄이기를 추가했습니다.
  • Inspector에서 사용 기능과 파라미터 사용량을 확인할 수 있습니다. 포즈 검색·일괄 추가·정렬·Scene 간단 미리보기도 지원합니다.
  • 데스크톱 모드의 서기·웅크리기·앉기 전환을 빠르게 했습니다.
  • 설정 변경 후 프리빌드 경고, Inspector 스크롤 부하, 생성 데이터 정리 중의 긴 멈춤을 개선했습니다.
  • 자동 가져오기가 켜져 있을 때 바뀌지 않은 프리빌드에 업데이트 경고가 표시되고 업로드 시 재생성되는 문제를 수정했습니다. 가져온 결과는 생성할 아바타에 적용하고 원본 오브젝트의 가져오기 설정은 변경하지 않습니다.
  • 머리 기울기로 뒤척이기와 포즈별 대응 모션 설정을 추가했습니다.
  • 이전 프리셋의 뒤척이기 설정 유지, 자체 모션 가져오기, 생성 에셋 관리를 개선했습니다.

[3.1.0-beta.2] - 공개 베타(2026-11-05)

  • IK 위치 길이 기준에 고정 길이와 Head에서 Viewpoint까지의 높이 차(Y)·앞뒤 차(Z)를 추가했습니다.
  • Inspector 경고를 Hierarchy 오브젝트 이름 왼쪽에도 표시합니다. 프리빌드 미실행·설정 변경뿐 아니라 모션 가져오기·프리셋 작업 중 표시되는 경고도 지원합니다.
  • 씬을 열 때 등의 생성 데이터 자동 정리에서 다른 씬의 생성 Controller를 읽어 Unity가 오래 멈추는 문제를 수정했습니다.
  • 포즈 목록이나 기능을 바꿀 때 프리빌드 기록이 사라지는 문제를 수정했습니다. 미실행 대신 프리빌드 이후 설정이 변경되었다고 표시하고 Hierarchy에도 업데이트 필요 경고를 표시합니다.
  • Inspector·Hierarchy의 프리빌드 비교 결과를 공유하여 설정과 참조 에셋이 그대로인 동안의 스크롤 부하를 줄였습니다. 빌드 시 비교는 기존처럼 매번 수행합니다.

[3.1.0-beta.1] - 공개 베타(2026-11-04)

  • 데스크톱 모드의 일반 자세 전환을 한 번의 평가 방식으로 변경했습니다. 일반 빌드와 프리빌드에 적용하고 VR·특수 조건은 기존 경로를 유지합니다.
  • alpha.3 이전 프리빌드를 업데이트 대상으로 인식합니다.
  • 촬영 중 바닥 높이를 바꿀 때 시점을 유지하고 촬영 종료 후 최신 바닥 높이로 복귀합니다.
  • 자동 가져오기를 생성 시에만 검출하도록 변경하여 프리빌드·빌드가 수동 가져오기 설정을 추가·수정하지 않게 했습니다.
  • 자동 가져오기 ON/OFF, Base 변경, 수동 지정 해제를 재생성에 반영합니다. 여러 상품이 공유하는 수동 지정·조정을 유지하고 오래된 가져오기 모션은 기본 자세로 되돌립니다.
  • 프리빌드의 생성 Controller를 씬 GUID별·아바타별 하나의 파일로 관리합니다. 복제·다른 씬·Prefab의 공유 참조는 업데이트 전에 분리합니다.
  • 빌드 시 NDMF 임시 에셋 관리를 사용하며 편집용 생성 파일을 늘리지 않습니다.
  • 씬을 열거나 저장할 때 생성 데이터를 확인합니다. 미저장 편집·Undo/Redo·외부 참조는 유지하며 소유 관계가 명확한 미사용 파일만 휴지통으로 옮깁니다.
  • 가져오기 모션의 회전·조정 애니메이션·재생 위치를 반영합니다. 회전·RootT/RootQ·Humanoid 조정을 일반 포즈와 같은 처리로 통일했습니다.
  • 중첩 BlendTree의 조정은 가져오기 대상 전용으로 복제하여 원본 모션과 걷기용 블렌드 설정을 유지합니다.
  • 서기 전용의 재생 위치 지정은 원본 프레임 레이트로 정지 자세를 만들며 걷기 쪽 재생은 중지하지 않습니다.

[3.1.0-alpha.2] - 비공개 테스트(2026-10-26)

수정·변경

  • 도구 포즈 미선택 시의 기본·자체 모션에도 촬영 모드와 바닥 높이 보정을 적용합니다.
  • 바닥 높이를 위아래 3m로 확장했습니다. 50%가 원래 높이와 기본값, 0%가 3m 아래, 100%가 3m 위입니다.
  • 서기 전용 덮어쓰기가 원본 BlendTree를 변경하는 문제를 수정했습니다.
  • IK 규칙이 없는 자세는 수동 보정을 사용하고 불필요한 생성 경고를 줄였습니다.
  • 같은 이름 포즈의 조정 초안 혼동과 같은 에셋 내부의 모션 변경 누락을 수정했습니다.
  • 유효하지 않은 초기 포즈 번호가 다른 포즈를 초기 선택하는 문제를 수정했습니다.
  • 지원하지 않는 AnimatorOverrideController를 가져올 때 예외 대신 안내를 표시합니다.
  • 이전 프리셋을 적용해도 명시적으로 끈 뒤척이기 설정을 유지합니다.
  • 밝은 Editor 테마에서 기능 아이콘을 보기 쉽게 개선했습니다.

VRChat 클라이언트의 시점과 기본 모션 교체 후 동작 확인은 계속 진행 중입니다.

[3.1.0-alpha.1] - 공개 전

추가

  • 기능별 ON/OFF와 ExpressionParameters 사용량 표시를 추가했습니다.
  • 아바타를 앞쪽으로 이동·회전하는 촬영 모드를 추가했습니다.
  • 촬영 모드 동기화 선택을 추가했습니다. 로컬만 사용할 때 0 bit, 동기화 시 16 bit입니다.
  • 촬영 모드 중 자신의 아바타 머리가 숨겨지지 않도록 하는 설정을 추가했습니다.
  • 머리를 포함한 몸 전체를 위아래 3m 움직이는 바닥 높이를 추가했습니다. 50%가 원래 높이와 기본값, 0%가 3m 아래, 100%가 3m 위입니다.
  • 머리 기울기에 따른 뒤척이기와 포즈별 대응 애니메이션 설정을 추가했습니다.
  • 호흡 동작과 약·중·강·빠름·사용자 지정 설정을 추가했습니다.
  • 호흡 동작과 게임 내 ON/OFF 메뉴를 개별 선택할 수 있습니다. 동작만 사용할 때 0 bit, ON/OFF 동기화는 1 bit입니다.
  • VRChat 기본 대기 동작의 흔들림을 끄는 설정을 추가했습니다.
  • 목 방향 차이로 인한 포즈 변형을 줄이는 설정을 추가했습니다.
  • 지원되는 포즈의 팔다리 자동 조정(IK)과 아바타 전체·포즈별 ON/OFF를 추가했습니다.
  • IK 결과를 조정 애니메이션에 저장하는 IK 결과를 조정에 저장을 추가했습니다.
  • 아바타별 자세 보정, 무릎 역방향 굽힘 방지, 최소 굽힘 각도 설정을 추가했습니다.
  • 포즈 목록에서 Scene 자세를 확인하는 간단 미리보기를 추가했습니다.
  • 자세 분류 탭, 통합 검색, 여러 애니메이션 일괄 추가, 이동 순서 지정을 추가했습니다.
  • Inspector 내부에 상품·공통 시스템 변경 내역을 표시합니다.

변경

  • 프리셋 로딩을 빠르게 하여 도구 추가나 프리셋 목록 표시의 대기 시간을 줄였습니다.
  • 프리셋 추가·편집·삭제를 목록에 자동 반영합니다.
  • Inspector를 기능·포즈·아바타 설정의 세 탭으로 정리했습니다.
  • 설정 설명과 아이콘을 추가하고 상세 설정의 펼침 방식을 통일했습니다.
  • 호흡 상세를 기능 설정으로, 프리셋을 아바타 설정 맨 아래로 이동했습니다.
  • 자체 모션 개별 지정과 아바타 원래 자세의 자동 가져오기를 별도 설정으로 정리했습니다.
  • 발 높이 조정에서 생성하는 전신 애니메이션 중복을 줄였습니다.
  • 포즈 이미지 업데이트를 확인 대화 상자가 있는 버튼으로 바꿨습니다.
  • 경고 표시 설정을 설정 확인 안에 모았습니다.
  • 8bit 전용 Prefab의 새로 추가를 없애고 일반 Prefab의 기능 선택으로 통일했습니다. 기존 참조는 유지합니다.
  • VRChat Avatars SDK 최소 버전을 3.10.4로 올렸습니다.

수정

  • 도구 포즈 미선택 시의 기본·자체 모션도 촬영 모드·바닥 높이 보정 대상에 포함했습니다.
  • 서기 전용 덮어쓰기에서 원본 BlendTree를 변경하는 문제를 수정했습니다.
