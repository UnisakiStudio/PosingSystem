# Choose your language — v3.2.0

On first use, choose a language at the top of the Inspector and press Select / Continue. This is independent of the Unity interface language. You can change it in the same place later.

## VRChat menu language

In Features, choose In-game menu language, then upload your avatar. This setting is separate from the tool interface language. Upload the avatar again to change a menu that is already in VRChat.

## Pose names and translations

The pose list shows translated names. Search using either the original Japanese name or the translation. Original pose names, animations and internal parameters stay unchanged. Custom names without a translation keep their original text.

## Translations in progress

Translations are being added in the v3.2.0 development build. Missing translations use Japanese, or the original text for custom names. Coverage varies by language.
