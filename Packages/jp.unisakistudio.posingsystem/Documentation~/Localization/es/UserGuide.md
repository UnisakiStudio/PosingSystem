# Unisaki Posing System 3.2.0 — Manual en español

Unisaki Posing System es la base compartida de Kawaii Posing, Cool Posing y herramientas relacionadas.
Instala juntos el producto comprado y esta base mediante VCC o ALCOM. Usa Unity 2022.3,
VRChat Avatars SDK 3.10.4+, Modular Avatar 1.15.1+ y NDMF 1.14.0+.

## Idioma

Elige **Language / 言語** arriba del Inspector. Una sola elección controla
el Inspector y el menú VRChat generado. Sube de nuevo el avatar tras cambiar su idioma.
La última elección se recuerda en otros proyectos del mismo usuario del sistema de este
ordenador. Sin elección guardada se usa el idioma del sistema o inglés si no está disponible.
Se conserva la selección explícita de avatares existentes. Las preferencias no se sincronizan con otros PC.

## Configurar un avatar

Selecciona un avatar de escena con VRC Avatar Descriptor en Hierarchy y elige
**Unisaki Studio > Añadir Kawaii Posing** o **Añadir Cool Posing**. Aplica un preajuste
compatible cuando se ofrezca. El Inspector tiene **Funciones**, **Poses** y **Configuración del avatar**.
Elige poses y controles opcionales, ajusta su encaje y sube normalmente.
Usa **Actualizar precálculo** tras modificar ajustes si reutilizas datos precalculados.

## Manuales detallados

Abre **Manual** en el Inspector del producto comprado para leer su guía sin conexión en el idioma elegido.
`Documentation~/UserGuide.en.html` contiene instalación, adaptación al avatar,
controles VRChat, edición, memoria de parámetros, actualización y solución de problemas.
Las poses estándar se traducen al mostrarse; nombres propios, avatares, archivos de recursos,
objetos guardados e identificadores de parámetros conservan la escritura original.
Hay treinta idiomas. Inspector, diálogos, nombres estándar
y menús generados tienen catálogos completos para cada selección. La documentación sin conexión se proporciona en todos los idiomas.

Las [referencias rápidas en 30 idiomas](../../QuickReference/index.html) explican funciones y nombres de poses estándar. Son referencias breves; utiliza la lista de idiomas para la documentación completa.

## Licencias y asistencia

Usa el instalador de la tienda donde compraste el producto. Las licencias
conservan su almacenamiento existente por usuario en registro o archivos, separado de EditorPrefs.
Lee las condiciones originales incluidas. El acuerdo inglés existente del sistema común
es una traducción de referencia; el acuerdo de cada producto también se proporciona por separado.
