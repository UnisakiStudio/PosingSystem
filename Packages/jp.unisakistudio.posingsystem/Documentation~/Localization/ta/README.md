# Unisaki Posing System

Kawaii Posing Tool, Cool Posing Tool போன்றவை பயன்படுத்தும் பொதுவான போஸ் அமைப்பு இது. Modular Avatar மற்றும் NDMF மூலம் அவதாரைப் பதிவேற்றும்போது தேவையான பட்டிகளையும் அசைவூட்டங்களையும் உருவாக்குகிறது.

இந்த README உருவாக்கத்தில் உள்ள v3.2.0-க்கானது. அதிகாரப்பூர்வ வெளியீட்டுத் தேதி இன்னும் தீர்மானிக்கப்படவில்லை. நிறுவிய பதிப்பைப் போஸ் கருவியின் Inspector மேல்பகுதியில் பார்க்கலாம். [புதிய வசதிகள் மற்றும் மாற்றப் பதிவையும்](CHANGELOG.md) பார்க்கவும்.

## காட்சி மொழியும் இணையமில்லா ஆவணங்களும்

Inspector-இன் உச்சியிலுள்ள «Language / 言語» மூலம் காட்சி மொழியைத் தேர்ந்தெடுக்கவும். ஒரே தேர்வு Inspector-க்கும் உருவாக்கப்படும் VRChat பட்டிக்கும் பொருந்தும். விளையாட்டில் மொழியை மாற்ற அவதாரை மீண்டும் பதிவேற்றவும்.

தேர்வு செய்யாவிட்டால் கணினியின் மொழி பயன்படுத்தப்படும்; ஆதரிக்காத மொழிகளுக்கு ஆங்கிலம் பயன்படுத்தப்படும். Windows, macOS, Linux ஆதரிக்கப்படுகின்றன. கடைசித் தேர்வு EditorPrefs-இல் சேமிக்கப்பட்டு இந்தக் கணினியில் அதே OS பயனரின் பிற திட்டங்களிலும் பயன்படுத்தப்படும். அவதாரில் வெளிப்படையாகச் சேமித்த தேர்வு பாதுகாக்கப்படும். பிற கணினிகளுடன் ஒத்திசைக்காது. உரிமம் சேமிக்கும் முறை மாறாது.

இணைக்கப்பட்ட [மொழிப் பட்டியலில்](../index.html) README, மாற்றப் பதிவு, வழிகாட்டியைத் தேர்ந்தெடுக்கலாம். Inspector-இன் வழிகாட்டி மற்றும் மாற்றப் பதிவு இணைப்புகளும் தேர்ந்த மொழியைப் பின்பற்றும். அசல் பயன்பாட்டு விதிகளும் குறிப்புக்கான மொழிபெயர்ப்புகளும் முன்புபோலத் தனியே வழங்கப்படுகின்றன.

## டெஸ்க்டாப் முறையில் போஸ் மாற்றுதல்

டெஸ்க்டாப் முறையில் நிற்றல், குனிதல், உட்காருதல் இடையே மாறும்போது குறிப்பிட்ட போஸ் செயல்படுவதற்கான தாமதம் குறைக்கப்பட்டது. வழக்கமான கட்டமைப்பிலும் முன்கட்டமைப்பிலும் இயங்கும்; தனிக் கட்டளையோ கூடுதல் அமைப்போ தேவையில்லை. VR முறையிலும் சிறப்பு நிலைகளிலும் பழைய செயலாக்கம் நீடிக்கிறது. பழைய முன்கட்டமைப்பைப் புதுப்பித்த பிறகு பதிவேற்றவும்.

## நிறுவலும் பதிப்புப் புதுப்பித்தலும்

ஒவ்வொரு தயாரிப்பின் வாங்கிய கோப்புகளையும் நிறுவல் வழிமுறைகளையும் பின்பற்றி VCC அல்லது ALCOM மூலம் போஸ் கருவியைச் சேர்க்கவும். இந்த அமைப்பு போஸ் கருவியின் சார்புத் தொகுப்பாக நிறுவப்படும்.

v3.2.0-க்குத் தேவையான சூழல்:

- Unity 2022.3 VRChat அவதார் திட்டம்
- VRChat Avatars SDK 3.10.4 அல்லது புதியது
- Modular Avatar 1.x தொடரில் 1.15.1 அல்லது புதியது
- NDMF (Non-Destructive Modular Framework) 1.x தொடரில் 1.14.0 அல்லது புதியது

Kawaii Posing Tool பயன்படுத்தினால், ALCOM / VCC-இல் அதை 3.2.0-க்குப் புதுப்பித்து Unisaki Posing System-மும் 3.2.0 ஆகியுள்ளதா உறுதிப்படுத்தவும். முன்கட்டமைப்பைப் பயன்படுத்தியிருந்தால் «முன்கட்டமைப்பைப் புதுப்பி» அழுத்தி, காட்சியைச் சேமித்தபின் அவதாரைப் பதிவேற்றவும்.

Cool Posing Tool 1.2.0 பொதுவான 3.2.0-ஐப் பயன்படுத்துகிறது. தயாரிப்பையும் பொது அமைப்பையும் பொருந்தும் பதிப்புகளுக்கு ஒன்றாகப் புதுப்பிக்கவும்.

### 8bit பதிப்பைப் பயன்படுத்தியவர்களுக்கு

புதிய சேர்த்தல்கள் வழக்கமான Prefab-இல் ஒருங்கிணைக்கப்பட்டன. «வசதிகள்»-இல் தேவையற்றவற்றை அணைத்துப் பயன்பாட்டைக் குறைக்கலாம். போஸ் தேர்வு மட்டும் இருந்தால் அடிப்படைப் பயன்பாடு 8 bit.

ஏற்கெனவே அமைத்த அவதார்களும் முன்னமைவுகளும் கொண்ட குறிப்புகளைப் பாதுகாக்க பழைய 8bit Prefab ஒவ்வொரு தயாரிப்பின் «Editor/Legacy»-இலும் உள்ளது. தற்போதைய 8bit பதிப்பைப் பயன்படுத்த Prefab-ஐ நீக்கவோ மாற்றவோ தேவையில்லை. Unity-இன் புதிய சேர்த்தல் பட்டியில் 8bit பதிப்பைத் தேர்ந்தெடுக்கும் நடைமுறை நீக்கப்பட்டது.

## அமைப்புத் திரையைப் புரிந்துகொள்ளுதல்

Hierarchy-இல் அவதாருக்குள் உள்ள «可愛いポーズ», «カッコいいポーズ» போன்றவற்றைத் தேர்ந்தெடுத்து அமைக்கலாம்.

| தாவல் | அமைப்புகள் |
| --- | --- |
| வசதிகள் | விளையாட்டுப் பட்டியில் சேர்க்கும் உருப்படிகள், வசதி விருப்பங்கள், சின்னப் படங்கள், ExpressionParameters பயன்பாடு |
| போஸ்கள் | போஸ் தேர்வு, சேர்த்தல், வரிசைமாற்றம், Scene முன்னோட்டம், தனிப்போஸ் விவரங்கள், அசைவூட்டத் திருத்தம் |
| அவதார் அமைவு | உடலமைப்புக்கான திருத்தம், முழங்கால் திருத்தம், அசல் போஸ்கள் மற்றும் தனிப்பயன் இயக்கங்களின் இறக்குமதி, முன்னமைவுகள் |

விரிவான அமைப்புகளுள்ள உருப்படிகளில் «அமைப்புகளைத் திற» அழுத்தினால் அதன் கீழே அமைப்புப் பகுதி திறக்கும். மூச்சு அமைப்புகளும் «வசதிகள்»-இல் உள்ளன.

மேலுள்ள «உதவி / மாற்றப் பதிவு» மூலம் வழிகாட்டி, ஆதரவு, மாற்றப் பதிவைத் திறக்கலாம். மாற்றப் பதிவில் தயாரிப்புக்கும் Unisaki Posing System-க்கும் இடையே மாறிப் படிக்கலாம்.

## வசதிகளும் ExpressionParameters பயன்பாடும்

«வசதிகள்»-இன் «பட்டி வசதிகள்»-இல் தேர்ந்தவை விளையாட்டுப் பட்டியில் தோன்றும். எடுத்துக்காட்டாக «பிரதிபலி» தேர்ந்தால் விளையாட்டில் பிரதிபலிப்பை மாற்றலாம். Inspector-இல் தேர்ந்தெடுப்பதால் மட்டும் எல்லாப் போஸ்களும் எப்போதும் பிரதிபலிக்கப்படாது.

| வசதி | கூடுதல் bit பயன்பாடு |
| --- | ---: |
| பிரதிபலி | 1 bit |
| சைகைகள் நிறுத்து | 1 bit |
| மூச்சு அசைவூட்டத்தை இயக்கு | 0 bit |
| மூச்சு (விளையாட்டில் இயக்குதல்/நிறுத்துதல்) | 1 bit |
| பாத உயரம் | 8 bit |
| தரை உயரம் | 8 bit |
| புகைப்பட முறை (உங்கள் திரையில் மட்டும்) | 0 bit |
| புகைப்பட முறையை ஒத்திசை | 16 bit |
| புகைப்பட முறையில் தலையைக் காட்டு | 0 bit |
| VRChat இயல்புநிலை அசைவை நிறுத்து | 0 bit |
| தலைச் சுழற்சியால் போஸ் சிதைவதைக் குறை | 1 bit (புரளலுடன் பகிரப்படும்) |
| புரளு | 10 bit (இதில் 1 bit போஸ் சிதைவு தடுப்புடன் பகிரப்படும்) |

புரளலுக்கு இயக்குதல்/நிறுத்துதலுக்காக 1 bit, தலைச் சாய்வுக்கு 8 bit, கழுத்துப் பூட்டுக்கு 1 bit தேவை. போஸ் சிதைவைக் குறைக்கும் வசதி ஏற்கெனவே இயக்கப்பட்டிருந்தால், புரளலைச் சேர்க்கும்போது 9 bit மட்டுமே கூடும். பகிர்ந்தவை இருமுறை எண்ணப்படாது; தேர்வை மாற்றும்போது காட்சியும் புதுப்பிக்கப்படும்.

காட்டப்படும் மொத்தம் அந்த அவதாரில் உள்ள போஸ் கருவிகளுக்கானது. உடைகளும் பிற கருவிகளும் உள்ளிட்ட முழு அவதாரின் மொத்தம் அல்ல. பல போஸ் கருவிகளை ஒன்றாகப் பயன்படுத்தினாலும் பொதுவான அமைப்புகள் இருமுறை எண்ணப்படாது. போஸ் எண்ணிக்கை அடிப்படை எண் வரம்பைத் தாண்டினால் தேர்வுக்கும் கூடுதல் bit தேவை.

### பாத உயரமும் தரை உயரமும்

- «பாத உயரம்»: தலையின் இடத்தை வைத்துக்கொண்டு பாதப் பகுதியின் உயரத்தை மாற்றும். பாதங்களைத் தரைக்கோ படுக்கைக்கோ பொருத்தப் பயன்படுத்தவும்.
- «தரை உயரம்»: தலை உட்பட முழு உடலையும் மேலே/கீழே நகர்த்தும். 50% அசல் உயரம், 0% அதைவிட 3m கீழே, 100% அதைவிட 3m மேலே. இயல்புநிலை 50%.

இரண்டும் விளையாட்டின் «அமைப்புகள்»-இல் உள்ளன; «தரை உயரம்», «பாத உயரம்»-க்கு அடுத்து வரும். மையத்திலிருந்து மாற்றினால் உடல் மேலே/கீழே நகரும்; சுமார் 50%-க்கு மீட்டால் அசல் உயரத்துக்குத் திரும்பித் திருத்தம் முடியும். தனியாக மிதத்தல் இயக்க/நிறுத்த சுவிட்ச் இல்லை. மிதத்தல் தொடங்கும்போதும் தரை உயரத்தைக் கையாளும்போதும் பார்வையிடம் திருத்தப்படும்.

சாதாரண அசைவூட்டங்களில் பாத உயரத் திருத்தத்திற்காக முழு உடலின் இயக்கத்தையும் மீண்டும் உருவாக்காத முறைக்கு மாற்றப்பட்டது. இதனால் உருவாக்கும் அசைவூட்டத் தரவு குறையும்; முழு அவதாரின் அளவும் எப்போதும் மூன்றில் ஒரு பங்காகிவிடும் என்று பொருள் இல்லை.

### புகைப்பட முறை

1. «வசதிகள் > பட்டி வசதிகள் > புகைப்பட முறை» இயக்கு.
2. VRChat-இல் «புகைப்பட முறை» திறந்து «போஸ் தேர்வு»-இல் போஸைத் தேர்ந்தெடு.
3. «தூரம்» மூலம் அதிகபட்சம் 3m முன்னோக்கி நகர்த்து, «திசை» மூலம் சுழற்று. தூரம் 0-ஐவிட அதிகமானால் அவதார் உங்களை நோக்கும்.
4. தேவைக்கேற்ப «பாதங்களை பூட்டு» இயக்கு. தொடங்கும்போது கட்டாயமாகப் பூட்டாததால் முதலில் இடத்தை மாற்றலாம். «சைகைகள் நிறுத்து» பட்டியில் சேர்த்திருந்தால் இதே திரையில் கை வடிவத்தையும் மாற்றலாம்.
5. «புகைப்படம் முடி» மூலம் தூரத்தையும் திசையையும் மீட்டுப் பாதப் பூட்டை விடுவி.

உங்கள் திரையில் மட்டும் பயன்படுத்தும் புகைப்பட முறையின் நகர்வும் சுழற்சியும் 0 bit. மற்றவர்களுக்கும் இடத்தையும் திசையையும் காட்ட «வசதி விருப்பங்கள் > புகைப்பட முறையை ஒத்திசை» இயக்கு. தூரத்துக்கும் திசைக்கும் மொத்தம் 16 bit தேவை.

அருகிலுள்ள உங்கள் அவதாரின் தலை மறைந்தால் «வசதி விருப்பங்கள் > புகைப்பட முறையில் தலையைக் காட்டு» இயக்கு. புகைப்படம் எடுக்கும்போது உங்கள் திரையில் மட்டும் பொருந்தும்; முடித்ததும் சாதாரணக் காட்சிக்குத் திரும்பும்.

### குதித்துப் படுக்கும் போஸ்களை மாற்று

மல்லாந்தும் குப்புறவும் இரண்டையும் தேர்ந்தால் ஒரே இடத்தில் குதித்து மாற்றலாம். ஒன்றை மட்டும் தேர்ந்தால் அதையே வைத்திருக்கும். குதித்து மாற்ற விரும்பாவிட்டால் Unity-இன் «வசதிகள் → வசதி விருப்பங்கள்»-இல் «குதித்துப் படுக்கும் போஸ்களை மாற்று» அணைக்கவும். கூடுதல் ஒத்திசைவு அளவுருப் பயன்பாடு 0 bit. பல போஸ் கருவிகளுள்ள அவதாரில் ஒன்றில் அணைத்தாலும் முழு அவதாருக்கும் பொருந்தும்.

### புரளு

ஆதரிக்கும் படுக்கும் போஸில் தலையை இடம்/வலம் சாய்த்தால் உடலும் மென்மையாகப் புரளும். எல்லாப் படுக்கும் போஸ்களும் தானாக ஆதரிக்கப்படுவதில்லை.

1. «வசதிகள் > பட்டி வசதிகள் > புரளு» இயக்கு.
2. «போஸ்கள்»-இல் பயன்படுத்தும் படுக்கும் போஸின் «விவரங்கள்» திறந்து «புரளலை இயக்கு» இயக்கு.
3. «புரளலுக்கான பக்கவாட்டு போஸ்»-இல் பக்கவாட்டு அசைவூட்டத்தை அமை. அசல் மற்றும் பக்கவாட்டு போஸ்களிலிருந்து இடம்/வலம் புரளல் உருவாகும். தேவைக்கேற்ப «தரைத் தொடர்புத் திருத்த வலிமை» மாற்றவும்.
4. VRChat-இல் ஆதரிக்கும் போஸைத் தேர்ந்து «புரளு» இயக்கு. கழுத்துப் பூட்டை விடுவித்துப் பயன்படுத்தவும்.

புரளலைப் பயன்படுத்தும் போஸில் தலைச் சாய்வு அசைவூட்டத்தின் இயக்க இடத்தை நிர்ணயிப்பதால் வழக்கமான MotionTime அமைப்பு கிடைக்காது. ஏற்கெனவே முடித்த புரளல் அசைவூட்டத்தைப் பயன்படுத்தினால் வழக்கமான அசைவூட்டப் புலத்தில் அமைத்து «புரளலுக்கான பக்கவாட்டு போஸ்»-ஐ காலியாக விடவும். இயக்க இடம் 0 இடப்பக்கம், 0.5 மல்லாந்த நிலை, 1 வலப்பக்கம் ஆகும் அசைவூட்டத்தைத் தயாரிக்கவும்.

### மூச்சும் இயல்புநிலை அசைவும்

«வசதிகள் > வசதி விருப்பங்கள் > மூச்சு அசைவூட்டத்தை இயக்கு» மூலம் மார்பு போன்றவை மூச்சுக்கு ஏற்ப அசையும். «அமைப்புகளைத் திற» மூலம் ஒவ்வொரு போஸ் வகைக்கும் «இல்லை, மெலிது, நடுத்தரம், வலிமை, விரைவு, தனிப்பயன்» தேர்ந்தெடுக்கலாம். «விரைவு» வேகமான மூச்சு. «தனிப்பயன்»-இல் உங்கள் மூச்சு அசைவூட்டத்தை அமைக்கலாம்.

மூச்சு அசைவு மட்டும் 0 bit. VRChat-இல் அதை நிறுத்தவும் மீண்டும் தொடங்கவும் «பட்டி வசதிகள் > மூச்சு»-வும் இயக்கவும். இயக்க/நிறுத்த ஒத்திசைவுக்கு 1 bit தேவை. வலிமையை மாற்றினாலும் bit எண்ணிக்கை கூடாது.

மார்புடன் கழுத்து, தோள்கள், கைகள் போன்றவையும் அசைந்து தலை மற்றும் கைகளின் இடப்பெயர்வைக் குறைக்கின்றன. இடம் முற்றிலும் பூட்டப்படாததால் உடலமைப்புக்கும் போஸுக்கும் ஏற்ப வலிமையைத் தேர்ந்தெடுக்கவும்.

«வசதி விருப்பங்கள் > VRChat இயல்புநிலை அசைவை நிறுத்து» என்பது VRChat சேர்க்கும் இயல்புநிலை ஓய்வு உடலசைவைக் குறைக்கும் அமைப்பு. இயல்பாக அணைந்திருக்கும்; போஸ் கருவியின் மூச்சையும் பிற தனிப்பயன் இயக்கங்களையும் பாதுகாக்கும். மூச்சு அசைவு இல்லாவிட்டாலும் தேர்ந்தெடுக்கலாம்; bit பயன்பாடு அதிகரிக்காது. இயல்புநிலை ஓய்வு இயக்கம் தவிர பிற காரணங்களால் வரும் அசைவை இது நிறுத்தாது.

பல போஸ் கருவிகளைப் பயன்படுத்தினால் ஒன்றில் இயல்புநிலை அசைவை நிறுத்தினாலும் முழு அவதாருக்கும் பொருந்தும். மீட்டமைக்க எல்லாக் கருவிகளிலும் இதை அணைத்து மீண்டும் பதிவேற்றவும்.

### தலைச் சுழற்சியால் போஸ் சிதைவதைக் குறை

கழுத்துப் பூட்டை விடுவிக்கும்போது அசல் போஸிலிருந்து கழுத்தின் திசை மாறுவதால் போஸ் சிதைந்தால் பயன்படுத்தவும். «வசதிகள் > வசதி விருப்பங்கள்»-இல் உள்ளது; தனி விளையாட்டுப் பட்டி சேர்க்கப்படாது. கழுத்து பூட்டியிருக்கும்போது அசல் போஸின் திசையே பயன்படும். மல்லாந்த நிலையில் அசல் மேல்நோக்கும் திசையைப் பாதுகாக்க அதைத் திருத்தத்திலிருந்து விலக்குகிறது.

### பட்டியின் சின்னப் படங்கள்

- «போஸ் சின்னங்களை உருவாக்கு»: அவதார் ஒவ்வொரு போஸையும் எடுக்கும் படங்களை உருவாக்கிப் பட்டியில் காட்டும். போஸ்களை அறிய உதவும்; பட உருவாக்கத்தால் கட்டமைப்பு நேரம் அதிகரிக்கும்.
- «சின்ன அளவைக் குறை»: படத் தெளிவுத்திறனைக் குறைத்து அவதார் அளவைக் குறைக்கும்.

Android கட்டமைப்புகளில் போஸ் சின்னங்கள் உருவாக்கப்படாது. உடைகளை மாற்றியபின் «சின்னங்களை மீண்டும் படமெடு» பயன்படுத்தவும். போஸ் பட்டியலின் படங்களை «போஸ் சிறுபடங்களைப் புதுப்பி» மூலம் புதுப்பிக்கலாம். நேரம் எடுக்கும் செயலாக இருப்பதால் உறுதிப்படுத்தல் உரையாடலைப் படித்தபின் இயக்கவும்.

## போஸ் சேர்த்தல், வரிசைமாற்றம், முன்னோட்டம்

«போஸ்கள்»-இன் இடப்பக்கத்தில் வகையைத் தேர்ந்தெடுக்கவும். உச்சியிலுள்ள பூதக்கண்ணாடித் தாவலில் எல்லா வகைகளிலும் பெயரைத் தேடலாம். «விவரங்கள்» திறந்து அசைவூட்டம், சின்னம், MotionTime போன்றவற்றை ஒன்றாக அமைக்கலாம்.

பல அசைவூட்டங்களைச் சேர்க்கும் பகுதியில் இழுத்துவிடலாம்; அல்லது Project-இல் தேர்ந்தெடுத்து «Project-இல் தேர்ந்த கிளிப்புகளை இறக்குமதி செய்» அழுத்தி ஒன்றாகச் சேர்க்கலாம். ஒரே கிளிப்பின் நகல்கள் நீக்கப்படும்.

வரிசையை மாற்ற «விவரங்கள்»-இன் «வரிசை»-இல் இலக்கைத் தேர்ந்தெடுக்கவும். மேல்/கீழ் நகர்த்தும் பொத்தான்களையும் பயன்படுத்தலாம். நகர்த்தினாலும் விவரங்களின் திறந்த/மூடிய நிலை பாதுகாக்கப்படும்.

ஒவ்வொரு போஸின் «முன்னோட்டம்» அழுத்தினால் திருத்தச் சாளரத்தைத் திறக்காமல் Scene-இல் பார்க்கலாம். முடித்ததும் அசல் காட்சிக்குத் திரும்பும். இந்த எளிய முன்னோட்டம் MA அல்லது NDMF கட்டமைப்பை இயக்காது; எனவே கட்டமைப்பில் சேரும் உடைகள், FloorAdjuster போன்றவற்றின் இறுதி முடிவிலிருந்து மாறலாம். கட்டமைப்புக்குப் பிறகும் உடைகளையும் தரைத் தொடர்பையும் சரிபார்க்கவும்.

## அசைவூட்டத் திருத்தமும் தானியங்கிக் கை-கால் திருத்தமும் (IK)

«போஸ்கள்»-இல் «அசைவூட்டத் திருத்தம்» திறந்தால் முன்னோட்டத்துடன் உடலையும் கை-கால்களையும் நுணுக்கமாகத் திருத்தலாம். முடித்தபின் சாளரத்தின் சேமிப்புச் செயலைப் பயன்படுத்தித் திருத்த அசைவூட்டத்தைச் சேமிக்கவும்.

தானியங்கிக் கை-கால் திருத்தம் ஆதரிக்கும் தயாரிப்புகளிலும் போஸ்களிலும் அவதாரின் உடலமைப்புக்கு ஏற்ப கை-கால் இடங்கள் மாற்றப்படும். அசைவூட்டத் திருத்தத் திரையின் «தானியங்கிக் கை-கால் திருத்தத்தை இயக்கு» மூலம் முழுவதற்கும், «இந்த போஸுக்கு IK இயக்கு» மூலம் தனிப்போஸுக்கும் மாற்றலாம். தானியங்கித் திருத்தம் இல்லாத போஸ்களுக்கு அந்தத் தகவல் காட்டப்படும்.

தானியங்கித் திருத்தத்தை அடிப்படையாகக் கொண்டு கைமுறையில் முடிக்க «IK முடிவைத் திருத்தத்தில் பதியவும்» அழுத்தவும். அப்போதைய IK முடிவை புதிய திருத்த அசைவூட்டத்தில் எழுதி, அந்த அவதாரின் அந்தப் போஸுக்கு IK அணைக்கப்படும். அசல் அசைவூட்டம் பாதுகாக்கப்படும். மொத்த மற்றும் தனிப்போஸ் தானியங்கித் திருத்தங்கள் இயக்கப்பட்டு பொருந்தும் IK அமைப்புகள் இருந்தால் இப்பொத்தான் கிடைக்கும்.

«அவதார் அமைவு»-இன் «முழங்கால் பின்னோக்கி மடங்குவதைத் தடு» மூலம் முழங்கால் திருத்தத்தை மாற்றலாம். விவரங்களின் «குறைந்தபட்ச முழங்கால் மடக்கம் (பாகை)» மூலம் கோணத்தை அமைக்கவும். பொருந்தும் திருத்தத் தரவு இருந்தால் «அவதார் திருத்தத்தை இயக்கு» கிடைக்கும். தானியங்கிக் கை-கால் திருத்தத்துடன் ஒன்றே செய்யும் சில திருத்தங்களை ஒருங்கே பயன்படுத்த முடியாது.

## அசல் போஸ்கள், தனிப்பயன் இயக்கங்கள், முன்னமைவுகள்

இவற்றை «அவதார் அமைவு»-இல் அமைக்கலாம்.

- «அசல் நிற்றல், குனிதல், குப்புறப் போஸ்களைப் பயன்படுத்து»: அவதாரில் முதலில் அமைத்த போஸ்களைத் தானாக இறக்குமதி செய்யும்.
- «உங்கள் இயக்கங்களைப் பயன்படுத்து»: இறக்குமதி அமைப்பைத் திறந்து நிற்றல், குனிதல் (Crouching), குப்புறப் படுத்தல் (Prone) போன்ற ஒவ்வொரு வகைக்கும் தனித்தனியாக இயக்கத்தை அமைக்கவும். பொதுவாக ஒவ்வொரு வகைக்கும் ஓர் இயக்கத்தை அமைக்கவும்.
- «பிற கருவிகளுடன் கண்காணிப்புப் பூட்டுகளை ஒருங்கிணை»: பிற கருவிகளுடன் சேர்த்துப் பயன்படுத்தும்போது பூட்டுகள் சரியாக இயங்காவிட்டால் இயக்கவும்.

உங்கள் இயக்கங்களைத் தனியாகக் குறிப்பிடும் இறக்குமதி அமைப்புகள், அசல் போஸ்களைத் தானாக இறக்குமதி செய்யும் அமைப்பிலிருந்து வேறானவை.

முன்னமைவுகள் தாவலின் அடியில் உள்ளன. பெயரால் தேடி «இந்த முன்னமைவைப் பயன்படுத்து» மூலம் போஸ் அமைப்புகளை மாற்றலாம். முக்கியமாக நிறுவும்போதான தொடக்க அமைவுக்கானது; தற்போதைய அமைப்புகளை மாற்றுவதால் திருத்தங்கள் இருந்தால் முதலில் சேமிக்கவும்.

முன்னமைவுப் பட்டியலைக் காட்டும்போது பெயர்களும் ஆதரிக்கும் அவதார் தகவலும் மட்டும் ஏற்றப்படும். தேர்ந்த முன்னமைவைப் பயன்படுத்தும்போதுதான் திருத்த அசைவூட்டங்கள் ஏற்றப்படும். முதன்முறை பட்டியல் உருவாக்கும்போதும் எல்லா அவதார்களின் அசைவூட்டங்களையும் முன்கூட்டியே ஏற்றாது.

பட்டியல் «அவதாருக்குப் பொருந்தும்», «பயனர் முன்னமைவுகள்», «Unisaki Studio அதிகாரப்பூர்வ முன்னமைவுகள்» எனப் பிரிக்கப்பட்டுள்ளது. «உள்ளமை முன்னமைவுகளை மறை» ஒரே திட்டத்தில் பகிரப்படும் காட்சி அமைப்பு. முன்னமைவுகளைச் சேர்த்தால், திருத்தினால், நீக்கினால் பட்டியல் புதுப்பிக்கப்படும். காட்சி மாறாவிட்டால் «மீளேற்று» அழுத்தவும்.

## முன்கட்டமைப்பும் எச்சரிக்கைகளும்

«அசல் நிற்றல், குனிதல், குப்புறப் போஸ்களைப் பயன்படுத்து» இயக்கப்பட்டால் ஒவ்வொரு உருவாக்கத்தின்போதும் அவதாரின் Base-இலிருந்து இயக்கங்கள் கண்டறியப்படும். முடிவுகள் கைமுறை இறக்குமதி அமைப்புகளில் எழுதப்படாததால் தானியங்கி இறக்குமதி மட்டும் பயன்படுத்தினால் பட்டியல் குறிப்பிடாத நிலையிலேயே இருக்கும். Base இயக்க மாற்றங்களும் தானியங்கி இறக்குமதியை இயக்குதல்/அணைத்தலும் அடுத்த உருவாக்கத்தில் பொருந்தும்.

பதிவேற்றும்போதான தானியங்கி இறக்குமதி கட்டமைப்பு நகலுக்குப் பொருந்தும். காட்சியின் அசல் பொருள், இறக்குமதி அமைப்புகள், மூல Controller அல்லது இயக்கங்களை மாற்றாது. முன்கட்டமைப்பு இருந்து உள்ளீடுகள் மாறவில்லை என்றால் அந்த முடிவு மீண்டும் பயன்படுத்தப்படும்.

கைமுறைத் தேர்வுள்ள வகைகளில் அதற்கு முன்னுரிமை தரப்பட்டு சுழற்சி, திருத்த அசைவூட்டம், இயக்க இடம் ஆகியவையும் பொருந்தும். «பயன்படுத்து» அணைத்த அமைப்போ ஏற்கெனவே குறிப்பிட்ட இயக்கத்தை அகற்றிய அமைப்போ அந்த வகைக்கான தானியங்கி இறக்குமதியை நிறுத்தும். «கைமுறைத் தேர்வை அழி» மூலம் அந்த வகையின் அமைப்பையும் திருத்தத்தையும் அகற்றினால் தானியங்கி இறக்குமதி இயக்கப்பட்டிருக்கும்போது அடுத்த உருவாக்கத்தில் மீண்டும் கண்டறியும். Undo மூலம் மீட்டலாம். ஒரே வகைக்கு பல பழைய அமைப்புகள் இருந்தால் Inspector-இல் தேர்ந்த செயல்படும் அமைப்புக்கு முன்னுரிமை.

பழைய தானியங்கி இறக்குமதி பட்டியலில் சேர்த்த அமைப்புகளை கைமுறையில் பதிவு/திருத்தம் செய்தவற்றிலிருந்து பிரிக்க முடியாததால் தானாக நீக்காது. தானியங்கி இறக்குமதிக்கு மீட்க விரும்பும் வகைகளுக்கு மட்டும் «கைமுறைத் தேர்வை அழி» பயன்படுத்தவும். ஒரே அவதாரில் பல தயாரிப்புகள் இருந்தால் மற்ற தயாரிப்புகளின் கைமுறை அமைப்புகளும் பொதுவான அசல் போஸ்களுக்குப் பொருந்தும்.

முன்கட்டமைப்பு உருவாக்கிய தரவை மீண்டும் பயன்படுத்தி அவதார் கட்டமைப்பு நேரத்தைக் குறைக்கிறது. «முன்கட்டமைப்பைப் புதுப்பி» மூலம் உருவாக்கவும் புதுப்பிக்கவும் முடியும். வழக்கமான அவதார் கட்டமைப்பும் தேவையான தரவை உருவாக்குவதால் ஒவ்வொரு முறையும் கைமுறையாக முன்கட்டமைக்கத் தேவையில்லை.

அமைப்புகளை மாற்றினால் புதுப்பிப்பு தேவைப்படும் நிலையாகி Inspector மேலுள்ள «அமைப்புகளைச் சரிபார்» அல்லது Hierarchy குறியீடு தெரிவிக்கும். போஸ் அல்லது IK அமைப்புகளை மாற்றியபின் முன்கட்டமைப்பைப் புதுப்பிப்பது அடுத்த கட்டமைப்புகளின் நேரத்தைக் குறைக்கும்.

«எச்சரிக்கைக் காட்சி அமைப்புகள்», «அமைப்புகளைச் சரிபார்» பெட்டிக்குள் உள்ளன. எச்சரிக்கை வகைகளையோ Hierarchy குறியீட்டையோ மறைக்கலாம். மறைப்பதால் அமைப்புச் சிக்கல் தீராது; உருவாக்கிய தரவும் புதுப்பிக்கப்படாது. பிழைகளும் தேவையான உருவாக்கச் செயல்களும் நீடிக்கும்.

## பயன்பாட்டுக் குறிப்புகள்

- மூன்று புள்ளிக் கண்காணிப்பு மற்றும் டெஸ்க்டாப் பயன்பாட்டுக்காக வடிவமைக்கப்பட்டது. முழு உடல் கண்காணிப்பில் போஸ் பூட்டுதல் ஆதரிக்கப்படாது.
- உடலமைப்பும் மாற்றங்களும் பொறுத்து கை-கால் தரைத்தொடர்புக்கும் உடைகளின் தோற்றத்துக்கும் கூடுதல் திருத்தம் தேவைப்படலாம்.
- சிறப்பு Base அடுக்குகள் அல்லது பிற போஸ் மாற்றுக் கருவிகளுடன் எதிர்பார்த்தபடி இயங்காமல் இருக்கலாம்.
- புகைப்பட முறையின் நகர்வு/சுழற்சியும் தரை உயரமும் கருவிப் போஸ்களுக்கும் போஸ் தேர்ந்தெடுக்காதபோது இயல்புநிலை/தனிப்பயன் இயக்கங்களுக்கும் திருத்தம் செய்கின்றன. VRChat-இல் மாற்றப்படும் இயல்புநிலை இயக்கங்களையும் பார்வையின் நடத்தையையும் உண்மையான செயலியில் சரிபார்க்கவும்.
