Unisaki Posing System 3.2.0 — தமிழ் வழிகாட்டி

Unisaki Posing System என்பது Kawaii Posing, Cool Posing மற்றும் தொடர்புடைய கருவிகளின் பொதுவான மைய அமைப்பு. வாங்கிய தயாரிப்பையும் இதையும் VCC அல்லது ALCOM மூலம் ஒன்றாக நிறுவவும். Unity 2022.3, VRChat Avatars SDK 3.10.4+, Modular Avatar 1.15.1+, NDMF 1.14.0+ பயன்படுத்தவும்.

மொழி

கருவி Inspector-இன் உச்சியில் Language / 言語 தேர்ந்தெடுக்கவும். ஒரே தேர்வு Inspector-க்கும் உருவாக்கும் VRChat பட்டிக்கும் பொருந்தும். மொழியை மாற்றியபின் அவதாரை மீண்டும் பதிவேற்றவும். இந்தக் கணினியில் அதே OS பயனரின் பிற திட்டங்களுக்காகக் கடைசித் தேர்வு நினைவில் வைக்கப்படும். சேமித்த தேர்வு இல்லாவிட்டால் OS மொழியைப் பின்பற்றி, கிடைக்காவிட்டால் ஆங்கிலம் பயன்படுத்தும். எல்லா போஸ் கருவிகளும் அவதார்களும் ஒரே மொழியைப் பயன்படுத்துகின்றன. எந்தக் கருவியின் Inspector-இல் மொழியை மாற்றினாலும் பொதுவான அமைப்பு புதுப்பிக்கப்படும்; தனித்தனி அவதார்களின் மொழித் தேர்வுகள் பயன்படுத்தப்படாது. மொழி விருப்பங்கள் பிற கணினிகளுடன் ஒத்திசைக்காது. மொழி சேமிக்கப்படாதபோது முதல் நிறுவல் உறுதிப்படுத்தலில் மட்டுமே மொழிப் பொத்தான் காட்டப்படும். பின்னர் மொழியை Inspector-இல் மாற்றலாம்.

அவதாரை அமைத்தல்

Hierarchy-இல் VRC Avatar Descriptor கொண்ட காட்சி அவதாரைத் தேர்ந்தெடுத்து Unisaki Studio > Kawaii Posing சேர் அல்லது Cool Posing சேர் தேர்ந்தெடுக்கவும். பொருந்தும் அவதார் முன்னமைவு வழங்கப்பட்டால் பயன்படுத்தவும். கருவியின் Inspector-இல் வசதிகள், போஸ்கள், அவதார் அமைவு தாவல்கள் உள்ளன. வேண்டிய போஸ்களையும் விருப்பக் கட்டுப்பாடுகளையும் தேர்ந்தெடுத்து, பொருத்தத்தைத் திருத்தி, வழக்கம்போல் பதிவேற்றவும். சேமித்த முன்கட்டமைப்புத் தரவைப் பயன்படுத்தினால் அமைப்புகளை மாற்றியபின் முன்கட்டமைப்பைப் புதுப்பி பயன்படுத்தவும்.

விரிவான வழிகாட்டிகள்

வாங்கிய தயாரிப்பின் Inspector-இல் வழிகாட்டி திறந்து தேர்ந்த மொழியின் இணையமில்லா வழிகாட்டியைப் படிக்கவும். தயாரிப்பின் Documentation~/UserGuide.en.html நிறுவல், அவதார் பொருத்தம், VRChat கட்டுப்பாடுகள், போஸ் திருத்தம், அளவுரு நினைவகம், புதுப்பித்தல், பிழைத் தீர்வு ஆகியவற்றை விளக்குகிறது. நிலையான போஸ் பெயர்கள் காட்சிக்காக மொழிபெயர்க்கப்படும்; தனிப்பயன் பெயர்கள், அவதார் பெயர்கள், சொத்துக் கோப்புப் பெயர்கள், சேமித்த பொருள் பெயர்கள், அளவுரு அடையாளங்கள் அசல் எழுத்துமுறையிலேயே இருக்கும். முப்பது மொழிகளைத் தேர்ந்தெடுக்கலாம். இணைக்கப்பட்ட Inspector, நிறுவல் உரையாடல்கள், நிலையான போஸ் பெயர்கள், உருவாக்கிய பட்டிகள் ஆகியவற்றின் காட்சித் தரவு ஒவ்வொரு மொழிக்கும் முழுமையாக உள்ளது. தேர்ந்தெடுக்கக்கூடிய ஒவ்வொரு மொழியிலும் இணையமில்லா ஆவணங்கள் வழங்கப்படுகின்றன.

30 மொழி விரைவுக் குறிப்புகள் வசதி விளக்கங்களையும் நிலையான போஸ் பெயர் அட்டவணைகளையும் வழங்குகின்றன. இவை சுருக்கமான குறிப்புகள்; முழு ஆவணங்களுக்கு மொழிக் குறியீட்டைப் பயன்படுத்தவும்.

உரிமமும் ஆதரவும்

தயாரிப்பை வாங்கிய கடையிலிருந்து பதிவிறக்கிய நிறுவியைப் பயன்படுத்தவும். தயாரிப்பு உரிமங்கள் ஏற்கெனவே உள்ள ஒவ்வொரு பயனருக்கான பதிவகம்/கோப்பு சேமிப்பைப் பயன்படுத்தி EditorPrefs-இலிருந்து தனியே இருக்கும். தொகுப்புடன் உள்ள அசல் ஒப்பந்தங்களைப் படிக்கவும். தற்போதைய ஆங்கிலப் பொது அமைப்பு ஒப்பந்தம் குறிப்புக்கான மொழிபெயர்ப்பு; ஒவ்வொரு தயாரிப்பின் ஒப்பந்தமும் தனியே வழங்கப்படுகிறது.
