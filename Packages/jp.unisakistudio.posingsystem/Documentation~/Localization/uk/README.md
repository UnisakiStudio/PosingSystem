# Unisaki Posing System

Спільна система поз для Kawaii Posing Tool, Cool Posing Tool та інших інструментів. За допомогою Modular Avatar і NDMF вона створює потрібні меню й анімації під час завантаження аватара.

Цей README стосується розроблюваної версії v3.2.0. Дату офіційного випуску ще не визначено. Установлена версія відображається вгорі Inspector інструмента поз. Дивіться також [нові функції та історію змін](CHANGELOG.md).

## Мова інтерфейсу й автономна документація

Виберіть мову в полі «Language / 言語» вгорі Inspector. Один вибір керує і Inspector, і створюваним меню VRChat. Щоб змінити мову в грі, завантажте аватар повторно.

Якщо мову не вибрано, використовується мова комп’ютера; для непідтримуваної мови — англійська. Підтримуються Windows, macOS і Linux. Останній вибір зберігається в EditorPrefs і діє в інших проєктах того самого користувача ОС на цьому комп’ютері. Явно збережений в аватарі вибір зберігається. Синхронізації з іншими комп’ютерами немає. Спосіб зберігання ліцензій не змінюється.

README, історію змін і посібник можна вибрати в доданому [списку мов](../index.html). Кнопки посібника й історії змін у Inspector також дотримуються вибраної мови. Оригінальні умови використання та довідкові переклади, як і раніше, надаються окремо.

## Перемикання поз у настільному режимі

Зменшено затримку застосування вибраної пози під час переходу між стоянням, присіданням і сидінням у настільному режимі. Зміна діє у звичайній і попередній збірці без спеціальних команд та додаткових налаштувань. Для VR та особливих станів збережено попередню обробку. Оновіть попередню збірку старої версії перед завантаженням аватара.

## Установлення й оновлення

Додайте інструмент поз через VCC або ALCOM відповідно до придбаних файлів та інструкцій товару. Ця система встановлюється як залежність інструмента поз.

Вимоги версії v3.2.0:

- Проєкт аватара VRChat у Unity 2022.3
- VRChat Avatars SDK 3.10.4 або новіший
- Modular Avatar гілки 1.x, версії 1.15.1 або новішої
- NDMF (Non-Destructive Modular Framework) гілки 1.x, версії 1.14.0 або новішої

Якщо ви користуєтеся Kawaii Posing Tool, оновіть його до 3.2.0 через ALCOM / VCC і переконайтеся, що Unisaki Posing System також має версію 3.2.0. Якщо використовувалася попередня збірка, натисніть «Оновити попередню збірку», збережіть сцену й завантажте аватар.

Cool Posing Tool 1.2.0 використовує спільну систему 3.2.0. Оновлюйте товар і спільну систему разом до сумісних версій.

### Для користувачів старої 8bit-версії

Нові встановлення тепер використовують звичайний Prefab. Вимкніть непотрібні пункти на вкладці «Функції», щоб зменшити витрати. Якщо потрібен лише вибір поз, базові витрати становлять 8 біт.

Старий 8bit-Prefab залишено в «Editor/Legacy» кожного товару, щоб зберегти посилання наявних аватарів і пресетів. Для подальшого використання старої 8bit-версії не потрібно видаляти або замінювати Prefab. Вибір 8bit-версії в меню нового додавання Unity вилучено.

## Вікно налаштувань

Щоб відкрити налаштування, виберіть у Hierarchy об’єкт «可愛いポーズ (Kawaii Posing)», «カッコいいポーズ (Cool Posing)» або інший інструмент усередині аватара.

| Вкладка | Налаштування |
| --- | --- |
| Функції | Пункти ігрового меню, зручні функції, піктограми та витрати ExpressionParameters |
| Пози | Вибір, додавання й порядок поз, попередній перегляд у Scene, подробиці поз та корекція анімацій |
| Налаштування аватара | Корекція пропорцій тіла й колін, імпорт початкових поз і власних рухів, пресети |

Якщо пункт має додаткові налаштування, натисніть «Відкрити налаштування»: поля з’являться під ним. Налаштування дихання також є на вкладці «Функції».

Верхня панель довідки та історії змін відкриває посібник, підтримку й історію змін. Історію можна перемикати між товаром і Unisaki Posing System.

## Функції та витрати ExpressionParameters

Пункти, вибрані в «Функції > Функції меню», з’являються в ігровому меню. Наприклад, «Віддзеркалити» дозволяє перемикати віддзеркалення в грі. Сам вибір цього пункту в Inspector не змушує всі пози постійно бути віддзеркаленими.

| Функція | Додаткові біти |
| --- | ---: |
| Віддзеркалити | 1 біт |
| Без жестів | 1 біт |
| Додати анімацію дихання | 0 біт |
| Дихання (перемикач у грі) | 1 біт |
| Висота ніг | 8 біт |
| Висота підлоги | 8 біт |
| Фоторежим (лише на своєму екрані) | 0 біт |
| Синхронізувати фоторежим | 16 біт |
| Не приховувати голову у фоторежимі | 0 біт |
| Вимкнути похитування VRChat | 0 біт |
| Зменшити спотворення пози від обертання голови | 1 біт (спільний із переворотом) |
| Перевернутися | 10 біт (з них 1 біт спільний зі зменшенням спотворення) |

Переворот використовує 1 біт для ввімкнення, 8 біт для нахилу голови та 1 біт для її фіксації. Якщо зменшення спотворення пози вже ввімкнено, додавання перевороту збільшить витрати на 9 біт. Спільна частина не рахується двічі, а показники оновлюються зі зміною прапорців.

Показаний підсумок стосується лише інструментів поз, установлених у цьому аватарі. Це не загальні витрати аватара з одягом та іншими функціями. Спільні налаштування кількох інструментів також не враховуються повторно. Якщо кількість поз перевищує базовий діапазон номерів, їх вибір потребуватиме додаткових бітів.

### Висота ніг і висота підлоги

- «Висота ніг»: регулює висоту з боку ніг, зберігаючи положення голови. Використовуйте для суміщення ніг із підлогою чи ліжком.
- «Висота підлоги»: переміщує все тіло разом із головою вгору або вниз. 50% — початкова висота, 0% — на 3m нижче, 100% — на 3m вище. Початкове значення — 50%.

Обидва пункти містяться в ігровому меню «Налаштування», де «Висота підлоги» йде після «Висота ніг». Відхилення висоти підлоги від центру переміщує тіло вгору чи вниз; повернення приблизно до 50% відновлює початкову висоту та завершує корекцію. Окремого перемикача ширяння немає. Корекція точки огляду відбувається на початку ширяння й під час зміни висоти підлоги.

Для звичайних анімацій висота ніг тепер регулюється без повторного створення рухів усього тіла для зміни висоти. Це зменшує обсяг створених анімацій, але не означає, що весь аватар завжди зменшується до 1/3.

### Фоторежим

1. Увімкніть «Функції > Функції меню > Фоторежим».
2. Відкрийте Фоторежим у VRChat і виберіть позу через «Вибрати позу».
3. Регулятором «Відстань» перемістіть аватар уперед на відстань до 3m, а «Напрямок» використайте для обертання. Якщо відстань більша за 0, аватар повертається до вас.
4. За потреби ввімкніть фіксацію ніг. На початку вона не примусова, тож можна спочатку налаштувати положення. Якщо до меню додано «Без жестів», на цьому екрані також можна перемикати форму рук.
5. Натисніть «Вийти з фото», щоб скинути відстань і напрямок та звільнити ноги.

Переміщення й обертання у фоторежимі витрачають 0 біт, якщо використовуються лише на своєму екрані. Щоб інші бачили положення й напрямок, увімкніть «Зручні функції > Синхронізувати фоторежим». Відстань і напрямок разом використовують 16 біт.

Якщо голова вашого аватара зникає зблизька, увімкніть «Зручні функції > Не приховувати голову у фоторежимі». Це впливає лише на ваш екран під час знімання. Після виходу відновлюється звичайна видимість.

### Перемикання лежачих поз стрибком

Якщо вибрані пози і на спині, і на животі, між ними можна перемикатися стрибком на місці. Якщо вибрана лише одна, вона зберігається. Щоб не перемикати стрибком, вимкніть «Змінювати лежачі пози стрибком» у Unity, у розділі «Функції → Зручні функції». Додаткові витрати синхронізованих параметрів — 0 біт. Якщо в аватарі кілька інструментів поз, вимкнення в будь-якому з них діє на весь аватар.

### Перевернутися

У підтримуваних лежачих позах тіло плавно перевертається, коли ви нахиляєте голову вліво або вправо. Функція не додає автоматичну підтримку всіх лежачих поз.

1. Увімкніть «Функції > Функції меню > Перевернутися».
2. На вкладці «Пози» відкрийте подробиці потрібної лежачої пози й увімкніть «Увімкнути переворот».
3. Призначте анімацію на боці в полі «Бокова поза перевороту». Перевороти ліворуч і праворуч створюються з початкової та бокової поз. За потреби налаштуйте «Сила корекції контакту з підлогою».
4. Виберіть підтримувану позу у VRChat та ввімкніть «Перевернутися». Фіксацію голови треба вимкнути.

У позах із переворотом нахил голови задає позицію відтворення анімації, тому звичайний MotionTime недоступний. Якщо використовується готова анімація перевороту, призначте її у звичайне поле анімації та залиште «Бокова поза перевороту» порожньою. Підготуйте анімацію, у якій 0 — лівий бік, 0.5 — спина, а 1 — правий бік.

### Дихання та стандартне похитування

«Функції > Зручні функції > Додати анімацію дихання» додає рух у такт диханню, наприклад у ділянці грудей. Через «Відкрити налаштування» для кожної категорії поз можна вибрати «Немає / Слабке / Середнє / Сильне / Швидке / Власне». Швидке — це прискорене дихання. Власне дозволяє призначити підготовлену вами анімацію.

Сам рух дихання витрачає 0 біт. Щоб зупиняти й відновлювати його у VRChat, увімкніть також «Функції меню > Дихання». Синхронізація перемикача використовує 1 біт. Зміна сили не збільшує витрати.

Шия, плечі та руки рухаються разом із грудьми, зменшуючи зміщення голови й кистей. Це не повна фіксація положення, тому вибирайте силу відповідно до статури й пози.

«Зручні функції > Вимкнути похитування VRChat» пригнічує стандартне похитування тіла в очікуванні. Типово вимкнено; власне дихання інструмента й інші користувацькі рухи зберігаються. Функцію можна вибрати й без дихання, витрати бітів не зростають. Похитування з інших причин, не пов’язаних зі стандартною анімацією очікування, ця настройка не усуває.

За наявності кількох інструментів поз вимкнення стандартного похитування в будь-якому з них діє на весь аватар. Щоб повернути його, вимкніть налаштування в усіх інструментах і завантажте аватар повторно.

### Зменшити спотворення пози від обертання голови

Використовуйте, якщо відмінність напрямку голови від початкової пози спотворює тіло після зняття фіксації. Налаштування є в «Функції > Зручні функції» й не додає окремого ігрового меню. Під час фіксації використовується початковий напрямок голови. Положення на спині виключено з корекції, щоб зберегти початковий погляд угору.

### Піктограми меню

- «Створювати піктограми поз»: створює зображення аватара в кожній позі й показує їх у меню. Це допомагає розрізняти пози, але генерація зображень подовжує збірку.
- «Зменшити розмір піктограм»: знижує роздільність зображень і зменшує розмір аватара.

У збірках для Android піктограми поз не створюються. Після зміни одягу чи іншого вигляду використовуйте «Перезняти піктограми». Зображення списку поз оновлюються через «Оновити мініатюри поз». Обробка потребує часу: прочитайте підтвердження перед запуском.

## Додавання, упорядкування й перегляд поз

Виберіть категорію ліворуч на вкладці «Пози». Верхня вкладка з лупою шукає назви в усіх категоріях. У Подробицях можна разом налаштувати анімацію, піктограму, MotionTime та інші параметри.

Кілька анімацій можна додати перетягуванням в область додавання або вибрати в Project і натиснути команду імпорту вибраних кліпів. Повторні посилання на один кліп вилучаються.

Щоб змінити порядок, виберіть кінцеву позицію в «Подробиці > Порядок». Також доступні кнопки вгору й униз. Розгорнутий або згорнутий стан подробиць зберігається після переміщення.

«Перегляд» біля кожної пози показує її в Scene без відкриття вікна корекції. Після завершення відновлюється початковий вигляд. Спрощений перегляд не запускає збірку MA чи NDMF, тому результат може відрізнятися від остаточного одягу, FloorAdjuster та інших операцій збірки. Перевірте одяг і контакт із підлогою також після збірки аватара.

## Корекція анімації та автоматична корекція кінцівок (IK)

Відкрийте «Корекція анімації» на вкладці «Пози», щоб точно налаштувати тіло й кінцівки з переглядом. Після роботи збережіть анімацію корекції через збереження в цьому вікні.

Для підтримуваних товарів і поз автоматична корекція підлаштовує кінцівки під статуру аватара. «Увімкнути автоматичну корекцію кінцівок» у вікні корекції анімації керує всією функцією, а «Увімкнути IK для цієї пози» — окремою позою. Якщо автоматична корекція не передбачена, про це повідомляється.

Щоб доопрацювати автоматичний результат вручну, натисніть «Запекти IK у корекцію». Поточний результат IK записується в нову анімацію корекції, а IK цієї пози для аватара вимикається. Початкова анімація зберігається. Кнопка доступна, коли загальна й індивідуальна автоматична корекція ввімкнені та є застосовні налаштування IK.

У «Налаштування аватара» пункт «Запобігати зворотному згину колін» перемикає корекцію колін. У Подробицях задайте «Мінімальний згин коліна (градуси)». «Увімкнути корекцію аватара» доступне за наявності відповідних даних корекції. Корекції, що перекриваються, не завжди сумісні з автоматичною корекцією кінцівок.

## Початкові пози, власні рухи та пресети

Ці налаштування містяться на вкладці «Налаштування аватара».

- «Використовувати початкові пози стоячи, у присіді та на животі»: автоматично імпортує початково налаштовані пози аватара.
- «Власні рухи»: відкрийте налаштування імпорту й окремо призначте рухи для кожного типу — наприклад стояння, присіду (Crouching) і положення на животі (Prone). Зазвичай одному типу призначається один рух.
- «Поєднувати фіксацію відстеження з іншими інструментами»: увімкніть, якщо фіксація неправильно працює разом з іншими функціями аватара.

Налаштування імпорту власних рухів — окрема функція, відмінна від автоматичного імпорту початкових поз.

Пресети містяться внизу вкладки. Знайдіть за назвою й натисніть «Застосувати цей пресет», щоб замінити налаштування поз. Це здебільшого початкове налаштування під час установлення, яке замінює поточну конфігурацію. Збережіть зроблену корекцію перед перемиканням.

Коли відкривається список пресетів, завантажуються лише назви та відомості про сумісні аватари. Анімації корекції завантажуються під час застосування вибраного пресета. Навіть під час першого створення списку анімації всіх аватарів не завантажуються заздалегідь.

Список поділено на «Сумісний аватар», «Користувацькі пресети» й «Офіційні пресети Unisaki Studio». «Приховати вбудовані пресети» — спільне налаштування вигляду в межах проєкту. Додавання, зміна й видалення пресетів оновлюють список. Якщо вигляд не змінився, натисніть «Оновити».

## Попередня збірка й попередження

Коли «Використовувати початкові пози стоячи, у присіді та на животі» ввімкнено, рухи визначаються з Base аватара під час кожної генерації. Результати не записуються в ручні налаштування імпорту, тому за суто автоматичного імпорту список залишається незаповненим. Зміни рухів Base й перемикання автоматичного імпорту враховуються під час наступної генерації.

Автоматичний імпорт під час завантаження застосовується до копії для збірки. Він не змінює початковий об’єкт сцени, налаштування імпорту, початкові Controller та рухи. Якщо попередня збірка вже є й вхідні дані не змінилися, її результат використовується повторно.

Ручне призначення має пріоритет для свого типу; застосовуються також обертання, анімація корекції та позиція відтворення. Вимкнення «Використовувати» або вилучення призначеного руху зупиняє автоматичний імпорт цього типу. «Очистити ручний вибір» видаляє його налаштування та корекцію: якщо автоматичний імпорт увімкнено, наступна генерація визначить рух знову. Дію можна скасувати через Undo. За кількох старих налаштувань одного типу пріоритет має вибране в Inspector припустиме налаштування.

Налаштування, додані старим автоматичним імпортом, не можна відрізнити від вручну зареєстрованих і скоригованих, тому їх не видаляють автоматично. Використовуйте «Очистити ручний вибір» лише для типів, які хочете повернути до автоматичного імпорту. Якщо в одному аватарі кілька товарів, ручні налаштування інших товарів також впливають на спільні початкові пози.

Попередня збірка скорочує час збірки аватара повторним використанням створених даних. Створити чи оновити її можна через «Оновити попередню збірку». Звичайна збірка аватара теж створює потрібні дані, тому щоразу виконувати попередню збірку вручну не обов’язково.

Після зміни налаштувань потрібне оновлення. Про це повідомляють «Перевірка налаштувань» угорі Inspector і позначка Hierarchy. Після зміни поз або IK оновлення попередньої збірки може пришвидшити наступні збірки.

«Показ попереджень» міститься всередині блоку «Перевірка налаштувань». Можна приховати окремі види попереджень або позначку Hierarchy. Приховування не виправляє налаштування й не оновлює створені дані. Помилки та потрібні операції генерації залишаються.

## Примітки щодо використання

- Розраховано на 3-точкове відстеження й настільний режим. Фіксація поз за повного відстеження тіла не підтримується.
- Статура та модифікації можуть потребувати додаткового налаштування контакту кінцівок і вигляду одягу.
- Особливі Base-шари й інші системи зміни поз можуть працювати не так, як очікується.
- Переміщення й обертання фоторежиму та висота підлоги коригують пози інструмента, а також стандартні й власні рухи без вибраної пози. Перевірте в самому VRChat точку огляду й поведінку замінених стандартних рухів.
