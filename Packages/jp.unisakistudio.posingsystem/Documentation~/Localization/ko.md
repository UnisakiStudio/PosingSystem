# Unisaki Posing System 3.2.0 — 사용 설명서

Unisaki Posing System은 Kawaii Posing·Cool Posing 등의 공통 시스템입니다. VCC 또는 ALCOM에서 구매한 상품과 함께 설치하세요. Unity 2022.3, VRChat Avatars SDK 3.10.4 이상, Modular Avatar 1.15.1 이상, NDMF 1.14.0 이상을 사용합니다.

## 언어

도구 Inspector 최상단의 **Language / 言語**에서 선택합니다. 하나의 선택이 Inspector와 생성 VRChat 메뉴를 제어합니다. 언어를 바꾼 뒤에는 아바타를 다시 업로드하세요. 마지막 선택은 이 컴퓨터의 같은 OS 사용자에 속한 다른 프로젝트에서도 사용합니다. 저장된 선택이 없으면 OS 언어를 따르고, 지원하지 않는 언어이면 영어를 사용합니다. 기존 아바타의 명시적인 선택은 유지합니다. 언어 설정은 다른 컴퓨터에 동기화되지 않습니다.

## 아바타 설정

Hierarchy에서 VRC Avatar Descriptor가 있는 씬의 아바타를 선택하고 **Unisaki Studio > Kawaii Posing 추가** 또는 **Cool Posing 추가**를 선택합니다. 맞는 아바타 프리셋이 제안되면 적용하세요. Inspector에는 **기능**·**포즈**·**아바타 설정** 탭이 있습니다. 원하는 자세와 선택 기능을 정하고 체형에 맞춘 뒤 일반적인 방법으로 업로드합니다. 프리빌드 캐시를 쓴다면 설정 변경 후 **프리빌드 업데이트**를 사용하세요.

## 자세한 설명서

구매한 상품의 Inspector에서 **사용 설명서**를 열면 선택한 언어의 오프라인 안내를 볼 수 있습니다. 상품의 `Documentation~/UserGuide.en.html`에는 설치·체형 조정·VRChat 조작·포즈 편집·파라미터 사용량·업데이트·문제 해결이 담겨 있습니다. 표준 포즈 이름은 표시용으로 번역하며 자체 이름·아바타 이름·에셋 파일명·저장된 오브젝트 이름·파라미터 식별자는 원래 표기를 유지합니다. 30개 언어를 선택할 수 있으며 Inspector·설치 대화 상자·표준 포즈 이름·생성 메뉴의 표시 데이터를 모두 제공합니다. 각 선택 언어의 오프라인 문서도 준비되어 있습니다.

[30개 언어 빠른 참조](../QuickReference/index.html)는 기능 설명과 표준 포즈 이름 대조표를 제공합니다. 간결한 참조 문서이며 전체 문서는 언어 목록에서 열어 주세요.

## 라이선스와 지원

상품을 구매한 스토어에서 받은 설치 프로그램을 사용하세요. 상품 라이선스는 기존 사용자별 레지스트리·파일에 저장하며 EditorPrefs와 별개입니다. 패키지에 동봉된 원본 약관을 읽어 주세요. 기존 공통 시스템의 영어 약관은 참고 번역이며 각 상품의 약관도 별도 제공됩니다.
