# 언어 선택 — v3.2.0

처음 사용할 때 Inspector 위쪽에서 언어를 선택하고 Select / Continue를 누르세요. Unity의 표시 언어와 별도로 선택할 수 있으며, 나중에 같은 위치에서 변경할 수 있습니다.

## VRChat 메뉴 언어

Inspector 위쪽에서 선택한 언어를 도구 화면과 게임 내 메뉴에 함께 사용합니다. 설정은 아바타의 도구에 저장됩니다. VRChat에 반영하려면 아바타를 다시 업로드하세요.

## 자세 이름과 번역

목록에는 번역된 자세 이름이 표시됩니다. 일본어 원래 이름과 번역된 이름으로 검색할 수 있습니다. 원래 자세 이름, 애니메이션 및 내부 매개변수는 유지됩니다. 번역이 없는 사용자 지정 이름은 원문으로 표시됩니다.

## 번역 진행 중

v3.2.0 개발 버전에는 번역을 순차적으로 추가하고 있습니다. 번역이 없는 항목은 일본어로, 사용자 지정 이름은 원문으로 표시됩니다. 언어마다 번역 범위가 다릅니다.
