# 选择语言 — v3.2.0

首次使用时，请在Inspector顶部选择语言，然后点击“选择 / Continue”。此设置独立于Unity的界面语言，也可以稍后在同一位置修改。

## VRChat菜单语言

在功能选项卡中选择游戏内菜单的语言，然后上传角色。此设置与工具界面语言相互独立。若要更改已上传角色的菜单语言，需要重新上传。

## 姿势名称与翻译

列表显示翻译后的姿势名。可以使用日文原名或翻译后的名称进行搜索。原始姿势名、动画和内部参数保持不变。没有翻译的自定义名称会按原样显示。

## 翻译进行中

v3.2.0开发版正在逐步添加翻译。未翻译的内容显示日文，自定义名称则显示原文。各语言的翻译覆盖范围不同。
