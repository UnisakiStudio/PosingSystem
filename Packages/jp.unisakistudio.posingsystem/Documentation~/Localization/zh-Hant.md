# 選擇語言 — v3.2.0

預設使用電腦的語言，與Unity的介面語言無關；不支援的語言使用英語。可透過Inspector頂部的「Language / 言語」修改。同一電腦使用者的其他Unity專案也會沿用此選擇。安裝確認視窗中也提供「Language...」按鈕。

## VRChat選單語言

在Inspector頂部選擇的語言同時用於工具介面和遊戲內選單。設定儲存在角色上的工具中。變更後需要重新上傳角色，才會在VRChat中生效。

## 姿勢名稱與翻譯

清單顯示翻譯後的姿勢名稱。可以使用日文原名或翻譯後的名稱搜尋。原始姿勢名稱、動畫和內部參數保持不變。沒有翻譯的自訂名稱會按原樣顯示。

## 支援的語言

v3.2.0為30種語言提供標準顯示文字及全部128個內建姿勢名稱。Inspector、安裝對話方塊和產生的遊戲內選單使用同一語言。自訂名稱保持原樣。完整離線手冊提供英文版。
