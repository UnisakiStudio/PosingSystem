# Unisaki Posing System 3.2.0 — 繁體中文指南

Unisaki Posing System是Kawaii Posing、Cool Posing及相關工具的共用核心。
請通過VCC或ALCOM將購買的商品與此核心一同安裝。使用Unity 2022.3、
VRChat Avatars SDK 3.10.4+、Modular Avatar 1.15.1+及NDMF 1.14.0+。

## 語言

在工具Inspector頂部選擇**Language / 言語**。同一項選擇同時控制Inspector和產生的VRChat選單。
更改語言後請重新上傳虛擬化身。最後的選擇會用於此電腦上同一OS使用者的其他專案。
沒有已儲存的選擇時，工具使用OS語言，不支援時回退為英語。
所有姿勢工具和虛擬化身都使用同一種語言。在任意工具的Inspector中變更語言，都會更新共用設定；不採用個別虛擬化身的語言選擇。語言偏好不會同步到其他電腦。 僅在尚未儲存語言時的首次安裝確認中顯示語言按鈕。之後請在Inspector中變更語言。

## 設定虛擬化身

在Hierarchy中選取場景內帶有VRC Avatar Descriptor的虛擬化身，再選擇
**Unisaki Studio > 加入Kawaii Posing**或**加入Cool Posing**。如提示存在適用的虛擬化身預設，請套用。
工具Inspector包含**功能**、**姿勢**和**虛擬化身設定**頁籤。
選擇所需姿勢與可選控制項、調整適配後，按一般流程上傳。
如果使用快取的預先建置資料，更改設定後請執行**更新預先建置**。

## 詳細手冊

在所購商品的Inspector中開啟**使用說明**，即可查看所選語言的離線指南。
商品的`Documentation~/UserGuide.en.html`包含安裝、虛擬化身適配、VRChat操作、
姿勢編輯、參數記憶體、更新與疑難排解說明。
標準姿勢名會翻譯後顯示；自訂名稱、虛擬化身名稱、資源檔案名、
儲存的物件名和參數識別碼均保留原始拼寫。
可選擇30種語言。隨附的Inspector、安裝對話框、標準姿勢名和產生選單
已為每種選擇提供完整顯示目錄。所有可選語言均有離線文件。

[30種語言的快速參考](../QuickReference/index.html)涵蓋功能說明和標準姿勢名表。這是簡明參考；完整文件請從語言清單進入。

## 授權與支援

請使用購買商品的商店提供的安裝程式。商品授權保留現有的按使用者登錄或檔案儲存方式，
與EditorPrefs分開。請閱讀套件隨附的原始協議。
現有共用系統英文協議為參考譯文；各商品的協議也單獨提供。
