# 選擇語言 — v3.2.0

首次使用時，請在Inspector頂部選擇語言，然後點擊「選擇 / Continue」。此設定獨立於Unity的介面語言，也可以稍後在同一位置修改。

## VRChat選單語言

在功能分頁中選擇遊戲內選單的語言，然後上傳角色。此設定與工具介面語言相互獨立。若要變更已上傳角色的選單語言，需要重新上傳。

## 姿勢名稱與翻譯

清單顯示翻譯後的姿勢名稱。可以使用日文原名或翻譯後的名稱搜尋。原始姿勢名稱、動畫和內部參數保持不變。沒有翻譯的自訂名稱會按原樣顯示。

## 翻譯進行中

v3.2.0開發版正在逐步加入翻譯。未翻譯的內容顯示日文，自訂名稱則顯示原文。各語言的翻譯涵蓋範圍不同。
