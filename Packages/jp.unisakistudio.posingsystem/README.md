# ゆにさきポーズシステム
Version 3.0.14

# 概要
このPackageは「可愛いポーズツール」を始めとしたゆにさきスタジオで販売しているVRChat向けポーズツールのベースとなるシステムです。
メニューはModularAvatarを使用して生成しています。
NDMFを使用した非破壊ギミックになっています。

# プリセットの選択と再読込
「アバター固有」タブのプリセット一覧は、名前で検索できるスクロール式のリストです。先頭の「アバターに適合」に現在のアバター向けのおすすめプリセットを表示し、「ユーザー作成」「ゆにさきスタジオ公式」にも元の一覧を表示します。各グループは折りたためます。適合判定はツール導入時と共通で、元のPrefab（Variantの継承元を含む）の一致を優先し、該当がなければアバター名で探します。 一覧の上にある「同梱プリセットを表示しない」をオンにすると、公式プリセットを一覧・検索結果から非表示にします。この設定は共有ファイルに保存され、同じプロジェクトの各アバターで共通です。

一覧の読込情報は `Assets/UnisakiStudio/Editor/PosingSystemPresetCatalog.asset` に保存し、同じプロジェクトの各アバターから参照します。初回とゆにさきスタジオのツールのバージョン変更時に自動更新し、それ以外は保存済みの一覧を使用します。プリセットの追加・編集・削除後は、一覧の「再読込」を押してください。自作プリセットの保存後も再読込が必要です。

`Packages/jp.unisakistudio.*/Resources/Presets/` 以下を公式プリセットとして扱い、それ以外の場所はユーザー作成として表示します。共有ファイルは一覧の情報だけを保存しており、プリセット本体やポーズの設定を複製するものではありません。
