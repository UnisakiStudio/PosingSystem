# ゆにさきポーズシステム
Version 3.0.18

# 概要
このPackageは「可愛いポーズツール」を始めとしたゆにさきスタジオで販売しているVRChat向けポーズツールのベースとなるシステムです。
メニューはModularAvatarを使用して生成しています。
NDMFを使用した非破壊ギミックになっています。

# 3.0.18の主な変更

- 姿勢アニメーション名の入力中にサムネイルを繰り返し生成して重くなる問題を修正しました。名前はEnterまたは別の欄への移動で確定し、名前だけの変更では画像を撮り直しません。
- 編集中の仮アイコンがアップロード後のメニューに使われる問題を修正しました。ビルド時に処理後のアバターで生成し直します。設定したカスタムアイコンは維持します。
- しゃがみ・伏せのモーション置き換えで、単発のAnimationClipも自動取り込み・手動指定で使えるよう修正しました。

過去の変更は[CHANGELOG](CHANGELOG.md)をご覧ください。

# 更新方法
VCCで「ゆにさきポーズシステム」を3.0.18へ更新してください。Unityのコンパイル完了後、設定とプレビューを確認し、アバターを再アップロードするとVRChat側へ反映されます。

修正前のプレビルド済みデータは、次回ビルド時に再生成されます。更新後の状態を事前に確認する場合は「プレビルド実行」を押してください。

今回の修正は共通システムの更新で適用されます。対応する依存バージョン範囲で利用している各ポーズツールを、同時に版上げする必要はありません。

# アバターのモーション取り込み
「アバターの姿勢設定をビルド時に自動でインポート」を有効にするか、モーションの設定から「アバターから自動インポート」を実行すると、アバターの固有モーションを取り込めます。

同じ種類の有効なBlendTreeを優先し、しゃがみ・伏せはBlendTreeが見つからない場合に単発のAnimationClipを取り込みます。すでに設定されているモーションは維持します。歩行・走行に単発のAnimationClipを取り込む対応は含みません。

# つま先が不自然に曲がる場合
ハンカなどつま先などに特殊なPhysboneが入っているアバターなどは、つま先が不自然に曲がってしまうケースがあるため、ポーズツール使用時はPhysboneを無効にすることをお勧めします。

無効にする対象は、つま先など症状に関係するPhysBoneです。ツールが自動で無効化する機能はありません。物理動作を残したい場合は、ポーズの高さや接地位置を調整してください。
