# ゆにさきポーズシステム

「可愛いポーズツール」「カッコいいポーズツール」などで使う共通のポーズシステムです。Modular AvatarとNDMFを使用し、アバターのアップロード時に必要なメニューやアニメーションを生成します。

このREADMEは開発中のv3.2.0向けです。正式リリース日は未定です。導入済みのバージョンは、ポーズツールのInspector上部で確認できます。[追加機能・変更履歴](CHANGELOG.md)もご覧ください。

## 表示言語とオフライン文書

Inspector最上部の「Language / 言語」で表示言語を選びます。一つの選択がInspectorと生成するVRChatメニューの両方に適用されます。ゲーム内の表示を変更するにはアバターを再アップロードしてください。

未選択の場合はパソコンの言語を使い、対応していない言語では英語を使います。Windows・macOS・Linuxに対応します。最後に選んだ言語はEditorPrefsに保存し、このパソコンの同じOSユーザーの別プロジェクトでも使用します。アバターに保存済みの明示的な選択は維持します。他のパソコンには同期しません。ライセンスの保存方法は変更しません。

README・変更履歴・使い方は同梱の[言語一覧](Documentation~/Localization/index.html)から選べます。Inspectorの「使い方」と「変更履歴」も選択言語に従います。元の利用規約と参照翻訳は従来どおり別に用意しています。


## デスクトップモードの姿勢切り替え

デスクトップモードで立ち・中腰・座りを切り替えたとき、指定ポーズが反映されるまでの遅延を短縮しました。通常のビルドとプレビルドで有効になり、専用コマンドや追加設定は不要です。VRモードや特殊な状態では従来の処理を維持します。旧版のプレビルドは更新してからアップロードしてください。

## 導入とバージョンアップ

各商品の購入ファイルと導入手順に従い、VCCまたはALCOMからポーズツールを追加してください。このシステムはポーズツールの依存パッケージとして導入されます。

v3.2.0の必要環境は次のとおりです。

- Unity 2022.3のVRChatアバタープロジェクト
- VRChat Avatars SDK 3.10.4以上
- Modular Avatar 1.15.1以上の1.x系
- NDMF（Non-Destructive Modular Framework）1.14.0以上の1.x系

可愛いポーズツールをお使いの方は、ALCOM / VCCで可愛いポーズツールを3.2.0に更新し、ゆにさきポーズシステムも3.2.0になったことを確認してください。プレビルドを使っていた場合は「プレビルドを更新」を押し、シーンを保存してからアバターをアップロードします。

カッコいいポーズツール1.2.0は共通3.2.0を使用します。商品と共通システムを対応する版へ併せて更新してください。

### 8bit版を使っていた方へ

新規追加は通常のPrefabに統一しました。「機能」で不要な項目をオフにすると、使用量を抑えられます。姿勢選択だけなら基本の使用量は8 bitです。

旧8bit版Prefabは、配置済みのアバターやプリセットの参照を保つため、各商品の「Editor/Legacy」に残しています。既存の8bit版を使うために、Prefabを削除したり置き換えたりする必要はありません。Unityの新規追加メニューから8bit版を選ぶ手順は廃止しています。

## 設定画面の見方

Hierarchyでアバター内の「可愛いポーズ」「カッコいいポーズ」などを選ぶと設定できます。

| タブ | 設定する内容 |
| --- | --- |
| 機能 | ゲーム内メニューに追加する項目、便利機能、アイコン画像、ExpressionParametersの使用量 |
| ポーズ一覧 | ポーズの選択・追加・順番変更、Sceneでのプレビュー、ポーズごとの詳細、アニメーション調整 |
| アバター調整 | 体格に合わせた補正、膝の補正、元の姿勢や自作モーションの取り込み、プリセット |

詳しい設定がある項目は「設定を開く」を押すと、その下に設定欄が開きます。呼吸の設定も「機能」にあります。

上部の「ヘルプ・変更履歴」から、使い方・お問い合わせ・変更履歴を開けます。変更履歴は商品とゆにさきポーズシステムを切り替えて読めます。

## 機能とExpressionParametersの使用量

「機能」の「メニュー追加」で選んだ項目がゲーム内メニューに表示されます。たとえば「左右反転」を選ぶと、ゲーム内で反転を切り替えられるようになります。Inspectorで選んだだけで、常に全ポーズが反転する設定ではありません。

| 機能 | 追加で使うbit数 |
| --- | ---: |
| 左右反転 | 1 bit |
| ジェスチャー無効 | 1 bit |
| 呼吸の動きをつける | 0 bit |
| 呼吸（ゲーム内でのON/OFF） | 1 bit |
| 足の高さ | 8 bit |
| 床の高さ | 8 bit |
| 撮影モード（自分の画面だけ） | 0 bit |
| 撮影モードを同期する | 16 bit |
| 撮影モード中は頭を非表示にしない | 0 bit |
| VRChat標準の揺れを止める | 0 bit |
| 首の向きの違いによる姿勢崩れを抑制 | 1 bit（寝返りと共用） |
| 寝返り | 10 bit（うち1 bitを姿勢崩れ抑制と共用） |

寝返りの内訳は、ON/OFFに1 bit、頭の傾きに8 bit、首固定に1 bitです。姿勢崩れ抑制をすでに有効にしている場合、寝返りを追加したときに増える量は9 bitになります。共用分は重複して数えず、チェックを変えると表示も更新されます。

表示する合計は、そのアバターに導入したポーズツールの分です。衣装やほかのギミックを含むアバター全体の合計ではありません。複数のポーズツールを併用したときも共通の設定は重複して数えません。姿勢数が基本の番号範囲を超える構成では、姿勢選択にも追加のbitが必要になります。

### 足の高さと床の高さ

- 「足の高さ」：頭の位置を保ちながら、足側の高さを調整します。足を床やベッドに合わせたいときに使います。
- 「床の高さ」：頭を含む身体全体を上下へ移動します。50%が元の高さ、0%が3m下、100%が3m上です。初期値は50%です。

どちらもゲーム内の「設定」にあり、「床の高さ」は「足の高さ」の次に並びます。「床の高さ」を中央から動かすと上下へ移動し、50%付近へ戻すと元の高さへ戻って補正を終了します。別の浮遊ON/OFFスイッチはありません。視点の補正は浮遊開始時と床の高さの操作中に行います。

足の高さは、通常のアニメーションでは高さ調整のために全身の動きを重複して生成しない方式に変更しました。生成するアニメーションのデータ量を抑えられますが、アバター全体の容量が一律で3分の1になるわけではありません。

### 撮影モード

1. 「機能 > メニュー追加 > 撮影モード」をオンにします。
2. VRChatで「撮影モード」を開き、「姿勢選択」でポーズを選びます。
3. 「距離」で前方へ最大3mまで移動し、「向き」で回転させます。距離を0より大きくすると、アバターはこちらを向きます。
4. 必要に応じて「足固定」をオンにします。開始時には足固定を強制しないため、固定前に位置を調整できます。「ジェスチャー無効」をメニューに追加している場合は、同じ画面で手の形も切り替えられます。
5. 「撮影モードを終了」で距離と向きを戻し、足固定を解除します。

撮影モードの移動・回転は、自分の画面だけで使う場合は0 bitです。他の人にも位置と向きを見せたい場合は「便利機能 > 撮影モードを同期する」をオンにします。距離と向きに合計16 bitを使用します。

近くにいる自分のアバターの頭が見えなくなる場合は、「便利機能 > 撮影モード中は頭を非表示にしない」をオンにしてください。撮影中の自分の画面だけに適用し、終了すると通常の表示へ戻ります。

### ジャンプで寝姿勢を切り替える

仰向けとうつ伏せの両方を選ぶと、その場でジャンプして切り替えられます。片方だけを選んだ場合はその姿勢を保ちます。ジャンプで切り替えたくない場合は、Unityの「機能 → 便利機能」で「ジャンプで寝姿勢を切り替える」をオフにしてください。同期パラメーターの追加消費は0 bitです。複数のポーズツールを使うアバターでは、いずれかでオフにするとアバター全体に適用されます。

### 寝返り

対応する寝姿勢で、頭を左右に傾けると身体も滑らかに寝返りします。すべての寝姿勢が自動で対応する機能ではありません。

1. 「機能 > メニュー追加 > 寝返り」をオンにします。
2. 「ポーズ一覧」で使いたい寝姿勢の「詳細」を開き、「寝返りを使う」をオンにします。
3. 「寝返り時の横向き」に横向きのアニメーションを設定します。元の姿勢と横向きの姿勢から、左右への寝返りを作成します。必要に応じて「接地補正の強さ」を調整してください。
4. VRChatで対応する姿勢を選び、「寝返り」をオンにします。首固定は解除して使用してください。

寝返りを使うポーズでは、頭の傾きでアニメーションの再生位置を決めるため、通常のMotionTime設定は使えなくなります。完成済みの寝返りアニメーションを使う場合は、通常のアニメーション欄へ指定して「寝返り時の横向き」を空にします。再生位置0が左、0.5が仰向け、1が右になるアニメーションを用意してください。

### 呼吸と標準の揺れ

「機能 > 便利機能 > 呼吸の動きをつける」で、胸などが呼吸に合わせて動くようになります。「設定を開く」から、姿勢の分類ごとに「なし・弱・中・強・急・カスタム」を選べます。「急」は動きの速い呼吸です。「カスタム」では自分で用意した呼吸アニメーションを指定できます。

呼吸の動きだけなら0 bitです。VRChatで呼吸を止めたり再開したりする場合は、「メニュー追加 > 呼吸」もオンにしてください。ON/OFFの同期に1 bitを使用します。強さを変えてもbit数は増えません。

胸に合わせて首・肩・腕なども動かし、頭や手の移動を抑えています。完全な位置固定ではないため、体型やポーズに合わせて強さを選んでください。

「便利機能 > VRChat標準の揺れを止める」は、VRChatが標準で付ける待機中の身体の揺れを抑える設定です。初期値はオフで、ポーズツール独自の呼吸やほかのカスタム動作を維持します。呼吸の動きを使わない場合も選択でき、bit数は増えません。標準の待機動作以外が原因の揺れは、この設定では止まりません。

複数のポーズツールを併用している場合、いずれかで標準の揺れを止めるとアバター全体に適用されます。元に戻す場合は、すべてのツールでこの設定をオフにして再アップロードしてください。

### 首の向きの違いによる姿勢崩れを抑制

元のポーズと首の向きが違うことで、首固定を解除したときに姿勢が崩れる場合に使います。「機能 > 便利機能」にあり、ゲーム内に専用メニューは追加されません。首固定中は元のポーズの向きを使います。仰向け寝は元の上向きを保つため、補正対象から除いています。

### メニューのアイコン画像

- 「ポーズアイコン生成」：アバターが各ポーズを取った画像を生成し、メニューに表示します。ポーズを見分けやすくなりますが、画像生成の分だけビルドに時間がかかります。
- 「アイコン画像の容量を減らす」：画像の解像度を下げ、アバターの容量を抑えます。

Android向けのビルドではポーズアイコンを生成しません。衣装などを変更した後は「アイコンを撮り直す」を使用してください。ポーズ一覧用の画像は「ポーズ画像を更新」で更新します。時間のかかる処理なので、確認ダイアログを読んでから実行してください。

## ポーズの追加・並べ替え・プレビュー

「ポーズ一覧」の左側で姿勢の分類を選びます。一番上の虫眼鏡のタブでは、分類をまたいでポーズ名を検索できます。「詳細」を開くとアニメーション、アイコン、MotionTimeなどをまとめて設定できます。

複数のアニメーションは、追加欄へドラッグ＆ドロップするか、Projectで選択して「Projectで選択中のクリップを読み込む」を押してまとめて追加できます。同じクリップの重複は除かれます。

順番を変えるには「詳細」の「順番」で移動先を選びます。上下の移動ボタンも使用でき、移動しても詳細の開閉状態を保持します。

各ポーズの「プレビュー」を押すと、調整ウィンドウを開かずSceneで姿勢を確認できます。プレビューを終了すると元の表示に戻ります。この簡易プレビューはMAやNDMFのビルド処理を実行しないため、ビルド時に組み込まれる衣装やFloorAdjusterなどの最終結果とは異なることがあります。最終的な衣装・接地はアバタービルド後にも確認してください。

## アニメーション調整と手足の自動調整（IK）

「ポーズ一覧」の「アニメーション調整」を開くと、プレビューしながら身体や手足を細かく調整できます。調整後はウィンドウの保存操作で調整アニメーションを保存してください。

手足の自動調整に対応する商品・ポーズでは、アバターの体格に合わせて手足の位置を調整します。アニメーション調整画面の「手足の自動調整を使う」で全体を切り替え、「このポーズのIKを使う」で個別に切り替えられます。自動調整が用意されていないポーズには、その旨を表示します。

自動調整をもとに手作業で仕上げたい場合は、「IKを調整に反映」を押します。その時点のIKの結果を新しい調整アニメーションへ書き込み、そのアバターの対象ポーズのIKをオフにします。元のアニメーションは保持します。このボタンは、全体と対象ポーズの自動調整が有効で、適用できるIK設定がある場合に使用できます。

「アバター調整」の「膝が逆向きに曲がるのを防ぐ」では、膝の補正を切り替えられます。詳細の「最低膝曲げ角度（°）」で曲げ角度を設定します。「アバター固有補正を使う」は対応する補正データがある場合に使用できます。手足の自動調整と重なる補正は併用できない場合があります。

## 元の姿勢・自作モーション・プリセット

これらは「アバター調整」で設定します。

- 「アバターの元の立ち・しゃがみ・伏せ姿勢を使う」：アバターに元から設定されていた姿勢を自動で取り込みます。
- 「自分で用意したモーションを使う」：取り込み設定を開いて、立ち・しゃがみ（Crouching）・伏せ（Prone）など、種類ごとに使うモーションを個別に指定します。原則として一つの種類に一つのモーションを設定します。
- 「各固定機能の他ギミックとの統合」：ほかのギミックとの併用で固定機能がうまく動かない場合にオンにします。

自分でモーションを指定する取り込み設定は、元の姿勢を自動で取り込む設定とは別の機能です。

プリセットはタブの一番下にあります。名前で検索し、「このプリセットに変更する」でポーズの設定を切り替えます。主に導入時の初期設定に使うもので、現在の設定を置き換えるため、調整済みの内容がある場合は保存してから切り替えてください。

プリセット一覧を表示するときは名前や対応アバターの情報だけを読み込み、調整アニメーションは選んだプリセットを適用するときに読み込みます。初回の一覧作成でも、全アバター分のアニメーションを先読みしません。

一覧は「アバターに適合」「ユーザー作成」「ゆにさきスタジオ公式」に分かれています。「同梱プリセットを表示しない」は同じプロジェクトで共通の表示設定です。プリセットを追加・編集・削除すると一覧が更新されます。表示が変わらない場合は「再読込」を押してください。

## プレビルドと警告

「アバターの元の立ち・しゃがみ・伏せ姿勢を使う」がONの場合、生成するたびにアバターのBaseからモーションを検出します。検出結果を手動の取り込み設定へ書き戻さないため、自動取り込みだけなら一覧は未指定のままです。Baseのモーション変更や自動取り込みのON/OFFは次の生成へ反映されます。

アップロード時の自動取り込みはビルド用コピーに反映します。シーン上の元オブジェクト、取り込み設定、取り込み元のControllerやモーションを書き換えません。プレビルド済みで入力に変更がなければ、その結果を再利用します。

手動指定がある種類は手動設定を優先し、回転・調整アニメーション・再生位置指定も反映します。「使用」をOFFにした設定や、指定済みモーションを外した設定は、その種類の自動取り込みを止めます。「手動指定を解除」でその種類の設定と調整を外すと、自動取り込みがONなら次の生成で再検出します。この操作はUndoで戻せます。同じ種類に旧設定が複数ある場合は、Inspectorで選ばれた有効な設定を優先します。

旧版の自動取り込みで一覧に追加された設定は、手動登録・調整済みの設定と区別できないため、自動削除しません。自動取り込みへ戻したい種類だけ「手動指定を解除」を使ってください。複数製品を同じアバターへ導入している場合は、他の製品にある手動設定も共通の元姿勢に反映されます。

プレビルドは、生成したデータを再利用してアバターのビルド時間を短くする機能です。「プレビルドを更新」で作成・更新できます。通常のアバタービルドでも必要なデータは生成されるため、毎回手動でプレビルドする必要はありません。

設定を変えると更新が必要な状態になり、Inspector上部の「設定の確認」やHierarchyのマークでお知らせします。ポーズやIK設定を変更した後は、プレビルドを更新すると次回以降のビルド時間を抑えられます。

「警告の表示設定」は「設定の確認」の枠内にあります。警告の種類ごと、またはHierarchyのマークを非表示にできます。非表示にしても設定の問題が解消されたり、生成データが更新されたりするわけではありません。エラーや必要な生成処理はそのままです。

## 使用上の注意

- 3点トラッキングとデスクトップでの使用を想定しています。フルボディトラッキング中の姿勢固定には対応していません。
- 体格や改変内容によって、手足の接地や衣装の見え方に追加調整が必要になることがあります。
- 特殊なBaseレイヤーやほかの姿勢変更ギミックとの組み合わせでは、意図どおりにならない場合があります。
- 撮影モードの移動・回転と床の高さは、ツールポーズと未選択時の標準・独自モーションを補正対象にします。VRChat内で置換される標準モーションや視点の挙動は、実機で確認してください。
