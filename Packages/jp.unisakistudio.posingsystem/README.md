# ゆにさきポーズシステム
Version 3.1.0（実機検証中）

## 3.1の機能設定
Inspectorの「機能」タブで機能を選び、ExpressionParametersの使用量を確認できます。変更時にMA Parametersとメニューを更新し、使用する容量を表示します。最小構成は姿勢のみ8 bitです（姿勢番号が8 bitに収まらない場合は追加bitが必要です）。複数商品を併用する場合、共通パラメータは重複計上しません。

| 機能 | 追加の同期容量 |
| --- | ---: |
| 左右反転 | 1 bit |
| 足の高さ調整 | 8 bit |
| 呼吸の動き / 呼吸ON/OFF機能 | 動きのみ0 bit / ON/OFFの同期1 bit |
| VRChat標準の揺れを無効化（Unity側の設定） | 0 bit |
| 指ジェスチャーの無効化 | 1 bit |
| 顔の正面補正 | 首固定用1 bit |
| 撮影モード | 自分の画面のみ0 bit / 同期は距離8 + 向き8 = 16 bit |
| 床の高さ | 高さ8 bit（有効化は高さから自動判定、同期なし） |
| 頭の傾きによる寝返り（試験機能） | 有効化1 + 傾き8 + 首固定1 bit |

顔補正と寝返りの首固定パラメータは共用します。顔補正・撮影・浮遊・寝返りは既定オフです。従来の8bit専用Prefabは新規配置用から廃止し、既存の参照を維持するために各商品の `Editor/Legacy` に保存しています。既存の8bit版は機能がオフの構成へ移行します。

顔補正はアバターと姿勢ごとに首・頭のMuscleカーブを生成します。元の姿勢の再生状態・MotionTimeに同期し、首固定時は元の向きに戻します。仰向け（既存の自動頭固定と同じLocomotionType 32）は補正対象外とし、元の上向きの頭を保ちます。首の可動範囲を超えた補正は行いません。

「撮影モード」には「姿勢選択」「距離」「向き」「足固定」「ジェスチャー無効」「撮影モードを終了」を表示します（ジェスチャー無効はInspectorで有効にした場合）。姿勢選択・固定・ジェスチャーは元のメニューと設定を共有します。前へ移動すると180度こちらを向き、向きRadialの中央がこちら向きになります。距離0では元の正面を基準に回転します。開始時は首・腕の固定要求だけを加え、足・腰の固定やLocomotion Lockを強制しません。「撮影モードを終了」で距離・向きを元に戻し、足固定と撮影用の固定要求を解除します。既存の首・腕固定の選択は保持します。

「設定」に「床の高さ」を直接表示します。高さが0より大きいと浮遊を開始し、0へ戻すと終了します。浮遊の有効化トグル・専用サブメニューはありません。同期するのは高さのFloat（8 bit）のみで、`USSPS_Float` は各クライアントが高さから計算する同期なし・保存なしのBoolです。高さの操作中を判定するローカルパラメータも保存・同期しません。浮遊自体はTracking Controlを変更しません。視点の補正は浮遊開始時と「床の高さ」の操作中だけ行います。

寝返りは自己ContactとVRC Position/Rotation Constraintで頭の向きを測り、`USSPS_RollTime` を0（左）〜0.5（仰向け）〜1（右）へ変換します。Inspectorに寝返りAnimationを指定すると、寝姿勢・首固定オフ・ゲーム内の寝返りトグルオンの間だけMotionTimeで再生します。Animation未指定でも検出とパラメータ生成は行います。Box ContactのためVRChat SDK 3.10.4以上が必要です。

## 呼吸の動き
「機能 → 便利機能 → 呼吸の動きをつける → 設定を開く」で、姿勢ごとに「なし・弱・中・強・急・カスタム」を選べます。「弱・中・強」は5秒周期で動きの大きさを変更し、「中」は「弱」と「強」の中間の大きさです。「急」は「中」より大きく、1.8秒周期の速い呼吸になります。初期値は「中」です。「メニュー追加」の「呼吸」を有効にすると、ゲーム内の「呼吸」でまとめてオン／オフできます。「急」を選んでもExpressionParametersの使用量は増えません。

胸の反りに合わせて背中と首を逆方向へ曲げ、頭の位置と傾きの変化を抑えています。肩を開閉する動きを腕で補い、手の移動を抑えながら、脚もごく小さく動かします。汎用の加算アニメーションなので、頭・手足の完全固定ではありません。アバターの体型や元の姿勢、VRChatのトラッキングによって見え方は変わります。「カスタム」で指定したアニメーションは変更しません。

## VRChat標準の揺れを無効化
「機能 → 便利機能 → VRChat標準の揺れを止める」で切り替えます。初期値はオフです。ポーズツールの呼吸機能・各姿勢の呼吸の強さとは独立しており、呼吸を使わない構成や旧8bit版でも利用できます。ExpressionParametersの使用量は増えません。設定後は再プレビルドしてアップロードしてください。

MAの統合後、ビルド用Additive ControllerのSDK標準 `proxy_idle` 参照だけを空のアニメーションへ置き換えます。判定はSDKアセットのGUID／参照で行い、同じ名前のユーザー製アニメーションは対象にしません。Additive全体のWeightや、他のPlayable Layerは変更しません。独自の呼吸、カスタムControllerの他の動作、MAで追加された動作を保持します。元のController・SDKアセット・シーンのDescriptorは編集しません。

複数のポーズツールを併用する場合は、どれか一つでオンにするとアバター全体へ適用します。従来の標準Idleに戻す場合は、すべてのツールでオフにして再ビルドしてください。プレビルドには設定を保存し、標準Idleの置き換え自体は通常ビルドと同じNDMF処理で適用します。

VRChatで見えるすべての揺れが標準Idle由来とは限りません。DesktopおよびTracking ControlがAnimationの状態での揺れの変化は実機確認対象です。標準Additiveの役割は[VRChat公式Playable Layersドキュメント](https://creators.vrchat.com/avatars/playable-layers/#additive)を参照してください。

## 足の高さ・撮影モード・床の高さの適用方式
実機比較を終え、次の構成に固定しています。Inspectorの実機比較欄はありません。比較中に保存した設定も、同期・プレビルド・ビルド時にこの構成へ移行します。既存のプレビルドは再生成が必要です。各機能のオン／オフや同期の選択は維持します。

| 対象 | 採用する方式 |
| --- | --- |
| 足の高さ | BaseのAnimatorController内のAdditiveレイヤーで高さ補正 |
| 撮影モード・床の高さ | 比較時のE方式：Base内のAdditiveで姿勢に合わせて移動・回転の軸を補正 |
| 床の高さの視点補正 | 開始時・高さの操作中だけTemporary Pose SpaceのEnterを実行 |

### 足の高さとアニメーション容量
通常のAnimationClipを使うポーズは、全身ポーズの高さ別3複製を、元のポーズ1つと上下の高さ差分だけを持つ小さなHumanoidクリップへ置き換えます。寝姿勢でも上下へ動くようRootQの逆回転で補正し、動く姿勢では方向を時間に沿って記録します。高さの強弱を調整するBlendTreeは引き続き使用します。

全身のMuscleカーブの重複が減るため、アニメーション容量を削減できます。補正用クリップは残るので、クリップ個数やアバター全体の容量が3分の1になるという意味ではありません。削減量は元のポーズやアバターの構成によって変わります。複数の姿勢を混ぜるBlendTreeモーションは、混合後の回転と補正方向が一致する保証がないため、従来の高さ別複製を維持します。VRChat標準proxyモーションへの高さ補正も従来どおり省きます。ExpressionParametersは既存のFootHeight（8 bit）のままです。

同じアバターで有効な足の高さ機能が1つでもあれば、共通Controller全体へ適用します。加算レイヤーは元のLocomotionへ同期し、状態遷移・Motion Timeを引き継ぎます。DescriptorのAdditive枠は使いません。

### 撮影モード・床の高さ
元のLocomotionはOverrideのまま維持します。RootQをq、アバター基準の移動量をd、縦軸回転をrとすると、加算クリップにinverse(q) * dとinverse(q) * r * qを記録します。上下・前進を先に、回転を最後に加えます。各レイヤーはLocomotionへ同期し、左右反転時も回転操作の向きを保ちます。Write Defaultsは同期元の姿勢Stateを引き継ぎます。生成クリップには移動0・回転なしの加算基準を明示します。

通常のproxy歩行と、複数の姿勢を混ぜるBlendTreeモーションには撮影用の移動・回転や浮遊の移動を加えません。混合した逆回転が、混合後の姿勢の逆回転とは一致しないためです。

### 床の高さの視点補正
床の高さが0より大きくなると浮遊を開始し、80ms後に1回Enterします。以後は「床の高さ」のRadialを開いていて高さが変わった時だけ、固定時間を待たずEnterします。姿勢変更、足の高さ変更、頭の動きでは視点を再設定しません。Radialを開いたままでも高さが一定なら再Enterしません。閉じている間に別の仕組みが高さを変更した場合は、次にRadialを開いた時に反映します。

Behaviorはローカルだけで実行します。床の高さを0へ戻すとExitし、元のDesktop姿勢がTemporary Pose Spaceを使っていた場合は、浮遊量が戻るのを待って元の視点を再設定します。歩行への切り替えでは視点を保持します。初期の待機状態ではExitを発行せず、既存の姿勢の視点を解除しません。Tracking Controlは変更しません。視点補正のための同期bitは追加しません。

2026-10-07のユーザーによる実機評価・指定に基づく採用方式です。Unityテストでは姿勢・高さ・左右反転、通常ビルドとプレビルド、30/60/90/144fps相当のAnimator遷移とBehaviorの発行条件を検証します。VRChatクライアントの視点処理そのものはUnityテストで再現しません。

仕様確認: [Playable Layers](https://creators.vrchat.com/avatars/playable-layers/)、[State Behaviors](https://creators.vrchat.com/avatars/state-behaviors/)、[Contacts](https://creators.vrchat.com/common-components/contacts/)。

# 概要
このPackageは「可愛いポーズツール」を始めとしたゆにさきスタジオで販売しているVRChat向けポーズツールのベースとなるシステムです。
メニューはModularAvatarを使用して生成しています。
NDMFを使用した非破壊ギミックになっています。

# プリセットの選択と再読込
「アバター固有」タブのプリセット一覧は、名前で検索できるスクロール式のリストです。先頭の「アバターに適合」に現在のアバター向けのおすすめプリセットを表示し、「ユーザー作成」「ゆにさきスタジオ公式」にも元の一覧を表示します。各グループは折りたためます。適合判定はツール導入時と共通で、元のPrefab（Variantの継承元を含む）の一致を優先し、該当がなければアバター名で探します。 一覧の上にある「同梱プリセットを表示しない」をオンにすると、公式プリセットを一覧・検索結果から非表示にします。この設定は共有ファイルに保存され、同じプロジェクトの各アバターで共通です。

一覧の読込情報は `Assets/UnisakiStudio/Editor/PosingSystemPresetCatalog.asset` に保存し、同じプロジェクトの各アバターから参照します。初回とゆにさきスタジオのツールのバージョン変更時に自動更新し、それ以外は保存済みの一覧を使用します。プリセットの追加・編集・削除後は、一覧の「再読込」を押してください。自作プリセットの保存後も再読込が必要です。

`Packages/jp.unisakistudio.*/Resources/Presets/` 以下を公式プリセットとして扱い、それ以外の場所はユーザー作成として表示します。共有ファイルは一覧の情報だけを保存しており、プリセット本体やポーズの設定を複製するものではありません。
